### 3.3 无缝转场（单镜头内过渡）

> ⚠️ **2026-08-04 修正（以 H3 官方为准）**：Seedance 的"无缝转场"是**平台编辑能力**（两段视频之间生成连续过渡）。H3 官方 ref 文档**没有转场章节**，H3 的镜头间过渡靠 `<scenetrans>`（跨镜头台词连续）+ 分镜切点。本节内容 = **Seedance 思路的 H3 适配版**（把"两段视频转场"降为"单镜头内 A→B 变形"），**可用但无 H3 官方背书**，效果需实测。

Seedance 的无缝转场是"两段视频之间生成连续过渡"（平台编辑能力）。**H3 迁移为单镜头内过渡**：同一段视频里，画面从场景 A 连续变形到场景 B。

**转场链条（7 要素）**：
```
转场前状态 → 触发动作 → 镜头运动 → 画面变形 → 到达状态 → 声音衔接
```

**通用模板（H3 适配）**：
```
<场景A>中，<主体或前景物>通过<动作>触发转场。
镜头<运动方向和速度变化>，画面中的<形状、材质、光线或空间>逐渐变化为<场景B的对应元素>。
转场结束时自然到达<场景B的开头构图>，保持<主体位置、镜头方向和运动趋势>连续。
声音从<前段声音>平滑过渡到<后段声音>。
```

**转场方式速查**：

| 转场方式 | 写法重点 |
|---|---|
| 俯冲或折返 | 镜头方向、速度变化，何时进入下一场景 |
| 人物旋转 | 人物姿态、旋转方向，服装或背景如何连续变化 |
| 前景遮挡 | 遮挡物何时覆盖全屏，遮挡后出现的构图 |
| 物体变形 | 前后物体对应的形状、材质和变形过程 |
| 推拉或焦点变化 | 镜头运动、焦点对象，前后空间的连续关系 |

#### 🎬 专业转场效果库（2026-08-05 用户强调：不是低端叠化，要高级创意转场）

> **定位**：叠化/淡入淡出/划像 = 基础转场（官方切镜动词，用户点名才用）；下面是**有创意的专业转场**——让两镜之间的衔接本身有叙事感。**H3 适配**：单镜头内 A→B 连续变形（见 3.3 链条），或用镜头运动衔接两镜。

| 转场 | 写法 | 叙事作用 | 适用 |
|---|---|---|---|
| **匹配剪辑（Match Cut）** | 镜头一特写圆形硬币，旋转中逐渐变成圆月（形状/动作/构图匹配，两镜元素相似衔接） | 时间跳跃/意象连接 | 怀旧/文艺/蒙太奇 |
| **遮挡转场（Occlusion）** | 前景物体（墙/人/门/雨伞）靠近镜头覆盖全屏，遮挡后露出新场景 | 空间切换/隐藏剪辑 | 动作/旅行/场景过渡 |
| **旋转转场（Whirl）** | 镜头开始快速旋转，画面随之模糊旋转，旋转结束落在新场景 | 眩晕/时间流逝/情绪转折 | 情绪片/梦境/回忆 |
| **光效转场（Light Leak / Flash）** | 画面被过曝白光/光泄漏完全吞没，光线散开后是新场景 | 时间跳跃/记忆闪回 | 回忆/梦境/转场 |
| **焦外转场（Defocus）** | 镜头焦点逐渐失焦至全虚化，再从虚化中重新聚焦到新场景 | 时间/空间过渡 | 文艺片/情绪片 |
| **速度转场（Speed Ramp）** | 镜头先慢动作捕捉关键动作，之后突然加速拉远进入新场景 | 节奏对比/情绪爆发 | 动作/广告 |
| **声音桥（Sound Bridge）** | 镜头一结束时的声音延续到镜头二开头（雨声延续/钟声贯穿） | 听觉连贯/时间连续 | 情绪/氛围片 |

**范例（匹配剪辑，可直接套）**：
```text
✅ 镜头一特写少年手中一枚古铜钱，铜钱被抛起旋转，旋转中画面逐渐变成圆月；镜头二落在圆月下的小院，时间已到中秋夜。（形状匹配：铜钱→圆月）
❌ 镜头一转场。（无转场方式，模型用基础叠化）
```

**⚠️ 使用规则**：
1. **转场必须写"怎么转"**（遮挡物是什么/旋转方向/失焦对象），不写 = 模型默认基础叠化
2. **转场链条 7 要素**（转场前状态→触发动作→镜头运动→画面变形→到达状态→声音衔接）仍适用
3. **适合的片子才用**：匹配剪辑/焦外=文艺怀旧，遮挡/旋转=动作旅行，光效=回忆梦境——**纪实不用转场**，直接切镜

**🚨 片型→转场/运镜需求铁律（2026-08-05 用户强调：旅拍/写真/广告类短片 = 高级感转场运镜是标配）**：

**旅拍（旅行短片）、写真（人物写真/情绪写真）、广告（产品广告/品牌短片）三类短片，高级感转场 + 运镜是硬性标配，不是可选加分项。** 这类片型的观众期待就是"丝滑+设计感"，硬切 = 廉价感。

| 片型 | 转场要求 | 运镜要求 | 示例 |
|---|---|---|---|
| **旅拍/旅行** | 遮挡转场（建筑/门/人群盖镜头）、光效转场（逆光过曝）、匹配剪辑（形状衔接：圆窗→圆月） | 环绕、升降、横移跟拍、大景别运动 | 沙漠公路→城市夜景：前车驶过盖镜头→光散开见新场景 |
| **写真/情绪写真** | 遮挡转场（水花/发丝/衣角拂过镜头）、光效转场（阳光过曝白屏再聚焦）、焦外转场 | 变焦推近、环绕（绕人物转）、极缓推拉、固定+微晃 | 海边少女：水花溅镜头→白屏→聚焦脸部→发丝拂镜头→环绕拢发 |
| **广告/品牌** | 光效转场（光泄漏）、速度转场（慢动作→加速）、遮挡转场（产品/手/纸盖镜头）、匹配剪辑（产品形状衔接） | 环绕、升降、微距推近、跟拍运动、节奏化运镜 | 手表广告：表盘特写旋转→光泄漏→新场景，慢门拖影+加速 |

**写法要点**：
1. **每镜结尾写"触发转场"**——镜头结束时画面发生什么（"镜头结束时，水花迎面溅向镜头，水珠覆盖画面，触发转场"）
2. **下一镜开头写"承接"**——转场到达后画面落在哪（"水珠散开，画面落在..."）
3. **运镜与片型匹配**：写真=克制丝滑（变焦推/环绕/极缓），广告=节奏化（环绕/升降/微距），旅拍=大景别运动（横移/升降/跟拍）
4. **转场素材来自画面内**：水花/发丝/衣角/反光/门/人群——都是场景里已有的东西，不是凭空特效
5. **声音桥配合转场**：转场瞬间声音"同步减弱再复现"，强化丝滑感

**⚠️ 实测边界**：H3 对"覆盖全屏→透出下一镜"是单镜头内变形，可能不完全丝滑——实测生硬时降级为"遮挡物只挡半秒"的轻转场，不要放弃转场直接硬切。

**H3 验证示例（红伞→展厅天窗）**：
```
雨夜街道上，一把红色雨伞靠近镜头并逐渐覆盖整个画面，触发转场。
镜头继续向前推进，雨伞的圆形边缘逐渐变成展厅天窗的金属圆环，红色伞面逐渐过渡为天窗透入的白色天光。
转场结束时自然到达展厅天窗的仰拍构图，镜头由向前推进平滑转为向上抬升。
雨声逐渐减弱，平滑过渡为展厅内的脚步回声。
```

⚠️ 无缝转场追求画面与声音自然衔接，不是逐像素剪辑拼接；镜头运动时长仍控制在 5-6 秒内。
