# 中文古装剧情片 H3 prompt 实战案例（2026-08-24）

> 来源：用户给一段"玄武门事变"30 秒短剧需求（尉迟敬德 vs 李渊对峙），要求改写为 H3 中文 prompt。

## 用户原 prompt 的关键元素

- **30 秒、中式古装写实电影质感、原生同步中文对白**
- **画幅 20:9 宽银幕**（不是 16:9），24fps 观感，35mm 胶片颗粒
- **场景**：唐朝太极宫大殿偏殿（朱红立柱/斗拱/帷幕/青铜宫灯/青石地砖）
- **2 角色对峙**：尉迟敬德（45 岁武将，铠甲，横刀）vs 李渊（60 岁老年，冕服，悲愤无力）
- **3 个核心约束**（来自用户原文）：
  1. **180 度轴线**：尉迟敬德在画面左侧，李渊在画面右侧，相隔约 2 米
  2. **冲突靠微表情/眼神/呼吸/肢体压迫感**（拒绝舞台剧夸张表演）
  3. **4 镜硬切结构**（不是一镜到底）—— 镜 1 / 镜 2 / 镜 3 / 镜 4 明确切点
- **4 句台词**（用 `<d>[中文] 原文</d>` 格式，每句归属明确说话人）

## 改写时踩的坑 & 修法

### 坑 1：原文用"镜头一/镜头二"非 H3 格式

**原文**：「镜头一｜0.0-6.2 秒」「镜头二｜6.2-17.8 秒」

**错误改法**：直接照搬"镜头一/镜头二" → H3 不知道这是切点格式

**正确改法**：用 H3 官方切点格式
```
[Shot 1] ...（无时间戳）
[Shot 2] At 00:06.200, the camera cuts to ...
[Shot 3] At 00:17.800, ...
[Shot 4] At 00:24.200, ...
```

切点用 `At MM:SS.mmm` 严格递增。

### 坑 2：原文用 `{}` 包裹台词，普通模式 vs 全参考模式混淆

**原文**：「尉迟敬德台词：'太子、齐王作乱，已被秦王诛灭...'」

**判断**：
- 用户没有提供参考图（这是从零创作，不是有图改视频）→ **走 T2VA 普通模式**
- T2VA 普通模式下台词用 `<d>[中文] ...</d>` 格式
- **不是** Ref2VA 全参考模式（那种才用 `<d>[中文]</d>` 加更严格的 subject 标签体系）

**正确改法**：
```
尉迟敬德台词（声线浑厚低沉粗粝中年男声）：

<d>[中文] 太子、齐王作乱，已被秦王诛灭，请陛下交出权柄。</d>
```

### 坑 3：delivery（语气/音色）写在 `</d>` 之后

**错误**：
```
轻轻说 <d>[中文] 你……回来了。</d> 尾音发颤，最后一个字几乎散在风里。
```
H3 会把"尾音发颤..."当作旁白读出来。

**正确**：
```
嗓音带着明显的哭腔和笑意、尾音发颤，轻轻说 <d>[中文] 你……回来了。</d> 随后她低头把花束抱紧，肩头轻轻耸动。
```
delivery 描述在 `<d>` 前，`<d>` 后只跟画面动作。

> ⚠️ **2026-10-04 更新（短剧对白戏一律用）**：「轻轻说 `<d>`…」这种内联写法已废弃 → 改「台词标签固定版式」三行块：`S1 角色名台词（语气）：` 独立一行 → `<d>[中文] 原文</d>` 行首独立一行 → `随后嘴唇轻合，<画面动作>`。见 SKILL.md「🚨 台词标签固定版式」。

### 坑 4：人物设定段塞在 `[Shot 1]` 里

**错误**：
```
[Shot 1] 尉迟敬德 45 岁左右东亚男性，体格魁梧壮硕，铠甲披身...
```
人物设定重复，4 镜都要说一遍。

**正确**：人物设定放独立段落（不是塞在分镜里）
```
[Shot 1] ...（只写动作/表情/台词/镜头）

人物设定（贯穿全片）：

尉迟敬德：45 岁左右东亚男性，体格魁梧壮硕，面色黝黑...声线浑厚低沉粗粝中年男声。
李渊：60 岁左右东亚老年男性，鬓发花白...声线苍老低沉老年男声。
```

### 坑 5：30 秒超 H3 单镜头上限

**用户需求**：30 秒完整短片，4 镜

**H3 实际能力**：单次生成 5-6 秒上限，30 秒需拆段拼接

**风险预警必须明示**：
- ⚠️ 30 秒需拆 2-3 段（每段 ≤ 15 秒）
- 段间用尾帧→首帧图生续接保持人物一致性
- 接受 ±1 秒总时长误差

### 坑 6：用户给的"AU4 眉毛下压"等 FACS 表情辅助怎么写

**原文**：「表情辅助：AU4 眉毛下压，AU23 嘴唇收紧」

**判断**：AU 编码是 FACS（面部动作编码系统），对 H3 是**有效指令**（训练语料含电影工业文本），可以用。

**正确写法**：放在动作描述**之后**，用括号或短句补充
```
眉头紧锁，双目锐利直视画面右侧，下颌绷紧，刚经历厮杀，神态带着肃杀之气。表情辅助：AU4 眉毛下压，AU23 嘴唇收紧。
```

**反例**（不要写）：
- ❌ 「请按 AU4 表情执行」—— AI 不识别自由发挥指令
- ❌ 「眉毛做下压动作（AU4）」—— 括号内只是冗余标签，无内容增量

### 坑 7：180 度轴线 vs 反打

**用户硬约束**：尉迟敬德在画面左侧，李渊在画面右侧，相隔约 2 米，**不互换**

**正确做法**：
- 4 镜全程固定轴线，**不反打**（不跨越中轴线）
- 镜 1 尉迟敬德胸部以上近景（视角从左侧看）
- 镜 2 李渊越肩近景（**尉迟敬德铠甲肩头作为模糊前景占据画面左下角 1/5** —— 这是"李渊视角看尉迟"的越肩镜头，但轴线没反：尉迟仍然在左，李渊仍然在右）
- 镜 3 回到尉迟敬德近景（轴线与镜 1 完全一致）
- 镜 4 李渊面部极近特写（轴线仍不变）

**关键**：越肩镜头（OTS）是"借前一个人物作为前景"，但人物在画面中的左右位置不互换——轴线始终固定。

### 坑 8：台词标签揉进叙述句 → 多角色时「谁读谁的」混乱（2026-10-04 用户实测）

**现象**：台词写成 `……以轻蔑的语气说 <d>[中文] …</d> 随后嘴唇轻合……`——H3 分不清哪段是要念的，两个角色的声线还会串。

**修法（官方固定版式）**：`<d>` 另起一行、行首即标签；delivery 独立成行、冒号收尾；说话人 ID 写在 delivery 行开头。

```text
S1 尉迟敬德台词（浑厚低沉、字字沉）：
<d>[中文] 太子、齐王作乱，已被秦王诛灭，请陛下交出权柄。</d>
随后嘴唇轻合，甲叶轻响。
```

**附带必删**：独立台词表 + 表演参考块 + 「念出第 N 句台词」——同一句三处表示 = H3 重复念或错位念。

## 完整 4 件套交付模板（中文古装剧情片）

```text
integrated_multimodal_description:

[Shot 1] <景别+机位+光线>。<主语> <动作1+动作2>。<情绪辅助>。
Sx <角色名>台词（<语气>）：
<d>[中文] 台词原文</d>
随后嘴唇轻合，<收尾画面动作>。

[Shot 2] At MM:SS.mmm, the camera cuts to <新景别>。<新主语> <新动作>。<新情绪>。
Sx <角色名>台词（<语气>）：
<d>[中文] 台词原文</d>
随后嘴唇轻合，<收尾画面动作>。

[Shot N] ...（同上结构）

人物设定（贯穿全片）：
<角色 1>：<年龄+身份+脸型+服装+声音>。
<角色 2>：<年龄+身份+脸型+服装+声音>。

全局约束：<180 度轴线规则/服饰/面孔一致性>。

overall_soundscape: <环境音+动作音+非语言人声，按时间顺序串联>。

non_diegetic_music: N/A

负面约束：<禁项清单，源自原文要求>。
```

## 风险预警清单（30 秒短剧 H3 必查）

| 风险 | 描述 | 修复 |
|---|---|---|
| 单镜头时长超限 | H3 单次 5-6 秒，30 秒需拆段 | 拆 2-3 段，尾帧→首帧图生续接 |
| 跨镜人物漂移 | 纯文生无锚定易漂 | 拆段时每段保留人物设定段；多镜重申外貌+服装+道具 |
| 历史服饰准确性 | 唐代 vs 明清易混 | himg 出"阎立本《步辇图》"风格参考图锁定唐代 |
| 哭戏渲染 | "泪珠滑落"是高难度 | 简化为"眼眶泛红+泪光闪烁" |
| 画外音与嘴型同步 | 镜 3 李渊画外音在尉迟敬德画面 | 画外音进 overall_soundscape，标"画外音来自画面右侧" |
| 持兵器姿态 | 手握兵器低头觐见 | 加"右手持横刀，刀刃朝下，刀柄在腰侧"+ "兵器全程保持在画面内不消失" |
| 定格秒数 | "定格 0.3 秒"难精确 | 改"自然停留约半秒再结束"自然副词 |

## 用户给"参考图"但 prompt 没说的部分（如"现代戏 vs 古装戏"如何处理）

**场景**：用户给了一张现代图（口播美女）说要出 H3 视频，prompt 没指定朝代/风格。

**判断逻辑**：
- 有参考图 → 走 I2VA 模式（首帧锚定行）
- prompt 没指定朝代/风格 → 以参考图风格为准
- 关键约束放 prompt：180 度轴线 / 画面边界 / 禁止元素

**反例（2026-08-24 实测）**：
- ❌ 用户给现代口播图，AI 写"唐代玄武门" H3 prompt → 风格完全不一致
- ✅ 用户给现代口播图，AI 写现代温馨口播 H3 prompt → 风格统一
