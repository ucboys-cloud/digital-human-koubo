# 书写动作镜：正在写的字必须逐字写死（2026-09-18 用户强调）

> 触发场景：H3 / I2VA / T2VA 里出现**人物正在写字**的镜头（老师在写板书、白板写字、笔落在纸上、指尖正在落笔、手指正指着某行字）。
>
> 用户原话：「**黑板上女老师写的什么字也要说明**」「**必须具体 不然就是乱码**」。

## 一、问题

镜里人物**正在写字**时，只写「她在写板书」「她在写笔记」不合格。原因：参考图里她**粉笔正落在那一处**，那一瞬间的字**本来就被手压住看不清**——你不写，H3 就即兴发挥，结果是乱码、半截字、外星文字或与板书无关的词。

## 二、铁律：五要素缺一不可

书写动作镜必须把「她此刻写的是哪几个字」**逐字列出来**：

| 要素 | 写法示例 |
|---|---|
| ① 已有内容 | `黑板上已经写着标题「三、教育的功能」和三条内容「1.传承文化」「2.促进个体发展」「3.推动社会进步」` |
| ② 正在写的字 | **逐字列出**：`她正在「4.」后面写下「健」「全」「人」「格」四个字` |
| ③ 书写顺序/方向 | `从左到右依次写成`、`先写左半边再写右半边`、`一笔一笔落下` |
| ④ 写完的状态 | `写完后黑板第四行完整显示为「4.塑造健全人格」`；`粉笔停在末字末尾`；`写完退半步看清整行` |
| ⑤ 排他声明 | `这一镜只写这四个字，黑板上不出现任何其他新增文字` |

## 三、配套文字总则句（写在文字段开头）

```text
黑板与投影幕上的每一个字都必须逐字正确、笔画完整、朝向正常，与下面的逐条清单完全一致；
不得出现乱码、无意义字形、缺笔缺画的半截字、镜像字、异体字、日文汉字写法、错别字，
也不得把汉字写成类似汉字的方块乱纹。她新写下的字必须与黑板上已有的粉笔字同字体、同大小、
同倾斜角度、同笔画粗细。
```

## 四、两种特殊情形

### 1. 图里看不清的字（被手挡、只露半截、糊了）

**不能放着不管**。由**作者替它定成一个具体的词并写死**，同时在交付说明里明确标注「此处是我定的字（图中被遮挡看不全）」并请用户拍板是否换词。**禁止**留「写着板书」「写着一些字」这类模糊描述。

> 实战：2026-09-18 上课九宫格，格 3 她正写「4.塑造…」，末尾字被手挡住 → 定为「4.塑造健全人格」，并在交付里标出「这是我定的字」；同批格 7 末尾被手臂遮挡 → 定为「4.创造价值」并一并标出。

### 2. 只指不写的镜

手指点着某一行讲解、激光笔指示、敲黑板强调 → 必须写明 `这一镜只指不写，不在黑板上添加任何新字`，防模型自己加戏。

## 五、同步进声音层

书写镜的对位音写成**与逐字书写对齐**的形式：

```text
粉笔划过黑板的连续沙沙声，随着「健全人格」四个字一笔一笔写出而断断续续、节奏分明。
```

不要写「粉笔声」（笼统一条），也不要把书写音写成全程持续型抽象音。

## 六、与铁律 #2 的关系

- **铁律 #2**：画面里**已经有**的文字（招牌/石碑/黑板已有内容）必须写清、且与图逐字一致。
- **本节**：画面里**正在被写出来**的文字必须逐字写死 + 规定书写过程。
- 两条是**上下游**关系：先按铁律 #2 抄清已有内容，再按本节写死正在写的那几个字。

## 七、自检

- [ ] 正在写的字是否逐个列出（不是「写着板书」）？
- [ ] 是否写了书写顺序/方向？
- [ ] 是否写了写完后的完整状态？
- [ ] 是否有「只写这几个字」的排他声明？
- [ ] 是否加了禁乱码/半截字/异体字/日文汉字的文字总则？
- [ ] 图中看不清的字是否由作者定词、并在交付说明里标出？
- [ ] 只指不写的镜是否写明「不添加新字」？
- [ ] 书写音是否与逐字书写对齐？
