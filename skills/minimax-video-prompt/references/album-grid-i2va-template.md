# 手机相册 / App 截图九宫格 → i2va 专用模板

> **触发**：用户给「iPhone/App 截图 × 3×3 九宫格（相册/私密/生活流）」并要求 i2va（`跑i2va` / `生成i2va` / `按九宫格写`）。
> **立此文件的原因（2026-09-24 用户追问「下次你怎么不忘记」）**：该写法此前散落在铁律 #0/#1/#2 + 统一自检 + 决策树里，**没有入口** → 每次凭记忆片段拼，必漏段（实测漏过：首帧固定句、视角规则、叙事与基调、镜头运动纪律段、文字三分类、构图坐标、安全与物理约束、环境与光线 8 段）。
> **用法：先读本文件，再逐段填空。14 段一段都不许少。**

---

## 0. 三条硬前提（缺一条必翻车）

| # | 前提 | 为什么 |
|---|---|---|
| 1 | **九宫格 = 分镜参考图，不是第一帧** | 首帧行**禁写整图 `fully referenced`**；否则成片开头冒出几帧「九宫格 + 状态栏 + 截图边框」 |
| 2 | **必须写 `The first frame of the video is Shot 1 itself.`** | 权威版固定句，明确第一帧就是第 1 格，防 H3 拿整图当首帧 |
| 3 | **文字必须先逐格读图提取**（`vision_analyze` 分块 `region` 读原分辨率） | 铁律 #2 最高优先级：**prompt 里的文字必须是图里实际写的**；图里没有的字不许编 |

---

## 1. 默认参数（相册系列）

- **格数 = 镜数；每格时长按剧情分配，不平均分**（用户纠正：「每个分镜可不是严格按照平均分的，要根据实际场景和剧情来决定」）。
  - 九宫格 9 镜塞进 15s = 每镜 1.67s，**切换太碎** → 叙事/剧图片型默认 **六宫格（6 镜/15s）**；九宫格只用于相册、生活流这类本来就快的回放。
  - 分格时长档：建立镜 3.5-4.5s｜对话镜按台词字数 2.5-3.5s｜反应镜 2-2.5s｜特写炸点 1.5-2s｜收尾 2-3.5s。
  - 例（6 格 / 15s）：`4.5 / 3 / 2.5 / 1.5 / 1.5 / 2`，切点 `00:04.500 / 00:07.500 / 00:10.000 / 00:11.500 / 00:13.000`；**逐格求和必须严格 = 15.000s**。
- **每格必须与成片同比例**：16:9 成片 → 格也是 16:9。画布按「列数×16 : 行数×9」取 16 的倍数：六宫格横版 `3072x1152`、竖版 `2048x1728`（每格都是 1024×576）；九宫格 16:9 格用 `3840x2160`（每格 1280×720）。prompt 里要写「每格都是 16:9 的横向宽幅画面、格宽高相等」——只给画布尺寸模型不会自动等分。画布算法见 `skill_view('himg-image-generation')` →「宫格/分镜图的「格比例」= 画布算法」。
- 每镜必写：**景别 + 机位 + 动作 +（有文字则写文字）+「声音：…」**
- **零台词**（相册系列默认）
- 声音：环境音 ≤2 + 动作音，**全片 ≤4**；**每镜同刻 ≤2**
- 运镜：全片只走**静止/慢速**（相册回放的节奏是「停一下看一眼」，快运镜毁随手拍感）

## 2. 14 段骨架（照抄填空，顺序不要改）

### ① 首帧行（英文，固定句式）
```text
For the target video, <Picture 1> is a storyboard reference for [Shot 1] through [Shot 9], defining their shot size, viewpoint, subject placement, shot order and camera movement. <Picture 1> is not the first frame of the video. At 0.00 seconds the video already starts as a real live-action shot in [场景]: the phone album interface, the status bar, the time and battery icons, the date bar, the back button, the "今天" title, the 3×3 thumbnail grid, the rounded thumbnail frames, the white time captions in the corner of each thumbnail and the bottom album toolbar must NOT appear in the video. The first frame of the video is Shot 1 itself.
```

### ②【视角规则（第三人称随拍）】
机位像家里人拿手机随手记录，高度约一米六，极轻微业余手持晃动，不摆拍不打扰。**持机者本人不入画**：不出现持机者的手、手臂、身体或影子。（例外：自拍格要写明「那一格的手与手机属于人物本人，不属于持机者」。）

### ③【人物锁定（保留图中，不重描）】
**只写「保留 <Picture 1> 中完全一致的脸型/五官/发型/穿搭」+ 不换装/不换发型/不换配色**——不重描服装细节（复述＝给 H3 留「重画衣服」的口子）。写明「全片只有这 N 个人，不出现第 N+1 个主要人物」+ 不做艳俗化/滑稽化/丑化处理。

### ④【叙事与基调（表演动机，不朗读）】
用两三句写完整条生活动线（例：牵孩子出门 → 并排走 → 校门口整理衣领 → 蹲下叮嘱 → 目送 → 独自返程 → 树下回头 → 咖啡店 → 回到车上）。写明**全片没有一句台词**，情绪靠表情/动作/日常声响。

### ⑤【镜头运动纪律（每镜一种轨迹，全片慢速）】
**逐镜列出运镜 + 为什么**，末尾固定句：**「全片直接切，不做叠化、淡入淡出或花式转场。」**
（此段必须写进 prompt 正文；只放在自检表里＝没写。）

### ⑥【环境动态（风必须写进镜头句）】
室外：**风五处同步**——发丝 / 衣摆 / 植物 / 云 / 路边旗子；方向与力度从头到尾一致。
室内（车内等）：**没有风**，改写成怠速抖动 / 气流 / 灯带 / 窗外景物明暗变化。

### ⑦【背景群演动态（走 §2.1b 撬动背景四式）】
① 点名 2-3 个背景人物 + 具体动作；② 用「各自活动起来」不用「保持」；③ 明确「主角是唯一视觉锚点，背景不占锚定」；④ 显式许可背景微动 / 轻微运动模糊。**禁写「保持首帧状态」＝雕像。**

### ⑧【文字规则（三类分开处理）】← 铁律 #2
| 类 | 处理 |
|---|---|
| ① 场景实体文字（招牌/门牌/路标/指示牌/横幅/标语牌/石碑刻字/店招/黑板板书/包装/书封） | **逐字写清、与图一字不差、用英文双引号包裹**，每处加「字迹清晰完整」 |
| ② 界面/叠加层（状态栏/日期栏/返回键/标题/网格与圆角边框/**格内左下角白色时间小字**/底部工具栏） | **全部排除**，并写「一律不出现在视频里」 |
| ③ 其余 | **不新增文字**：不生成字幕/标题/序号/时间码/水印/数字叠加 |
> 图里读不出的字（太小/虚化）→ 写「字迹虚化、不可辨认，保持不可读，不放大、不补写、不替换成可读文字」，**不许编**。
> 文字要短（2-8 字），长标语要么缩到短句，要么接受它会糊。

### ⑨【构图坐标】
逐镜写「主体在画面左/中/右 + 背景元素位置」，末尾固定句：**「位置关系全程不左右换边。」**

### ⑩【安全与物理约束】
逐镜写物理安全（例：衣领不勒脖、手掌只是轻放头顶轻抚一下不压不推、杯子稳放不倾倒、车不启动不移动、不摔倒不撞门框、牵手不拉扯）。总起句：「全片是安稳的日常，不出现暴力、争吵、推搡与伤害动作。」

### ⑪【环境与光线】
逐镜写光源与色温，末尾固定句：**「全片光线稳定不跳变、不闪动、不出现色温突变。」**

### ⑫ `integrated_multimodal_description:` + N 镜（N = 格数，逐格一镜）
格式：`[Shot N] At 00:0X.XXX, the camera cuts to 景别，机位在…，镜头固定/跟随。` + 动作 + 文字 + `声音：…`。第 1 镜不写时间戳（它是 0.000s）；切点按分格时长逐个累加，**不平均分**。

### ⑬ `overall_soundscape:` / `non_diegetic_music: N/A`

### ⑭ 负面声明
开头逐项点名界面元素（状态栏/日期栏/返回按钮/标题/网格/圆角边框/格内白色时间小字/底部工具栏），**中间复述全部场景文字**（防乱码），再写物理/声音/光线约束，末尾固定句「只生成连续镜头，不生成静态分镜图。」

## 3. 逐格读图清单（生成图之后必做）

1. 状态栏 / 日期栏 / 底部工具栏逐字（确认 UI 完整）
2. **九格逐格：景别 + 机位 + 人物在做什么 + 道具**
3. **每格真实文字逐字提取**（分块 region 读原分辨率；缩略读出的字不可信）
4. 主角一致性（发型/服装/体态九格是否同一人）
5. 机位/衣着口径**只在用户于 prompt 里点名时才查**（**景别、机位、角度、衣着一律不设限**，不主动加条款）
6. 有无模型自加的字幕条 / 序号「1/9」/ 手写便签（不要就写排除句）

---

## 3.5 读图判定：先分类，再决定要不要重出（2026-10-16）

逐格读图后，**不要把所有「不符」都当成错误**——单张静帧天生表达不出动态。两类分开：

| 类 | 例子 | 处理 |
|---|---|---|
| **结构性偏差**（景别/动作/方向/位置/主体缺失） | 该是「手掌撑阶起身」却画成「坐在石阶边的下半身」；该是「朝街尾跑」却画成「迎面朝镜头跑」；该有两人却画成纯空镜 | **重出那一张**（同 prompt 里把那一格写得更死：给面积/朝向/主体的可见特征） |
| **动态不可表达**（风势/呼吸/人流散去/灯火渐亮/云层压低） | 单帧里「灯笼大幅摇晃」「树枝摇动」「人群加速散去」看不出 | **不算错，不重出**——H3 侧靠文字生成，静帧只做一个位置参考 |

另：整图也容易被画成「纯街景」——**关键人物在远景里太小时，模型会干脆不画人**；需要人物可辨时，那几格要写「两人位于画面中部偏下、占画面高度约四分之一」。

## 4. 交付自检（硬问句，软判据不算过）

- [ ] 首帧行有没有 `fully referenced`？（**有 = 错**）
- [ ] `The first frame of the video is Shot 1 itself.` 写了吗？
- [ ] 14 段齐了吗？（逐段点名，缺一段都算没写）
- [ ] 场景实体文字是否**逐字**写死、与图一致、英文双引号包裹？
- [ ] 界面元素 + 格内白色时间小字是否**全部排除**？
- [ ] 声音：环境音 ≤2？全片 ≤4？每镜同刻 ≤2？
- [ ] 时长严格闭合（**逐格求和 = 15.000s，不是平均分**）、切点递增、格数 = 镜数？
- [ ] 运镜表：一镜一轨迹？全片慢速？
- [ ] 交付是否**一整段**（`integrated_multimodal_description` / `overall_soundscape` / `non_diegetic_music` / 负面声明全在段内，一次复制到底）？

## 5. 踩过的坑（别再踩）

| # | 坑 | 修法 |
|---|---|---|
| 1 | 首帧行写 `fully referenced` → 成片开头冒出九宫格+状态栏 | 只写 storyboard reference + 「不是第一帧」+「第一帧就是 Shot 1」 |
| 2 | 场景文字被「统一排除」掉 | 场景实体文字**必须逐字写出来**（铁律 #2），只有界面/叠加层排除 |
| 3 | 文字用了「」而非英文双引号 | 铁律 #2 要求用英文双引号包裹 |
| 4 | 重描服装细节 | 改「保留图中，不重描」（只写增量） |
| 5 | 运镜只写在自检表里 | 必须写进 prompt 正文的【镜头运动纪律】段 |
| 6 | 室内场景照抄「风五处同步」 | 室内没有风 → 改怠速抖动/气流/窗外明暗 |
| 7 | 背景写「保持首帧状态」 | 走四式，写「各自活动起来」 |
| 8 | 路牌字读不出就编一个 | 写「字迹虚化、不可辨认」，或问用户 |
| 9 | 交付拆成两个代码块 | **一整段**，一次复制到底 |
| 10 | 每格平均分时长（9×1.667s 那种） | 按剧情分配：建立长、反应短、特写极短、收尾留白；总和闭合到 15.000s |
| 11 | 只写转场表、不写进 prompt 本体 | 每段 **段首承接句**（承上一段尾帧状态 + `continuation of action`）+ **段尾转场句**（写清转场物/方向/声音桥）都要落进 prompt；**同一场景至少 2 段（≥30s）**，否则多段拼不成一条连贯片 |
| 12 | 叙事/国漫类套用本骨架时沿用「零台词」 | 短剧/国漫/情感类**默认配台词**：音色锁定 + 每句语气 + `<d>[中文] …</d>` 三行块 + 每句闭嘴落点；只有奔跑/强风等声源受限段才留白，且要在交付里说明留白理由 |

---

## 6. 交付格式（五件套）

① 【1. 干净的 H3 prompt】**一整段** ② 【2. 自检结果】逐项写判据 ③ 【3. 修订/防坑要点】④ 【4. 新增的物理矛盾】⑤ 【5. 评估检查轮】——**交付之后自动跟一轮**（读回门禁原文 + 硬问句 + 打分 + 必修项附可替换句）。
