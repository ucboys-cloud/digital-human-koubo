### 连续运动型任务：运动组织与动态视听密度（2026-08-08 新增）

> **定位**：这是可选的高级导演模块，不是所有视频提示词的默认写法。它吸收高级参考案例《光标提前下班》的运动语法，适用于连续变形、实拍与动画融合、追逐、通勤、荒诞动作、物体变形和高密度广告动作片。普通文戏、静物产品片、风景空镜、简单姿态和单一运镜任务不要强行启用。

#### 适用性判断

启用条件满足两项或以上时，考虑启用本模块：
- 主体需要连续改变形态或运动方式；
- 动作需要穿越多个空间或连续接触多个真实物体；
- 摄影机需要追赶、迟疑、失焦或被主体带动；
- 视频的看点是连续动作本身，而非对白或单一结果；
- 需要实拍与手绘、二维动画或其他媒介持续融合。

不满足上述条件时，使用普通叙事链、文戏分镜或基础公式，避免增加无效复杂度。

#### 连续运动组织公式

```text
运动目标 → 动能来源 → 形态/状态变化 → 运动方式或方向改变
→ 空间推进 → 摄影机响应 → 声音反馈 → 下一动作触发
```

每个高动态动作单元至少完成以下三项：
1. 改变主体形态或状态；
2. 改变主体的运动方式、方向或速度；
3. 把主体送入下一空间，并触发下一动作。

前一动作的速度、方向、接触点、弹力、冲击力或遮挡关系，应成为后一动作的运动来源。禁止把“变形、移动、攻击、转场”写成互不相干的事件列表。

**变形不是装饰，而是运动工具**：行李箱负责奔跑，地铁负责沿线滑行，纸飞机负责向上飞行；每次形态变化都必须解决一个新的运动问题，并把主体带到下一空间。

#### 动态视听密度

高动态任务不等于无节制堆动作。每个时间段至少同时推进两类变化：

```text
主体动作或形态变化 + 空间推进或摄影机变化
```

高潮段可加入真实物体互动、光色变化、线条变化和对应动作声，但所有变化必须服务同一个运动目标。优先采用“一个主运动 + 两个辅助层”，例如：主体变形 + 摄影机追赶 + 真实物体接触；不要把多个独立主动作同时启动。

按阶段规划动态密度：
- 开场：建立运动目标和空间路线，同时给出一个可见的异常触发；
- 发展：每次形态变化都改变路线、速度、方向或接触方式；
- 高潮：连续动作加速，摄影机出现迟疑、跟丢或补偿性追赶；
- 收束：减少新变化，完成核心动作，让最后形态和空间状态稳定下来。

#### 摄影机追赶链

```text
主体先改变方向或离开构图
→ 摄影机短暂迟疑、失焦或跟丢
→ 摄影机补偿性摇摄、俯仰、推进、后退或转向
→ 新空间和下一动作被发现
```

“手持感”“摄影机慢半拍”不能只作为风格形容词出现，必须写成具体的镜头反应。摄影机的迟到、补追和重新构图应由主体运动触发，而不是全程随机晃动。

#### 声画分段

连续运动任务允许使用“有理由的超额”声音，但必须按动作阶段进入、减弱或结束。每个声音都要绑定可见来源，并承担运动节拍、形态变化、空间转移、转场或结尾功能；不得将所有声音全程同时播放。声音多时，优先保留主运动声、关键变形声和结尾声，删除重复声与无来源抽象声。

#### 参考母案例：实拍 × 粗糙发光帧动画《光标提前下班》

```text
光标拒绝工作 → 逃出屏幕 → 行李箱改变奔跑方式 → 迷你地铁沿充电线滑行
→ 纸飞机改变为向上飞行 → 小鸟改变为贴墙飞行 → 自行车改变为地面追逐
→ 橘猫进入床铺 → 巨大睡猫完成合电脑和关灯。
```

该案例的可迁移规则是：
- 形态变化同时承担位移功能；
- 空间路线连续推进，不是孤立换场；
- 摄影机因追不上主体而迟疑和补追；
- 实拍物体通过接触、遮挡、反射和比例关系参与动作；
- 声音随动作阶段变化，超额音效必须有画面理由；
- 结尾回到一个稳定、可读的生活结果。

禁止直接复制案例中的光标、行李箱、地铁或睡猫，仅迁移运动组织方法。
