# MiniMax H3 / 海螺AI 视频生成 Prompt 技巧

> 来源：MiniMax 开放平台官方文档《Prompt 技巧》（platform.minimaxi.com/docs/guides/video-prompt）+ Huggi…

## ⚠️ 铁律 #0：提示词一律用中文（2026-08-03 用户硬性要求）

**所有产出给用户/H3 的 prompt 必须全中文编写。** 官方文档是英文的，只能借鉴其**结构**（三段式、声音三层分工、说话人 ID、镜头运动三要素），**不得**把最终 prompt 写成英文。

## ⚠️ 铁律 #1：禁止 skill 内部标记污染 prompt（2026-08-09 用户实测发现）

**写 prompt 正文时**，**禁止出现**以下 skill 内部使用的标记（这些标记只能出现在 skill 自身的检查清单/红线规则里，**不能写进给 H3 的 prompt 正文**）：

### ❌ 禁止的 12 类内部标记

| # | 禁止的标记 | 例子 | 为什么禁用 |
|---|---|---|---|
| 1 | **章节编号** | "8.8 高级运镜规则"、"8.9 物理一致性"、"8.9.1 动作戏专用" | H3 模型不知道 8.8/8.9 是什么 |
| 2 | **AI 评分标记** | "1+1 规则"、"4 层反向链"、"8 大反例" | H3 模型不知道这是评分项 |
| 3 | **AI 自检问句** | "**自检问**：'这个声音的物理来源能支持这个内容吗？'" | H3 模型**会回答这个问句**——当成 prompt 要求 |
| 4 | **反向指令污染** | "不'凭空出现'"、"不要'声源不匹配'" | H3 模型会**困惑**——我要凭空出现还是不要？ |
| 5 | **内部术语** | "**物理 8.9 真实**"、"红线 1 声源不匹配" | H3 模型当成新概念 |
| 6 | **自评分数字** | "**REBOUND 3 阶段**"、"100/100" | H3 模型可能当成画面要求或阶段数 |
| 7 | **优先级标记** | "**P0 必跑**"、"**P1 应跑**" | H3 模型不知道 P0 是什么 |
| 8 | **markdown 标题** | "# 镜头设计"、"## 物理一致性" | H3 模型当成 markdown 标题 |
| 9 | **shot 编号格式** | "镜 1（0-5s）" 这种非 H3 友好的分段 | 跨段拼接会乱 |
| 10 | **百分制自检** | "100/100"、"95/100" | H3 模型可能当成画面要求 |
| 11 | **8.9/8.8 数字** | "**8.9** 真实"、"8.8 高级" | skill 章节编号污染 |
| 12 | **"红线 X"** | "**红线 1 声源不匹配**" | 内部红线标记 |

### ✅ 正确的替代写法

| 错误（污染）| 正确（干净）|
|---|---|
| "**8.8 高级运镜规则**：REBOUND 3 阶段" | 镜头急促推近到中景、短暂停顿后反向回拉一点、锁死中景 |
| "**物理 8.9 真实**：缓缓飘落" | 缓缓飘落、落地时双脚同时轻触地面、落地后膝盖微屈一次缓冲 |
| "**Full Rebound 5 阶段镜头曲线**" | 镜头先正常推近、反向回拉、修正后硬锁死在面部特写 |
| "**4 层反向链**（圣女落地+开口后）" | 镜头锁死后：圣女躯干微顿、月白长裙下摆缓慢下垂、淡紫薄纱披风极轻飘动后归位 |
| "**1+1 规则**：本镜 1 身体动作 + 1 画面运动" | （直接删掉这个标签，H3 模型不识别）|
| "**自检问**：'这个声音的物理来源能支持这个内容吗？'" | （直接删掉）|
| "**P0 必跑**" | （直接删掉）|
| "**100/100**" | （直接删掉）|
| "# 镜头设计" | 镜头机位固定在男主肩后侧 30 度方位 |
| 推过 X% + 微反向回拉 X% | 急促推近 + 短暂停顿后反向回拉一点 |
| 0.4s / 0.3s 时长 | 缓慢 / 极轻 / 短暂 |
| "不'凭空出现'" | 背景虚化但能看到街道人影缓慢移动（为全景做人物在场性建立）|

### 写 prompt 的 5 步自检（交付前必跑）

写完 prompt 后，问自己 5 个问题：

1. ✅ prompt 里有没有出现**"8.8/8.9/4 层/1+1/P0/P1/100/100/自检问"**这些标记？
2. ✅ 物理描述有没有用"**X% / 0.Xs**"这种数字精度？应该改成"急促/缓慢/极轻/短暂"自然副词
3. ✅ 反向指令有没有写"**不'X'**"这种？应该改成正向描述
4. ✅ 有没有用 markdown `# 标题`？应该改成"镜头机位固定在..."的描述句
5. ✅ 有没有混入"**自检问/百分制/优先级标记**"？应该全部移到 prompt 外面

### 交付格式（**5 件套，唯一定义处**）

> 🧭 **本节是交付格式的唯一定义处（2026-09-24 修）**：其他位置（「统一自检流程 · 阶段 3」、「质量自检清单 · 0. 结构」）**只保留速查表与指针**，不再重复定义，避免三处漂移。

> 📏 **篇幅上限（2026-09-26 加 · 反制“逐条覆盖门禁导致 prompt 膨胀”）**｜用户实测「感觉反而不如原版效果好」的根因 = 篇幅膨胀稀释分镜权重。三条硬上限：
> 1. **总字数（是区间，不是越短越好）**：对白戏/文戏 **1,200-1,500 字**；单图/多图物理片 **≤2,500 字**；九宫格 i2va **≤2,000 字**。🚨 **低于下限 = 信息缺失，同样不合格**（2026-09-26 实测：把对白戏压到 700 字 → 丢掉轴线/机位/站位/道具台账/声音来源/光线 → 成片「错误百出」）。**极简 = 意图完整 + 零冗余，不是删信息。**
> 2. **段数按需，不逐段凑**：多镜头物理片默认 **12-14 段**，**16 段是上限不是标配**；能合的合（无背景群演就不写「背景群演动态」段，无台词就不写台词表）。
> 3. **负面声明 ≤8 条**：只写**这次题材真会踩**的（车辆片写“不倒退”、厨房片写“不烫伤”）；通用免责（不出现水印/不失焦/不色偏）合并成 1 条。
> **禁止为“覆盖门禁”而堆段**——门禁是写作时的自查清单，不是 prompt 的目录。

**自检结果**必须**写在 prompt 后面**（独立段落），**不能混在 prompt 里**：

```
【1. 干净的 H3 prompt】（不含任何自检/打分/内部标记）

> **🚨 整段交付铁律（2026-09-24 用户抓出“为啥分成两段”）**：干净 prompt **只能用一个代码块**——风格/概念/场景/人物设定 + `integrated_multimodal_description:` + 逐镜 + `overall_soundscape:` + `non_diegetic_music:` + 负面声明**全在同一段内**，字段名当行标。**不得拆成两个或多个代码块**（会让用户以为要分多个输入框，也与官方三段式字段不冲突）。权威参照：`references/canonical-examples.md` 的「玄黄刀 v10 完整示例」。

【2. 自检结果】（独立段落，紧跟 prompt 后）
- 8 红线全过
- 物理 7 大类全过
- 官方 12 词 + 高级导演运镜正确组合
- 修复了什么 / 本次新增的物理矛盾
- **6.5 因果·分镜·动作逻辑：必须逐镜成表输出**（每镜至少三列：①因果 ②分镜 ③动作）

> ⚠️ **6.5 不许压成一行「物理一致性 ✅」**（2026-09-17 用户连续两版抓出漏项）。只写「物理一致性通过」= 没跑这一步。逐镜跑才能抓出真问题：**台词与动作冲突**（自问「酒现在开吗」的同时手已在拧瓶塞）、**时序倒置**（迎客/送客的话排在被声明为「按时间顺序」的末尾）、**空间漂移**（同一舞台跨镜方位不一致）。发现即标「待修」，补实后才交付。
>
> **🔧 道具台账法 + 三查（2026-09-18 用户抓出「皮裙一般没有兜」「刚开镜还没买东西就提着袋」后加入）**：写分镜**前**先列道具台账，每件道具三列——**获得时点 / 消失或放下时点 / 物理属性约束**；再把 6.5 的③动作逻辑拆成三查：
> 1. **时序查**：这件东西此刻她拿到了吗？（正例：购物袋只在出店后出现；反例：开镜还没买就先提着纸袋 = 错）
> 2. **属性查**：这个动作这件衣服/道具物理上做得到吗？（正例：皮裙/紧身裙/瑜伽裤**一般没有侧兜**，不能写「手插裙袋」；反例：连体衣写「掀起下摆」、双手拎两个满袋还要同时举手机）
> 3. **守恒查**：数量与位置跳镜对得上吗？（正例：两只袋从出店到结尾一直两只；手持物要交代去处——杯子丢垃圾桶/放桌上/收进包里）
>    - 🚨 **模糊动词 = 道具消失的高发点（2026-09-24 用户抓出「最后一个镜头手机咋没了」）**：「收好 / 收起 / 放一边 / 处理掉」这类**没有落点**的动词，H3 会直接让道具凭空消失（红线 ②）。要么给**明确落点**（握在手里 / 放在腿上 / 放进**首帧里已有的**包 / 丢进垃圾桶），要么直接写「始终握在手里」。**不许靠“收进包里”救场**——首帧没有包 = 新增道具（另一条红线）。交付前对每件手持道具问一句：**「它最后在哪？画面里看得见吗？」**
> 交付时在 6.5 表下方附**道具台账**（每件道具一行，标出获得镜→消失镜），用户能一眼核。

【3. 修复了什么】
- 上一版 X 残留 → 已删除

【4. 本次新增的物理矛盾】
- ✅ 未发现 / ✅ 已修复 Z

【5. 评估检查轮】（2026-09-24 用户定：**交付给用户之后，必须自动再跟一轮**，不等用户开口点"评估"）

**为什么必须独立成轮**：写完的自检本质是"重述"——它检查的是"我有没有写这一项"，不是"这一项在事实层面成不成立"（典型：给新增道具写了"从旁边拿起"的来源说法就自认有来源）。评估轮靠两个机制抓真问题：**①换判据（软→硬）②对照外部原文（从盘上重读门禁，不凭记忆）**。两者在同一轮内即可完成，不必等下一轮。

**固定动作（不凭感觉）**：
1. **从盘上定点读回门禁原文**（本 skill 的「写 prompt 的 5 步自检」/「道具台账法 + 三查」/「声音元素总量铁律」/「质量自检清单」）——凭记忆片段自检 = 必漏项。
2. **硬问句逐条查（软判据一律不算过）**：
   - 这件道具**在首帧里存在吗**？不存在 → 凭空（"有来源说法"不算过）
   - 这个声音来自**哪个声场**？座椅/扶手/积水等 = 环境底噪 → 并入不单列（环境音 ≤2）
   - **同刻几个音**？（每镜 ≤2）
   - **景别、机位、角度、衣着一律不设限**——近景/局部特写/低角度仰拍都是电影语言，由用户按叙事定；**这一项只在用户于 prompt 里明确写了机位或衣着口径时才对照检查**（不主动加这类条款）
   - 每镜时长之和**是否严格 = 总时长**、切点是否递增？
   - 动作链三查：前提 / 顺序 / 落点
   - **主体行进方向有没有锚？**（铁律 #5；**凡有位移的镜头都要查，不限追逐/赛车戏**）：主体朝哪个方向前进写了吗？镜头的反向动词（后退/倒飞/跟随/拉开/环绕）有没有与主体的前进方向**成对写出**？画面内有没有位移矢量（树/护栏/路面/人流从哪流向哪）？半转身动作（回眸/回头看/侧身）有没有限定「只转头与上身、脚下与身体朝向不变」？
3. **输出**：打分（百分制 + 分项）→ **必修项 P0（附可直接替换的句子）** → P1 → 亮点（别改）。

**边界**：评估轮只抓**有硬判据**的项（物理 / 声音 / 合规 / 时长 / 道具台账）；**风格类（简约/厚重/生硬/设计感）抓不了**——那属审美判断，由用户定。
```

**反例**（prompt 内混自检——**错误**）：
```text
[Shot 1] ... 缓缓飘落。（物理 8.9 真实：双脚同步触地）... 
（P0 必跑：声源不匹配）...（自检问：'位置物理对吗？'）...
```

**正例**（prompt 外独立自检——**正确**）：
```text
[Shot 1] ... 缓缓飘落、落地时双脚同时轻触地面、落地后膝盖微屈一次缓冲...
（干净的物理描述，0 内部标记）

---

【自检结果】
✅ 1 声源不匹配：...
✅ 5 物理位置矛盾：双脚同步触地、落地后屈膝缓冲
...
```

### 内部标记 vs 高级专业术语的区分

| 类别 | 在 prompt 里能用吗 | 例子 |
|---|---|---|
| **高级专业术语**（导演/摄影术语）| ✅ **能用**（H3 是电影级模型支持）| Dolly In/Out、希区柯克变焦、Handheld、Steadicam、Dutch Angle、Whip Pan、Crane Shot、Rack Focus、POV、Low Angle、High Angle、Bird's Eye |
| **官方 12 词**（H3 原生支持）| ✅ **能用** | Push In/Pull Out/Pan/Tilt/Truck/Pedestal/Arc/Tracking/Static/Shake/POV/Roll |
| **skill 内部标记**（AI 评分/章节/红线/百分制）| ❌ **不能用** | 8.8/8.9/4 层反向链/1+1 规则/物理 8.9/P0 必跑/自检问/100/100/红线 X |

**判断标准**：
- **H3 文档或导演词典里能查到的词** = 高级专业术语 ✅
- **skill 章节里 AI 自己造的红线/标签/章节** = 内部标记 ❌

| 项 | 规则 |
|---|---|
| 产出语言 | ✅ 中文（包括分镜头、镜头运动、后制参数全部中文） |
| 官方英文结构 | 借鉴结构，中文表达 |
| 台词（普通模式） | 中文原样，用 `{}` 包裹 |
| 台词（全参考模式） | **用 `<d>[中文] ...</d>`**（官方 ref 文档硬性要求，覆盖本表"语言标签"行） |
| 语言标签 | 普通模式不写 `<d>[Chinese]`，直接中文；**全参考模式必须写 `<d>[中文]</d>`** |
| 例外 | 若用户明确要英文 prompt 才给英文 |

**理由**：中文 prompt 对中文模型意图表达更准，且与 himg 中文直传习惯一致；官方英文格式只作为内部理解参考。**2026-08-04 更新**：官方全参考模式（Full-Reference Mode）文档明确要求台词必须用 `<d>[语言] 原文</d>` 格式，此要求**覆盖**普通模式的 `{}` 写法——按任务类型选择：文生/图生普通模式用 `{}`，多素材全参考模式用 `<d>[中文]</d>`。

## ⚠️ 铁律 #2：画面内可见文字必须写清具体内容（2026-09-17 用户硬性要求）

**凡画面里出现文字，一律在镜头描述里把文字内容原样写出来。** 不写内容，H3 不会"猜"该写什么——它只会糊成乱码或随机编几个字，直接把真实感毁掉。写清 = 可控。

### 覆盖类型（一个都不许漏）

| 类别 | 例子 |
|---|---|
| 场景标识 | 招牌、门牌、路标、指示牌、横幅、标语牌、石碑刻字、店招、导览图 |
| **教学/办公** | **黑板板书、白板字**、投影屏幕上的文字、讲义标题 |
| 商品/读物 | 书封书名、标价牌、菜单、包装文案、海报文字 |
| 界面/系统 | 手机状态栏与 App 界面文字、HUD、倒计时、弹幕 |
| 字幕 | 屏幕字幕（格式见下方「屏幕可见文字」章节） |

### ⚠️ 最高优先级：文字必须与图里实际存在的文字一致（2026-09-17 用户纠错）

**prompt 里的文字不是"你想让它写什么"，而是"图里实际写了什么"**——凭空编造牌子/石碑/黑板上的文字 = 错，成片会和参考图对不上，一眼出戏。

| 步骤 | 做法 |
|---|---|
| 1. 先读图提取 | 参考图是**九宫格/分镜图/宫格图**时，**必须**用 `vision_analyze` 逐格提取画面里真实出现的文字（招牌/石碑/黑板/界面），一字不差记下 |
| 2. 照搬进 prompt | 只写图上真实有的文字；图里没字的格子写"无文字"，**不许自己加标语** |
| 3. 负面声明复述 | 把提取到的文字原样列进结尾负面声明，防乱码 |

**实测反例（本次纠错）**：登山九宫格图里实际写的是「登山口 向上即是风景」「坚持 就是更好的自己」「山不止于高 而在于你来过」「海拔 1186米 山高路远 但终会相见」「山顶 见证更好的自己」；而 AI 凭空编了「山顶 2km」「观景平台」「海拔 1280 米」，全部与图不符——**编造即失分**。

### 写法（三步，缺一步都算没写）

1. **在对应镜头描述里写明内容**：`身旁的木牌上写着"登山口 向上即是风景"`、`黑板上写着"光合作用"四个字，下面画了一条公式`、`白板上写着三道例题`
2. **用英文双引号包裹文字内容**（H3 屏幕文字官方格式），简体中文原样不翻译
3. **结尾负面声明里复述全部文字**，双保险防乱码：`画面标牌文字为简体中文：登山口 向上即是风景／山顶 2km／观景平台`

### 为什么必须写（反例对比）

| ❌ 不写内容 | ✅ 写清内容 |
|---|---|
| `黑板上写着板书` → 生成一黑板乱码/外星文字 | `黑板上写着"光合作用"四个字` → 字可控、工整 |
| `她身后的牌子上有字` → 随机编字，可能编出与场景无关的词 | `石碑上刻着"山顶 海拔 1280 米"` → 内容确定、位置确定 |

### 边界（别用过头）

- **只在该有文字的位置写**：招牌写招牌、黑板写板书；**不在无文字的场景凭空加标语**
- **文字要短**：长句小字渲染不稳，优先 2-8 字短词；长标语要么缩到短句，要么接受它会糊
- **位置/标点/字体**三条细则见下方「屏幕可见文字」章节（位置稳定、不用标点、字体匹配题材）
- **不覆盖"板上元素零进成片"**：开发板/分镜图这类**参考图**上的标注文字仍不进成片；本铁律只管**场景里真实存在的文字**

> 实战来源：2026-09-17 登山九宫格 I2VA——用户要求把"登山口 向上即是风景"牌子、"山顶 2km"路标、"观景平台"指示牌、山顶海拔石碑写进对应镜头；同批补…

> 🚨 **书写动作镜（2026-09-18）：正在写的字必须逐字写死**——五要素、文字总则句、看不清的字怎么办、自检清单：见 `references/2026-09-18-writing-action-rule.md`。

## ⚠️ 铁律 #3：环境动态（风/气流）必须显式写出，并落进镜头动作句（2026-09-17 用户实测）

**H3 在户外场景默认把环境渲染成「静止稳定」**——这是模型的保守策略（优先保主体稳定、画面不乱晃），不是 bug。**没写风，头发／衣摆／树叶／草地就一动不动**；而且**「微风」这类风级词几乎无效**，因为模型认的不是风的名字，而是「谁被吹动了、动了多少」。

### 写法公式（缺一项就不动）

> **风 = 施力对象 + 位移结果 + 方向 + 持续性**
>
> ❌ `微风吹过`（只有风的名字，没有受力对象）→ 画面静止
> ✅ `风从画面左侧吹来，她额前的碎发被掀起点偏离眉心，开衫下摆向右侧鼓起又落回，路边几片银杏叶贴着地面被吹着横移`

### 幅度分级（用可见位移代替风级词）

| 想表达 | 别写 | 写成可观察结果（画面层） | 配套声音层 |
|---|---|---|---|
| 几乎无风 | 「微风」 | 几缕碎发被轻轻撩起一点、发尾小幅晃；草只是叶尖微晃 | 极轻的空气流动声，几乎可忽略 |
| 有风 | 「和风」「风吹过」 | 发尾明显向一侧飘起、衣摆持续轻摆；草成片伏倒又弹起；树叶翻动、叶片互相摩擦 | 树叶沙沙声、草地被风扫过的连续窸窣 |
| 风大 | 「劲风」「大风」 | 整头长发向侧后方扬起、发丝根根分开；开衫下摆被掀起贴住腰侧；树冠摇动、落叶成片卷起横向掠过画面；草被压伏成浪 | 风灌过树冠的轰鸣、树叶密集拍打声、草浪的连续哗响 |

**动态与声音必须配对**：画面层写位移（写进对应镜头句），声音层同时写对应声响（写进 `overall_soundscape`）——只写声音不会让画面动。

### 四条硬规则

1. **每镜都要重申**：H3 跳镜不继承环境物理——镜 1 写了风，镜 3 不会自动有风。要连续就明写 `风从开头持续到结尾，一直存在，不是只在某几个镜头出现`。
2. **写进镜头动作句**（`integrated_multimodal_description`），紧贴主体动作；**只写在 `overall_soundscape` = 等于没写**。
3. **绑定具体对象**：发丝／发尾／刘海／衣摆／裙摆／树叶／草／落叶／热气／水面／旗帜／纸张——越具体越会动。
4. **参考图是静态时零风信息可继承**：九宫格／单帧首帧都不带风的动态，**只能靠文字补**（除非素材格子里头发本身就是飘起的，那一点可以被继承）。

### 边界（别用过头）

- 风的幅度要与场景匹配：室内／清晨静景不要写到「树冠摇动」级别；写风的**位移要落在合理区间**，不要夸张到把人吹得站不稳。
- 风不能只当氛围词写一次就完事：它是一条**贯穿全片的物理条件**，得按镜头反复交接（风吹到哪儿、什么被带动）。

> 实战来源：2026-09-17 用户实测——「户外场景一直没风，头发也不动」「微风都几乎没效果」；跳平台检索确认是训练策略（保主体稳定、避免不可控飘动），社区建议同样指向…

## ⚠️ 铁律 #4：H3 不过审 —— 禁止为“过审”降级内容（2026-09-24 用户硬性要求）

**minimax H3 的 i2va / T2VA 生成不走内容审核。** 写 H3 prompt 时，**不许**为了“可能被拦”做任何降级：

| ❌ 不许（这些是 himg/hedit 图片侧的规则，误用到 H3） | ✅ H3 侧的正确做法 |
|---|---|
| 把服装措辞改保守（吊带婚裙 → 加短袖/外搭） | 按用户给的原文写，不改措辞 |
| 收窄景别（“不做任何身体局部特写”） | 景别不设限，近景/特写/局部特写都是电影语言 |
| 删掉身体语言与身段描写 | 该写就写 |
| 主动加自保条款（“不出现酒杯、不出现烟”“人群保持一臂以外不触碰”“衣着不移位、不出现走光”） | **用户没提就不加**；用户提了才写 |
| 交付时附“过审概率/降级建议” | 不写这类提醒，直接给稿 |

**H3 侧只保留两类约束**：①**物理一致性**（8 红线、道具台账、声音总量、时长闭合）②**用户在这次任务里明确点名的要求**。**机位、角度、景别、衣着一律不主动加条款** —— 「不做贴地/贴身低角度仰拍」「衣着不移位」「不走光」三条已于 2026-09-24 被用户逐条撤掉（全属过审自保，不是物理需要）；他什么时候提，什么时候写。

> 判断法：写一条约束前先问自己「**这条是物理需要，还是我为了过审自保？**」——后者一律删掉。

**自检必查（硬问句，三问缺一即漏）**：
- [ ] 我改写了用户原文里的**身体描写 / 衣着措辞 / 景别**吗？（例：把「锁骨下方」改成「前襟纽扣」＝降级，必须改回原文）
- [ ] 我加了用户**没点名**的自保条款吗？（例：主动补「内搭＋居家短裤」防走光、把「赤脚」换成「拖鞋」）
- [ ] 交付里我写了「大概率被拦 / 建议降级 / 要不要保守点」这类提醒吗？（**本铁律明令禁写**）

> **为什么容易漏**：拦截规律全部来自 **himg / hedit 图片侧（65535 API）**，而 **H3 是本地部署、无上游内容审核**（2026-10-04 用户：「h3是本地部署的 不会被拦截的 关于nsfw部分不用改写」）。两条链路不同，图片侧的拦截经验**一律不得回流进 H3 prompt**。

## ⚠️ 铁律 #5：方向锚 —— 镜头反向动词必须与主体前进方向**成对**写出（2026-09-25 用户抓出「赛车逆向」后定稿）

**现象（用户实测抓出）**：追逐/跟拍类镜头里出现了**车倒着开 / 逆向行驶**。根因不是镜头写错，而是**一句话里只有一个方向词，且那个方向词说的是镜头** —— H3 按动词分配运动，找不到「主体仍在向前」的对照项时，会把这个反向运动分派给画面里最显眼的主体。

**四件套（凡「镜头倒飞/后退/下潜/环绕 + 主体高速前进」的段子，缺一不可）**：

| # | 组件 | 反面（会逆向） | 正面（锁死方向） |
|---|---|---|---|
| 1 | **主体绝对方向锚**（独立成段，写在主体锁定之后） | 全篇不写车头朝哪 | 「全片 X 始终朝同一方向前进，车头朝向与开场参考图一致，任何镜头里都不得朝向相反方向」 |
| 2 | **成对写出**：镜头反向动词旁必须同时出现主体的前进动词 | 「镜头贴着水面后退」（只写镜头） | 「镜头贴着水面后退，**而 09 号车仍在全速向前疾驰**」 |
| 3 | **运镜句主语显性写「镜头」** | 「向外横扫到全侧跟拍」（主语易被读成主体） | 「**镜头**从车尾左后方向外侧横扫到全侧跟拍」 |
| 4 | **对手主体的同向性单独声明** | 「对手车斜切过来 / 先冲出并撞上来」（暗示迎面） | 「**在前方沿同一方向行驶的**对手车变道斜切过来」 |

**附加两条**：
- **锁相对队形，不锁画面绝对位置**：「A 居中、B 右前、C 左后，只做前后距离与左右车道的相对变化」✅；「B 在画面右侧、不左右换边」❌ —— 后者与「主体在高速移动」冲突时，模型会让主体原地或反向来满足位置约束。
- **180° 转向必须给过渡**：从「背影远离」切到「迎面冲来」时，必须显式写「镜头先从车尾经车身侧面滑到车头前方，再用后退完成正对，**转身过程中车始终向前、方向不变**」；缺这句模型会猜错 → 逆向。

**补强（2026-09-25 第二版 · 用户实测「正往前开、车头却成了倒着开」后升级）**：只加「方向锚 + 成对句」还不够，还要**换参照系 + 绑定头尾特征**——四条：

| # | 做错了会怎样 | 正确写法 |
|---|---|---|
| 1 | 把方向锚绑在「与参考图里的朝向一致」→ 镜头一绕到车头前方，模型为保持“与参考图一致”**让车转身** | **参照系换成道路/世界**：「道路向前延伸的方向就是车头方向；车沿道路向前推进，道路永远在车的正前方展开」——**不引用画面/参考图里的朝向** |
| 2 | 主体的两端外形相似 → 模型分不清头尾，把车头当车尾 → 画面表现就是“倒着开” | **头尾特征绑定方向**：「带橙色发光圆环的那一端是车尾，始终朝向车的后方（背离前进方向）；车头灯那一端始终朝向车前进方向，车头灯的光柱始终打在车前方尚未走过的路面上」 |
| 3 | 只写相对镜头语（“两侧雨林向后掠过”）→ 没有画面内矢量，模型自由发挥 | **给画面内位移向量**：「两侧的树木、护栏与路面标线从画面右前方连续流向左后方」 |
| 4 | 镜头反向动词与主体前进动词仍在同一句 → 模型把两者**平均化/串味** | **分句隔离**：镜头方向单独成句，主体方向单独成句，同一句内不出现相反方向动词 |

另：参考图是**低后视角**（画面里看到的是车尾）时，必须显式点明「参考图里看到的是车尾，车正在远离镜头向前行驶」，否则模型会把“车尾朝镜头”读成“车朝镜头开”。

**适用范围（2026-09-26 补 · 用户抓出「正往前走、然后变成往后走」）**：铁律 #5 **不限交通工具/追逐戏** —— **凡画面里有主体位移的镜头都适用**：走路 / 跑步 / 骑车 / 开车 / 游泳 / 飞行 / 人群移动。真人步行的三个额外高危点：

| # | 高危点 | 必须补的句子 |
|---|---|---|
| 1 | 只写「往前走」，没给画面内位移矢量 | 「路边的行道树与路灯从画面右前方连续流向左后方」（有矢量，模型才知道往哪走） |
| 2 | **半转身动作**（回眸 / 回头看 / 侧身 / 转头微笑） | 「她只转头与上身，脚下与身体朝向不变，继续朝原方向行进」——不写这句，H3 会让整个人转身往回走 |
| 3 | 镜头「跟随 / 后撤 / 拉开」与步行同镜 | 按成对句写：「镜头向后拉开，而她仍继续沿人行道向前走」 |

**自检必查**：写完任何有位移的片子，回到「交付格式 · 硬问句」逐条过「**主体行进方向有没有锚？**」那一问。

**与铁律 #4 的边界**：本条属于**物理一致性**（运动方向自洽），是 H3 侧保留的两类约束之一，不受「不主动加条款」限制；但它只写**方向关系**，不写机位/角度/景别。

## ⚠️ 铁律 #6：参考图只锚「身份」，不锁「首帧姿态与场景」（2026-10-27 用户抓出「为什么每片都从参考图那个姿势开始」）

**一句话：参考图定义「她是谁」，不定义「她在哪、摆什么姿势」。**

| 维度 | 参考图说了算（锚定） | 分镜说了算（自由调度） |
|---|---|---|
| 人 | 脸型、五官、妆容、发型、发饰、服装、配饰 | 站/坐/走/倚、朝向、手脚动作、表情 |
| 画面 | 色调、光线方向、画质基调、风格 | 取景、构图、景别、机位、镜头运动 |
| 环境 | 视觉气质（如"清新透亮的绿荫"） | 具体场景、道具、与环境的接触 |

- 官方保留关系里这叫 **`attribute_transfer`（属性迁移）**，不是 `fully_preserved`（整帧复制）。要换场换姿态就写 attribute_transfer 的措辞；**只有真要「视频首帧 = 这张图」时才写 `fully referenced`**。
- 锚句两种写法（别混用）：
  - ✅ 换场换姿态（口播默认）：`... at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is referenced for the subject's identity, wardrobe and color grading; the location, framing and body pose are newly staged.`
  - ⭕ 真要复刻首帧：`... <Picture 1> (from [Shot 1]) is fully referenced.`
- **口播/数字人类任务默认不复刻**。复刻会得到"一张会说话的图"：人站定、镜头锁死、只有嘴在动，真实感弱。
- 例外：参考图本身就是**界面/截图**且用户要求保留界面（直播录屏风），此时按铁律 #2 的文字三分类把界面写进「版式固定段」——但**人物姿态依旧可以不复刻**。

### 动作设计：像真人在说话，不像站着念稿

给动作一个**动机**（她本来在做什么，顺带开口），而不是"面向镜头张嘴"：

| 要素 | 怎么写 |
|---|---|
| 动机 | 别回耳后的头发 / 扶着树干 / 拂去肩头落叶 / 端起茶盏 / 翻账本 —— 说话是这个动作的自然延续 |
| 重心 | 重心在两脚之间换一次；站久了会换脚、身体轻微前倾或后靠 |
| 手势 | 只在关键处抬手，**做有内容的手势**（比数量、摊手、指向身侧），做完自然落下，不要全程比划 |
| 呼吸 | 句间有换气；强调处前半拍停顿、说完轻轻呼气 |
| 眼神 | 多数时候看镜头，偶尔短暂移向手边事物再收回；不要全程死盯 |
| 环境互动 | 发丝与衣摆持续被风带动、光斑在脸上移动、脚下踩过落叶 |
| 机位 | 段间推进/跟移/换景别（中景 → 近景），不要全程固定不动 |

**幅度红线**：不做大转身背对镜头、不做快速大幅摆动、手不遮挡脸——这些会让 H3 掉脸/形变。动作幅度取"看得出来但不抢戏"。

### 自检（写完必查）

- [ ] 我写了「起幅与参考图完全一致 / 保留参考图的构图与姿态」吗？（口播类出现即犯规）
- [ ] 开场动作有没有动机？还是"站着张嘴"？
- [ ] 全片有没有景别 / 机位 / 站位的变化？还是从头到尾一个固定中景？
- [ ] 换姿态之后，脸 / 服装 / 发饰的锚定句还在不在？

## 🎞️ 长视频模式（30 秒 – 1 分钟）· ComfyUI-H3-Continuum 适配

> **触发**：用户要「30 秒」「40 秒」「1 分钟」「长视频」「连续长镜头」「多段接得上」「Continuum」「ComfyUI」。
> **必读**：`references/continuum-longform.md`。本节只是入口，硬规则、模板、自检清单都在那份文件里。

### 三条不能违背的前提

1. **H3 单次生成上限 15 秒** → 30 秒以上必须**分段续拍**，不存在"一条 prompt 直接出 60 秒"。别向用户承诺这种能力。
2. **总时长 = `Chunks` × `Seconds per Chunk`** —— 先算数，再动笔。
3. **铁律 #0 仍然生效**：正文全中文；台词 / 歌词 / 画面内文字保留原语言。

### 默认配置（用户没指定时）

| 目标 | 用这个 | 说明 |
|---|---|---|
| 30 秒 | `4 × 8s` | 接缝少且单段可审，最平衡 |
| 60 秒 | `6 × 10s` | 起承转合，段落清晰 |

### 正确形态：`[Chunk N]` 分段头 + H3 三字段（2026-10-17 修正）

**长片的每一段就是一条完整的 H3 三段式 prompt，外面套 `[Chunk N]` 段头。两者共存，不是二选一。**

❌ 错误做法：把长片写成纯文本 `[0-10s]` 段落，丢掉三个字段（等于放弃官方字段权重，声音与画面分工全丢）。

✅ 正确骨架：

```text
[Chunk 1]
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
integrated_multimodal_description:
[Shot 1] ……
[Shot 2] At 00:04.000, the camera cuts to ……
overall_soundscape:
……
non_diegetic_music:
N/A

[Chunk 2]
integrated_multimodal_description:
[Shot 1] Continuation of Chunk 1. 承接第 1 段末尾：……
overall_soundscape:
……
non_diegetic_music:
N/A
```

### 六条硬规则（写错就整段失效）

| # | 规则 |
|---|---|
| 1 | `[Chunk N]` **独占一行**，N 从 1 连续；段间**空一行**。不独占一行 → 不被识别为段头，整份回退成 `Fixed`（诊断码 `H3C-P100`） |
| 2 | **三个字段每段都要闭合**，不能只在首段写；`integrated_multimodal_description:` 单独成行当行标 |
| 3 | 首帧锚句 `For the target video, at 0.00 seconds...` **只在 Chunk 1 写一次**，重复会被当作每段重设首帧 |
| 4 | Chunk 2+ 的 `[Shot 1]` 用 `Continuation of Chunk N.` 开头，**后面再接中文承接句**；只写这一句不够 |
| 5 | 每段最后一个 shot 末尾给**交接状态四件套**：位置 / 动作相位 / 运镜 / 环境，下一段开头接住 |
| 6 | 段内 `[Shot 1]` 不带时间戳，后续 `At MM:SS.mmm, the camera cuts to` 严格递增且不超段长 |

### 参考图规则

| # | 规则 |
|---|---|
| 1 | 用 `<Picture N>`（不是 `@R`）。**编号全片稳定**：六段同一套槽位，中途一张都不要关，否则编号集体错位 |
| 2 | 三种角色分开：首帧锚（只 Chunk 1）/ 人物权威（脸型发型服装）/ 场景与姿态 |
| 3 | 参考图互相冲突时：**人物设定图 > 合影 > 剧情图**；场景图里出现不一致的服装，必须写明「只取场景/姿态，服装以设定图为准」 |
| 4 | **复合图（上下分格、九宫格、白底四视图）必须先裁成单幅**，不要指望 prompt 里写"不采用分隔线"硬扛 |

### 语言策略

结构行（`[Chunk N]`、首帧锚句、`Continuation of Chunk N.`、三字段名）用**英文**，它们是格式标记；画面描述、镜头、声音、交接状态用**中文**。用户明确要整段英文时才全英文。

### 交付格式

三块，顺序固定：① 设置说明（Chunks / Seconds per Chunk / Total Length / Prompt Format / `<Picture N>` 槽位表）→ ② **一个只含 prompt、不含任何说明或自检的代码块**（六段都在里面，段间空行）→ ③ 代码块外补连续性台账 + 易踩的坑。

| 主要表现物 | 视频核心信息：人物、动物、物体、想象之物 | 一只小狗 |
| 场景空间 | 环境信息：标志性空间或幻想场景 | 公园 |
| 运动/变化 | 主体状态：静止/运动、环境转化 | 奔跑 |

**示例**：
1. 一只小狗在公园中奔跑
2. 一个女人打着伞在雨中的街头行走
3. 山谷中的一条小溪静静流淌

### 2. Prompt 精确公式（专业输出 / 精准控制）
> 适用：对镜头运动或画面呈现有明确需求

```
Prompt 精确公式 = 主要表现物 + 场景空间 + 运动 / 变化 + 镜头运动 + 美感氛围
```

| 要素 | 说明 |
|---|---|
| 镜头运动 | 推、拉、摇、移、升、降等，限定画面呈现方式 |
| 美感氛围 | 视觉风格、画面氛围感限定 |

**示例**：
1. 一对情侣坐在公园的长椅上交流，镜头维持固定拍摄情侣，画面色调偏暖，氛围温馨
2. 一只小羊在一片草地里低头吃草，镜头缓缓推进小羊，画面色调自然写实
3. 一个身穿西装的男人面色凝重地在面馆里吃面，镜头逐渐拉远展示面馆的吵闹环境，画面色调自然

**两条基本原则**：
- 更精确的表达 → 更准确的视频信息呈现
- 更丰富的表达 → 更好的视频生成效果

## 精准的美学控制

**核心洞察**：相同的基础 Prompt，通过不同的美感氛围控制可以呈现截然不同的效果。

| 阴郁系 | 温馨系 |
|---|---|
| 画面色调灰暗，色彩低饱和，氛围阴郁 | 画面呈现暖色调，色彩浓郁，氛围轻松惬意 |
| 画面色调灰暗，氛围阴郁 | 画面色调艳丽，氛围绚丽科幻 |
| 画面色调阴郁，色彩饱和度低 | 画面色调偏暖，画面氛围温馨 |
| 画面明暗对比强烈，色调灰暗，氛围紧张压抑 | 画面色彩呈现暖色，氛围惬意温馨 |

**用法**：基础 Prompt 写完 → 追加一句氛围限定（色调 + 饱和度 + 氛围词）。

### 🎨 高级风格描述法（2026-08-05 用户提供范例「@A贿赂上帝-」升级）

> 核心差距：**把氛围当"输入"（写"高级克制"让模型自由发挥）= 简单写法；把氛围当"输出"（先给足摄影/光学/材质技术手段，氛围自然生成）= 高级写法。**

**结构（4 层）**：
| 层 | 写什么 | 示例 |
|---|---|---|
| 1. 色彩/色调 | 具体色彩操作（褪色但不去色/低饱和/漂白） | 褪色但不去色的胶片色调 |
| 2. 光学/大气 | 光、雾、介质、扩散（空气中的雾感与光线扩散） | 克制的冷暖关系、雾感、光线扩散 |
| 3. 焦点/颗粒/动态 | 失焦、颗粒、拖影、动态范围（让画面"活"） | 轻微失焦、颗粒、运动拖影、有限动态范围 |
| 4. 氛围落点 | 1-2 个情绪词作收束（只收束，不作来源） | 安静、孤独、诗意、说不清哪里不对的旧电影质感 |

**范例（用户提供，直接可套）**：
```
风格：画面强调褪色但不去色的胶片色调、克制的冷暖关系、空气中的雾感与光线扩散，再配合轻微失焦、颗粒、运动拖影和有限动态范围，形成一种安静、孤独、诗意，又说不清哪里不对的旧电影质感。
```

**用法**：风格描述段 = 技术手段（1-3 层，尽量具体可执行）+ 氛围落点（第 4 层，只 1-2 个词）。禁止只写"高级/唯美/有质感"这种无手段的抽象词。

**❌ 简单写法 vs ✅ 高级写法**：
```
❌ 画面色调高级，氛围克制安静（无手段，模型自由发挥）
✅ 褪色胶片色调、克制冷暖对比、雾感光线扩散、轻微失焦与颗粒、运动拖影、有限动态范围，安静孤独诗意
```

### 🎨 风格速查库（2026-08-05 多风格扩展）

> ⚠️ **先判断，后查表——不是所有 prompt 都要套风格。** 风格库是配方表，不是万能模板。写 prompt 前先按下面的适用性判断决定"要不要风格段、用哪档"。
> ⚠️ **风格判断是上游决策：判断错 → 提示词不伦不类 → 整段重写。** 宁可多花 10 秒确认风格，不要写完才发现不对。

#### 风格判断决策流程（先跑这个，再查表）

**第一步：从题材提取风格关键词**（不是拍脑袋选风格，是从内容里长出来）

| 问自己 | 提取什么 | 例子 |
|---|---|---|
| 这是什么题材？ | 题材自带风格池 | 仙侠法宝→国风水墨/胶片国风；科技新品→北欧极简/赛博 |
| 核心情绪是什么？ | 情绪匹配风格调性 | 孤独寂灭→胶片/夜景；治愈温柔→小清新/梦幻 |
| 给谁看/什么用途？ | 用途约束风格强度 | 广告片→服务调性 1 主风格；情绪片→重风格 |
| 有没有参考片？ | 参考即答案 | 苹果发布会→北欧极简+影棚黑底 |

**第二步：风格与题材匹配度检查**（选完风格后 5 秒验证）

| 检查 | 问自己 |
|---|---|
| 题材冲突？ | 赛博朋克能配国风法宝吗？不能 → 换 |
| 情绪冲突？ | 暗黑哥特能拍治愈小清新吗？不能 → 换 |
| 风格强于内容？ | 文戏被风格压过台词吗？会 → 降档或去掉 |
| 风格服务于表达？ | 这个风格让"讲什么"更清楚了吗？没有 → 去掉 |

**第三步：写完后反向验证**（交付前必跑，防"写完才发现不伦不类"）

```
通读风格段 → 问自己："如果这是一个真人导演拍这条片子，他会用这个风格吗？"
→ 会 → 保留
→ 不会/犹豫 → 风格判断错了，回到第一步重新判断
```

**❌ 判断错误案例**（为什么错 + 怎么改）：
```
❌ 仙侠法宝广告用"赛博朋克"（霓虹+体积光）→ 题材是古风，风格是现代科技，违和
   ✅ 改"国风水墨/武侠"或"胶片国风"（墨色+云隙光+纸面颗粒）
❌ 文戏对话用"褪色胶片+运动拖影"→ 表演被压死，台词失真
   ✅ 改"轻雾+柔光"（克制档）
❌ 日系小清新空镜用"暗黑哥特"→ 风格与题材完全冲突
   ✅ 改"日系小清新"（高明度低饱和+通透空气感）
```

#### 风格适用性判断（视频类型 → 风格档位）

| 视频类型 | 风格段怎么用 | 例子 |
|---|---|---|
| **氛围/空镜/情绪片** | 风格最重，直接查表全套 | 日系小清新空镜、国风水墨山水 |
| **产品/广告片** | 风格服务于产品调性，选 1 个主风格即可 | 苹果发布会=北欧极简/赛博；国风法宝=水墨 |
| **武戏/动作片** | 风格只取"动态"层（拖影/动态模糊/颗粒），别加慢风格压节奏 | 武侠打斗=动态拖影+颗粒，不加水墨雾气 |
| **文戏/对话/剧情片** | **风格要克制**——过度风格化会压过表演和台词，默认自然写实，最多加轻颗粒/柔光 | 仙侠对话=轻雾+柔光，不加褪色胶片 |
| **纪实/生活流** | 不加风格段，真实自然为主 | 民生观察、日常片段 |

**三条铁律**：
1. **风格 ≠ 万能**：文戏/对话/纪实类不加浓风格，加了反而假
2. **风格要匹配题材**：赛博朋克配不了国风法宝，日系小清新配不了暗黑哥特——先定题材，再选风格
3. **同段提示词只能 1 个主风格**：混搭最多取两行各 1-2 个手段，且要兼容（黑底水墨×苹果极简 OK；褪色胶片×赛博霓虹冲突）

**❌ 套用反例**（把风格库当万能模板无脑复制）：
```
❌ 日系小清新空镜用"暗黑哥特"风格 → 风格与题材冲突，画面违和
❌ 文戏对话加"褪色胶片+运动拖影" → 表演被风格压死，台词失真
✅ 日系小清新空镜 → 查表"日系小清新"行全套
✅ 国风法宝广告 → 查表"国风水墨/武侠"行，或"北欧极简×水墨"兼容混搭
```

### 2.1 🚨 背景群演动态法则（2026-09-14 用户实测：背景人物被做成"雕像"）

> 痛点来源：用户实测 H3 生成群像片时，背景人物动不动、眼睛不眨、像假人/蜡像，画面失真。

**铁律：背景中出现的每一个人必须保持自然的生活化动态，不能静止不动、不能集体定格。**

**核心原则「70% 自然流动 + 少量点睛冷场」：**
- **默认所有背景人物都在"继续做自己手里的事"**——走路的人继续走、说话的人自然张嘴、交头接耳、低头看手机、弯腰取物、抬头张望；节奏自然、持续、低强度，不刻意停顿。
- **不为每个背景人物强行设计"被主角吸引"的小动作**——那是过度设计，反而假。多数人正常做自己的事，只有极个别（通常是主角视线方向或剧情需要的那一两个人）才被吸引/侧目，形成"主角是焦点、背景自然流动"的正确关系。
- **背景人物动态必须连贯流畅**：同一人从一镜到下一镜，动作状态延续（在走的人继续走、位置连续），不跳变、不瞬移、不集体扭头。
- **镜头越广、背景人物越多，越要写一句"人群自然流动、各自忙碌"的总括**，而不是逐个堆砌。

**写法模板（给每个含人群的分镜追加一句背景动态声明）：**
```text
画面后景的人群各自进行中的日常动作自然延续：有人边走边低头看手机、有人在交谈中抬手比划、有人望向别处，整体保持自然流动的市井/校园/街道状态，不被主角的出现中断，无人静止或定格。
```

**反例（用户实测会崩）：**
```text
❌ 只写"背景有几个人"或"路人惊艳回望"→ H3 把背景做成人形雕像，眼不眨、身不动
❌ 给每个路人塞一个"被打断"的抢戏小动作 → 过度设计，画面假、拥挤
✅ 默认人群自然忙碌流动 + 只让个别人被吸引 → 真实、有生活感、焦点清晰
```

#### 2.1b 🚨 I2V/首帧图生视频「撬动背景 4 式」（2026-09-14 用户实测：图生视频背景人物更容易静止）

> 痛点：I2V 下静态图被模型当**强锚点**。它优先让主体"动起来"，同时**尽量少改背景**以压制闪烁变形——结果背景人物姿势/位置被锁定、趋于静止。比文生更严重。

**原理口诀：图生视频里，"保持背景" = 维持原图 = 静止。要让背景动，必须给模型一个"改动清单"和改动的许可。**

**撬动背景 4 式（组合使用）：**

| 招式 | 做法 | 例句 | 为什么有效 |
|---|---|---|---|
| 1️⃣ 点名+给动作 | 明确写出"哪些背景人物动、怎么动" | ✅ 首帧中的背景乘客在视频开始后各自活动起来：后排一位乘客继续低头刷手机、手指在屏幕上滑动；车门旁一位男乘客侧身让出空位；角落一位乘客抬头望向窗外 | 给模型一个明确的"改动清单"，它才有理由去动背景 |
| 2️⃣ 用"延续/活动起来"，不用"保持" | "保持"=维持原图(静止)；"继续/活动起来"=时间在推进 | ✅ 首帧里静止的人群在镜头进入后自然活动起来，各自继续手头的事 ❌ 保持首帧背景人物的姿势 | 一个词决定模型是不是锁背景 |
| 3️⃣ 明确主角是唯一锚点 | 写死"背景是流动环境，不占锚定" | ✅ 本片唯一视觉锚点是她的动作；背景乘客为流动环境，不锁定其姿势与位置，允许自然运动 | 主动降低背景的锚权重 |
| 4️⃣ 显式许可小变形 | 明确"允许背景微动/轻微运动模糊"安抚模型 | ✅ 允许背景乘客自然的身体摆动与低头抬头，允许轻微运动模糊与动态不完美，不必保持像素级静止 | 模型不敢动背景怕闪烁变形，给了许可才敢动 |

**反例（默认=静止）：**
```text
❌ 背景保持原图状态。（I2V 下 = 全静止）
❌ 背景人群自然流动。（文生够用，但 I2V 下太模糊，模型无从下手）
✅ 点名 2-3 个背景乘客的具体动作 + "各自活动起来" + "唯一锚点是主角动作 + 允许背景微动"
```

**一句话铁律**：文生的背景动态靠"总括句"就够；**图生视频的背景动态必须"点名 2-3 个 + 活动起来 + 主角唯一锚 + 允许微动"四式齐上**，否则静态图会死死锁住背景。

### 🚨 极简剧本式 > 重型结构（2026-09-25 用户实测：「感觉反而不如原版效果好」）

**背景**：用户给了一条 9 句台词的咖啡馆对白戏原稿（中文剧本式 `近景，女人问："有房吗？"`，每句一镜）。助手按 7 段骨架 + 台词三件套 + 字数档位把它重写成「合规重型版」（人物段 + 朗读规则段 + 单独【语速与节奏】段 + 表演与语气表 + 12 条负面声明 + 英文精密切点 + 10 镜），用户判定**不如原版**。

**根因 4 条**：①塞进 8 个非分镜段 → **稀释分镜描述的权重**（同「锚权重」机制，决定画面的是分镜）；②单列语速段 + 负面声明写「不出现拖长音、慢语速」→ **双重加速指令** → 全程赶读、气口僵硬、表演消失；③每镜塞满表演细节（手指转杯沿/交叠收紧/下巴抬起）→ **抢走模型自己的表演空间**，变成机械执行清单；④中文`近景/特写`脚本改成英文 `At 00:00.900, the camera cuts to` 精密切点并加镜 → 结构越复杂越偏离 H3 舒适区。

**极简剧本式骨架（对白戏默认）**：`一句画质/时长/场景总声明` → `一句人物设定（形象 + 音色）` → `一句朗读规则` → `逐句分镜（中文景别标注 + 引号台词 + 每镜 1 个微动作）` → `一句收尾（无字幕 + 轴线同侧）`。**不单列语速段、不列表格、不铺表演清单**；语气压成人物段末尾几个字（句尾下压 / 话少短促）；台词三件套照常满足（音色在人物段、语气在人物段小注、格式 = 引号 + 朗读规则声明）。

**🚨 对白戏三件必写（2026-09-27 用户抓出「台词可数少了 + 说完话没强调闭嘴 + 乱码语音」）**：
1. **台词只数落在字数档内（不过少也不过满）**：15s 正常对话 **30-35 字**；**低于下限 = 空档期间 H3 自己补人声（乱码语音的来源）**；高于上限 = 吞字。
2. **每句台词后面都必须写闭嘴落点**：照拄 skill 中文正反打示例的现成措辞——「**话音落下嘴唇轻合**」/「说完闭上嘴、不再出声」，**每一镜都要有**，不是只写前两句。
3. **默认补对话兜底句（抄原文，不要自造）**：「**全程除上述 `<d>[中文]</d>` 标签内的台词之外，无任何旁白、画外音或额外人声，人物不发出其他语音。**」（见「🚨 听觉/心理动词也会被配音」第 4 条；机制：H3 默认会自行编台词，张嘴/吸气/抽泣 = “这里有语音”信号）。
> 另：分镜里写呼吸只写视觉结果（「肩膀随呼吸轻微起伏」✅；“她吸了一口气”❌ 听觉动词会被配音）。

**物理片同样适用减重（2026-09-26 补）**：多镜头物理片**不需要把每个门禁都写成一个段**——只保留题材真正命中的段（段数按需，**12-14 段为默认，16 段是上限**：无背景群演就不写「背景群演动态」段，无台词就不写台词表/语气表，无画面内文字就不写「文字规则」段）。判断法：**这一段删掉，画面会不会变差？不会就删。**

**边界**：①只适用于**短剧对白戏/文戏**；九宫格 i2va、开发板、赛车片等多镜头物理片仍需完整骨架（那些片子的风险在物理不在权重）。②台词超字数档位时**优先减字或换气口**，不要靠「加一段语速说明」硬塞。

**🚨 极简 ≠ 越短越好（2026-09-26 用户纠正：「极简不是在这个方向，能完整表达意图，不啰嗦，这才叫极简」）**：减重**只减冗余，不减信息**。下列 7 项**一个都不能省**，省了就“错误百出”：

| # | 必须保留的信息 | 省掉的后果 |
|---|---|---|
| 1 | **机位与轴线**（两人各在画面哪侧、朝哪边、机位在连线同侧、视线不翻转） | 两人朝向乱、跟镜反方向 |
| 2 | **每镜的景别 + 镜头运动**（近景固定 / 特写极缓推近…） | 镜头乱动、景别乱跳 |
| 3 | **空间与站位**（谁在哪、距离多少） | 空间漂移、人物瞬移 |
| 4 | **道具台账**（每件道具从谁手里到哪去） | 道具凭空出现/消失 |
| 5 | **声音来源与数量**（环境音 ≤2、全片 ≤4） | 声音乱混 |
| 6 | **光线**（主光方向 + 补光 + 反光） | 光线跳变、脏光 |
| 7 | **文字规则 + 这次题材真会踩的负面声明**（通用免责合并为 1 条） | 出字幕、出多余文字 |

**只减这四类**：①同一件事写两遍的重复说明（镜位纪律里写过的，别在逐镜再写一遍）②通用免责合并成一句（水印/失焦/色偏合一）③题材没命中的整段（无群演/无台词/无画面文字时，对应段直接不写）④空话（“氛围感拉满”这类零信息量的话）。

### 分镜数量决策矩阵（2026-08-04 用户提出：按类型×情绪选，不是按时长一刀切）

> 分镜数量 = **类型（内容密度）× 情绪（节奏需求）** 的函数，不是时长的函数。
> 15 秒打斗戏 5-8 镜，15 秒对话戏可能只要 3-4 镜——密度完全不同。
> 快速指南：先定类型找基准段数，再用情绪修正（越紧张越密、越平静越疏）。

#### 第一步：按类型定基准段数（15秒参考）

| 类型 | 15秒基准段数 | 每镜时长 | 节奏特征 |
|---|---|---|---|
| 打斗/动作/追逐 | 6-8 段 | 1.5-2.5s | 快切，攻防链，每镜一个动作节拍 |
| 悬疑/惊悚/反转 | 5-6 段 | 2.5-3s | 中速切，信息逐镜释放，留悬念 |
| 对话/文戏/情感 | 3-4 段 | 3.5-5s | 长镜，正反打，情绪累积 |
| 氛围/空镜/情绪片 | 2-3 段 | 5-7s | 极缓推/拉，靠画面和声音撑 |

#### 第二步：用情绪修正段数

| 情绪强度 | 修正 | 说明 |
|---|---|---|
| 高张力（爆发/愤怒/惊恐） | 段数 +1~2 | 情绪点单独给镜，动作切碎 |
| 中张力（紧张/压抑/对峙） | 基准不变 | 正常切，留呼吸 |
| 低张力（平静/悲伤/沉思） | 段数 -1~2 | 长镜 + 留白，情绪靠表演细节 |

#### 第三步：时长缩放

```
基准表是 15 秒。其他时长按比例缩放后取整：
8-10 秒 → 基准段数 × 0.6
20-30 秒 → 基准段数 × 1.5~2（分两段式结构，见阶段化模板）
```

#### 示例

- 15 秒打斗：类型=动作(6-8) + 高张力(+2) → **8 镜**，每镜 ~2s 快切
- 15 秒对峙对话：类型=文戏(3-4) + 中张力(基准) → **4 镜**，正反打+反应镜
- 15 秒悲伤独白：类型=氛围(2-3) + 低张力(-1) → **2-3 镜**，长镜+特写留白

> ⚠️ **切点时间必须覆盖 100% 时长**：段数定好后，第一镜不写时间戳，后续按 `At MM:SS.mmm` 严格递增排满（如 8 镜 15 秒 → 切点约 00:01.875、00:03.750...）。

### 🚨 动作/追逐类场景：空间关系锁定（2026-08-04 用户实测发现）

**问题**：追逃/追逐类 prompt 如果不锁定空间关系，模型会**翻转角色位置**（恶魔跑到女孩前面），且画面单调。

**核心原则**：锁**运动关系**（谁在前、谁在后），不锁**屏幕坐标**（谁在左、谁在右）。关系稳 + 机位多变 = 电影感；位置固定不变 = 呆板像横版游戏。

**手法**：
1. **每镜重申空间关系**——"女孩在前方、恶魔在后方"逐镜重复，模型不会丢
2. **固定相对位置不换边**——确立"女孩向前逃、恶魔从后追"后绝不翻转，换机位但关系不变
3. **距离量化**——十米 → 五米 → 两米 → 一米，逐镜缩短让模型感知"逼近"
4. **5 种机位交替**（关系不变、画面多变）：
   - **纵深跟拍**：被追者背对镜头在前景，追击者在后景放大逼近
   - **反打**：被追者朝镜头跑来，追击者在她身后同框
   - **侧面横移**：两人平行跑，被追者在前追击者在后
   - **低角度仰拍/俯拍**：两人先后掠过镜头（纵深穿过），关系不变
   - **追击者主观视角**：直接代入追击者视线，利爪/手探向镜头
5. **进入画面时刻标记**——追击者"从画面边缘冲入/浮现"，防止凭空出现
6. **结尾可黑场钩子**——追击者利爪探向镜头瞬间黑场，高潮戛然而止方便接下一段

**示例骨架**（追逃 8 镜）：
```text

[Shot 2] At 00:02.000, the camera cuts to 面部特写。被追者目光越过肩头锁死身后，身体微退。
[Shot 3] At 00:04.000, the camera cuts to 纵深跟拍，低机位。被追者背对镜头向前狂奔，追击者在后景中央猛然扑来，逐渐放大。
[Shot 4] At 00:06.000, the camera cuts to 反打俯拍。被追者朝镜头跑来，追击者在她身后紧追，距离约五米。
[Shot 5] At 00:08.000, the camera cuts to 侧面横移。两人平行向画面右侧奔跑，被追者在前，追击者紧随。

[2..N-1] 分镜头（每镜一段，固定公式）
    "镜头{K}（{起止秒}，{景别}，{镜头运动}）：{人物代号+动作细节}，{情绪细节}，{台词用{}包裹}。{镜头运动的时序描述}"

### 🎭 文戏核心技法（2026-08-04 吸收自第三方导演模板，经用户评估保留）

> 来源：用户提供的「多功能提示词模版15S.md」文戏流程。只吸收核心框架，不吸收具体数值（第三方数值未经验证）。

#### 1. 文戏 = 一次清楚的关系变化

15 秒文戏只承载**一个**关系转折：识破 / 承认 / 拒绝 / 原谅 / 背叛 / 离开 / 决定 / 失去。
动笔前先确定"关系在开始和结束时分别是什么"，再把最关键转折集中在 15 秒内。

#### 2. 核心证据/道具触发

选择一个**能被摄影机看懂的道具或证据**触发关系变化（照片/信/车钥匙/戒指/转账记录）——比"突然吵架"更有画面依据。

#### 3. 切镜不由台词触发（专业导演思维）

每次切镜由**新信息、说话权变化、视线目标变化、道具状态变化、人物距离变化或行动决定**触发——**不要每句台词机械正反打**。

#### 4. 表演信号 2-3 个协同（不写"他很悲伤"）

中近景/特写只保留 2-3 个协同表演信号：目光停顿、呼吸变化、未完成的手部动作、身体重心变化。微表情必须前后连续，抽象情绪词禁止。

#### 5. 结尾留余波（精神采纳，不锁数值）

结尾保留一小段呈现**行为后果或表情余波**——最后一秒继续提供新的情绪信息（如金句落地后，对方的神情/动作反应）。

**文戏结构速查**：建立关系与空间 → 证据出现 → 对方回应 → 主角消化 → 决定 → 行为结果 → 情绪余波。

### 人物设定模块（2026-08-03 用户建议新增，含声音扩展版）

> **触发条件**：多镜头连续、角色反复出现的短剧/剧情类视频，必须加人物设定段；单镜头氛围片可省略。

**为什么需要**：外观嵌在分镜头里，多镜头时模型容易"每镜换装"，角色一致性崩。用代号提前锁定 → 分镜头只引用代号，不再重复描述。

### 🎙️ 音色适配指南（2026-08-03 用户强调：不能遗漏，必须给角色适配适合的音色）

> **原则**：音色是角色的"声音外貌"，必须与**身份、年龄、性格、情绪状态**匹配。选错音色 = 角色人设崩塌（如冷面师尊用少年音、萌妹用烟嗓）。

**按角色类型选音色（速查表）**：

| 角色类型 | 适配音色 | 语调/语速 | 示例写法 |
|---|---|---|---|
| 少年/青年男主 | 温润清亮、带少年气 | 语速平缓→激动时拔高 | 声音温润清亮，语速平缓，惯用敬语 |
| 中年男性（掌权者/师尊/老板） | 低沉浑厚 | 语速极慢，无情绪起伏 | 声音低沉浑厚，语速极慢，无情绪起伏 |
| 反派/冷面角色 | 沙哑低沉、气声重 | 句尾下压，压迫感 | 声音沙哑低沉，气声重，句尾习惯性下压 |
| 女主/温柔系 | 清甜柔和、气息绵长 | 语速偏慢，尾音轻 | 声音清甜柔和，语速偏慢，尾音轻轻上扬 |
| 御姐/精英女性 | 干净利落、中音区 | 语速偏快，短句多 | 声音干净利落，中音区，语速偏快 |
| 老者/世外高人 | 苍老沙哑、气音 | 缓慢，句间停顿长 | 声音苍老沙哑，气音明显，句间停顿长 |
| 孩童 | 明亮清脆 | 语速快，情绪外放 | 声音明亮清脆，语速快，情绪外放 |
| 机械/AI/非人 | 电子合成质感、无感情 | 匀速，无停顿 | 声音带电子合成质感，无情感起伏，匀速 |

**选音色的 4 步法**：
1. 定身份 → 选年龄段音区（少年/中年/老者）
2. 定性格 → 定语调底色（沉稳/轻快/压迫/温柔）
3. 定关系 → 定对谁说话的方式（对师尊用敬语，对下属用命令式）
4. 定情绪变化 → 定每镜的语气标注（声音微颤/拔高/压低）

**反面教材（会导致变声/出戏）**：
- ❌ 只写台词不写音色 → 模型随机分配，多镜头变声
- ❌ 所有角色同一音色模板 → 分不清谁在说话
- ❌ 音色与身份冲突（20岁少侠用老年烟嗓）

### 🗣️ 语气标注系统（2026-08-03 用户补充：音色之外还必须有语气描述）

> **核心区分**：**音色 = 角色的恒定声音特征**（贯穿全片不变）；**语气 = 每句台词的瞬时情绪状态**（逐镜变化）。
> 音色在人物设定段锁定一次；语气在**每个分镜头的台词处**单独标注。两者缺一不可——有音色无语气 = 机器人念稿；有语气无音色 = 变声。

**语气标注公式**：`以{语气}的语气/声音 {台词}` 或 `{台词}（{语气}）`（普通模式；**全参考模式把 `{台词}` 换成 `<d>[中文] ...</d>`**，语气描述放 `<d>` 前）

> ⚠️ **2026-10-04 起（短剧对白戏一律用）**：改用「🚨 台词标签固定版式」——`S1 林婉台词（轻蔑、句尾下压）：` 独立成行 + `<d>[中文] …</d>` 另起一行 + `随后嘴唇轻合，…`。**带「说」的内联引导句禁用**。

**语气速查表（按情绪 8 类）**：

| 情绪类 | 语气词 | 示例写法 |
|---|---|---|
| 平静 | 平淡、淡然、不紧不慢 | 以平淡的语气开口 {知道} |
| 紧张 | 微颤、干涩、发紧 | 声音微颤，开口 {徒儿有秘密} |
| 惊讶 | 拔高、倒吸一口气、急切 | 嗓音拔高追问 {您怎会知晓} |
| 愤怒 | 压低、咬牙、一字一顿 | 语气压得极低，一字一顿 {你再说一遍} |
| 威胁 | 冷冽、气声、句尾下压 | 声音冷冽，句尾下压 {别逼我} |
| 温柔 | 放软、尾音上扬、轻声 | 语气放软，尾音轻轻上扬 {我等你} |
| 悲伤 | 哽咽、带哭腔、气息断 | 声音哽咽，带哭腔 {我回不去了} |
| 嘲讽 | 拖长、阴阳怪气、轻笑 | 语气拖长，带着轻笑 {就这？} |

**语气变化的 3 条规则**：
1. **同一角色语气可随剧情变**——情绪曲线驱动（轻松→惊愕→对峙），每镜标注变化
2. **每镜至少标 1 处语气**——无标注的台词模型自由发挥，情绪会平
3. **语气与动作/表情联动**——语气标注要跟"瞳孔微缩""指尖收紧"这些视觉细节配套，声画一致

**示例（台词 + 音色 + 语气三段式）**：
```
人物设定：...声音低沉浑厚、语速极慢、无情绪起伏（音色-恒定）
镜头2：师父指尖轻捻佛珠，以低沉平缓的嗓音开口 {知道}（语气-平静）
镜头4：师父眉目平和，语气平静 {穿越设定就是我加的}（语气-平静，与镜头2呼应）
```

**分镜头台词写法**：台词用 `{}` 包裹，语气用括号紧跟标注，或直接用"以XX的语气说道"。

> ⚠️ **台词合规三件套（缺一不可）**：只要 prompt 里有台词，**无论几镜、哪怕只有两三句**，必须同时给：
> 1. **格式**——图生/文生普通模式 `{}`；多素材全参考模式 `<d>[中文] 原文</d>`
> 2. **音色锁定**——人物设定段里写明声音（音色+语调+语速+说话习惯），H3 是原生双声道，不给音色就变声
> 3. **语气标注**——每句台词前/后跟语气（`以轻快的语气说 {}` / `{}（温柔）`），无标注 = 情绪平
>
> **实测纠错（2026-09-17）**：I2VA 生活九宫格只写了裸台词 `{"今天跑远一点。"}`，漏掉**音色**与**语气**两项 → 不合规。修正 = 补人物设定段（清甜柔和/语速偏慢/尾音上扬）+ 每句标语气（轻快期待/懒散放松/温柔尾音上扬）。
> **附加物理规则**：角色戴头盔/口罩/氧气面罩的镜头**不开口**，台词只落在能自然发声的镜头（避免"戴全盔清晰说话"的失真）。
>
> ⚠️ **2026-10-04 更新（优先级最高，用户实测定稿）**：下面这套「独立台词表 + 表演参考块 + 念出第 N 句台词」的**四步修法已被「🚨 台词标签固定版式」取代**——同一句台词出现在多处（表/块/镜）正是「台词混乱」的根因。台词一律内联在所属镜头里，用「delivery 一行 → `<d>` 一行 → 收尾动作一行」的三行块表示。下方内容**仅保留**外部素材台词进 prompt 前的清洗部分（标点标准化 / `[unclear]`）。
>
> ⚠️ **台词与语气必须拆成两张表（2026-09-18 实测定稿，用户认定"以后可以用"）**：H3 会把引号台词**后面的语气说明当成台词念出来**（实测：「各位好，我现在在泰山登山步道上。」**语气平稳，像开场交代位置** ← 后半句被念进了音轨）。四步修法：
> 1. **台词表**——只放引号/`{}` 包裹的原文，逐句编号（第 1 句、第 2 句……），一句一行；**表内不出现任何说明性文字**。
> 2. **表演与语气表**——单列一块，块首标「仅作表演提示，**一律不朗读**」，逐句对应（第 1 句：平稳放松，像开场交代位置；第 2 句：「多了不少」四字略加重……）。
> 3. **镜头动作句不贴引号**——写成「开口**念出第 1 句台词**」；禁写「说：『原文』，语气平稳」——**引号后紧跟中文说明 = 必被念出**。
> 4. **两处兜底声明**——开头加「朗读规则（最高优先级）：全片只有「」内的文字会被念出，其余都是制作说明」；结尾负面声明再竖一次（不念语气表/镜位/时间码/画面小字）。
>
> 画面里已存在的图形文字（台标、角标、字幕条、画面小字）同样不朗读，并要在固定段里声明其保持原位原文。
```
✅ 语气标注：徒弟声音微颤，开口 {师父，徒儿有个秘密}
✅ 音色引用：陈队以低沉平稳的嗓音说 {苏晴，我姓陈}
```

**完整示例（增强版补人物设定+声音段后）**：

人物设定：徒弟，仙门弟子，二十出头，清瘦挺拔，眉目清朗，束发高髻，身着月白棉麻道袍宽袖，腰间一枚青玉坠，声音温润清亮、语速平缓，惯用敬语。师父，仙门掌门，中年，身姿端凝，面容冷峻，束发戴玄玉冠，身着玄色锦袍，指尖常捻一串紫檀佛珠，声音低沉浑厚、语速极慢、无情绪起伏。

## ⚙️ 官方工程化规范（HuggingFace docs 精华，2026-08-03 学习）

> 完整版见 `references/h3-official-prompt-spec.md`。官方 prompt 是**英文结构化格式**，比中文模板更严谨。中文模板用于快速创作，官方规范用于精细控制/批量生产。

### 任务类型（先判断用哪个）
T2VA（纯文生）/ I2VA（首帧图生）/ FL2VA（首尾帧）/ L2VA（尾帧）/ Ref（多素材全参考）

### base 文档关键规范（T2VA/I2VA/FL2VA/L2VA，2026-08-04 补充）

> 来源：`docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md`（HuggingFace MiniMax-H3 官方文档）。

#### 最终 prompt 三段结构（普通任务）

```text
<任务对应的参考图对齐指令>（I2VA/FL2VA/L2VA 才有，T2VA 没有）

integrated_multimodal_description: [Shot 1] ...（主字段：画面/动作/镜头/说话人/台词/剧情声音）

overall_soundscape: ...（环境音+物理动作音+非语言人声，1-4 句连续段落）

non_diegetic_music: ...（BGM，1-3 句）
```

> ⚠️ **字段名区分**：普通任务（T2VA/I2VA/FL2VA/L2VA）主字段 = `integrated_multimodal_description`；**全参考模式（Ref）= `detailed_description`**（见上文 ref 章节）。两者都是"按时间线逐镜头描述"，只是任务模式不同字段名不同。

#### I2VA / FL2VA / L2VA 首帧指令行（必写！第一行）

```text
I2VA（图生）：For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

FL2VA（首尾帧）：How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.

L2VA（尾帧）：How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

指令行后空一行，再写三个核心字段。

#### 🚨 资产图（角色设定表）作 I2V 角色参考 vs 场景首帧（2026-09-11 用户纠正）

**资产图（三视图/四格/LOOKBOOK 角色设定表）可以不必单独另出场景首帧，直接作 `<Picture 1>` 的角色身份参考**——它的作用是锁角色形象（脸/发型/服装/身材），画面（场景）由文字描述生成。此时首帧行要写成"角色身份参考"而非"画面首帧"，并显式声明不沿用资产图的排版与背景：

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is the visual reference for character identity.
...本片以【角色资产表】为角色形象基准：图中角色的脸型、发型、服装、身材全程保留、不换脸不改造型；画面整体为全新场景，由文字描述生成，不沿用资产表的排版与纯白背景。
```

**区分铁律**：
- 资产图**只锁角色身份** → 首帧行写 `is the visual reference for character identity`，文字负责场景，回纹/表格排版不进画面
- 单一场景图**作为视频第一帧** → 才写 `is fully referenced`（严格首帧锚定，画面就是这张图）

**⚠️ 但你 compaij 节点如果要求参考图必须就是画面首帧**（图即画面本身），那仍需单独出场景首帧——此时若角色含白丝/超短裙+路人惊艳组合，先降级穿搭（白丝→普通长袜/到脚踝袜），否则 himg 后端 502 必拦（与"湿身+深V+蕾丝"同类高拦截区）。

#### 🚨 续集/衔接集 = 一条完整全新的 15s prompt（2026-09-11 用户纠正）

用户说"接着上一集/再来一段衔接"时，指的是**一条独立的、完整的 15s 新剧情**，不是在上一条末尾追加一个分镜。写法要点：
1. **新开一条完整 5 镜 prompt**，起止时间照常 0→15s，不沿旧结尾硬塞分镜
2. **衔接点只在第一镜体现**：[Shot 1] 从上一集结尾的状态/动作延续起步（如上一集收尾"边吃烧饼走向教室"，本集 Shot 1 从"走进教学楼继续边吃"无缝续接，不重拍收尾）
3. **道具跨集延续**：上一集引入且未用完的道具（烧饼/斜挎包/刀）本集全程在场、因果一致——保留"新增道具"声明，不凭空消失

#### 各关键帧模式推荐结构（2026-08-06 吸收自官方 MiniMax-AI/MiniMax-H3 skills/h3-prompt-writing/references/base-en.txt §3）

> 官方指南为三种关键帧模式给出**推荐写作结构**（不是固定模板，是分镜组织顺序），三种模式写法不同：

| 模式 | 推荐结构 | 要点 |
|---|---|---|
| **I2VA** | `first-frame anchor → action onset → continuous development → result or reaction`（首帧锚定 → 动作启动 → 连续发展 → 结果/反应） | 先锁定首帧的风格/主体/构图/场景锚点，再写后续动作 |
| **FL2VA** | `first-frame state → observable intermediate changes → progressively narrowing differences → last-frame state`（首帧状态 → 可观察中间变化 → 差异逐渐收窄 → 尾帧状态） | **⚠️ 官方明确 FL2VA 通常用单镜头**（"FL2VA generally favors a single shot so the model can interpolate continuously"）——多镜头只在用户明确指定时才用；正文写的是**连接两帧的运动路径**，不是重复描述两张静态图 |
| **L2VA** | `plausible preceding state → explicit action and transition path → gradual convergence in the final shot → last-frame landing`（推断合理前态 → 明确动作与过渡路径 → 末镜逐渐收敛 → 尾帧落地） | `<Picture 1>` 是**末镜**的尾帧（不属于 Shot 1）；从用户意图+尾帧反推一个合理前态，再描述画面如何一步步落到参考图 |

**写法要点**：
- L2VA 是 skill 之前的缺口（只有指令行没有分镜写法）——**写尾帧任务时，正文=「前态 → 过渡路径 → 逐步逼近 → 落地」四段链**，最终构图/光线/道具状态必须明确落在参考图
- FL2VA 单镜头偏好与「15s 短剧多镜」场景不同：FL2VA 是首尾帧插值任务，单镜最稳；多段短剧用 I2VA 首帧/Ref 多素材更合适
- 分镜内不重复描述两张静态图内容（图锁定的），只写"怎么从 A 到 B"的运动路径

##### 屏幕文字位置规范（2026-08-05 用户实测：文字位置易错乱）

**问题**：只写"屏幕浮现 XX"不锁位置，模型自由发挥 → 文字乱跳/叠字/位置错乱。

**铁律：每条屏幕文字必须写明位置**（画面上方/中央/下方/左上角/右上角等），同段内位置稳定不漂移，同一镜内多行文字按"主标→副标"分层写位置：

```text
✅ 屏幕上方浮现白色纤细大字 "玄黄刀"，下方偏小字 "先天至宝"（位置分层明确）
✅ 画面中央偏上出现金属浮雕大字 "开天"（位置锁定）
❌ 屏幕浮现 "玄黄刀"（无位置，模型乱放）
```

**多行文字固定模板**（产品片/广告片常用）：
- 主标：画面上方 1/3 处，横贯通栏，最大字号
- 副标：主标下方，字号为主标 1/3-1/2
- 标签/价格：画面右下角或中央偏下，小字
- 结束标语：画面中央，全屏大字，最后 2 秒

**文字出现时机**：写明"淡入/浮现/打出"时机，避免全程悬挂（"第12秒画面中央打出标语 XX"）。

##### ⚠️ I2VA 里三类文字必须分开处理（2026-09-18 用户抓出遗漏）

带参考图的 i2va 任务，**不能一句"全片不出现任何文字"一刀切**——那句话会把参考图里本来就有的**场景实体文字**也一起禁掉（模型会当噪点抹掉或画糊），直接违反铁律 #2。三类分开写：

| 类型 | 例子 | 处理 |
|---|---|---|
| ① **场景实体文字** | 招牌、导视牌、匾额、门牌、书页、包装、服饰上的字 | **逐字抄进 prompt + 要求与参考图一致 + 保持原位原文原清晰度**（只删 `♡` 与装饰标点）。写在与"人物设定"同级的独立段里 |
| ② **界面/叠加层文字** | 手机 UI（状态栏/日期栏/相册工具栏/播放器控件）、电视角标（台标/字幕条/跑马灯） | 按场景定：**要保留的**（电视新闻帧类）→ 进"版式固定段"逐条列；**要排除的**（相册截图类做视频时必须去掉 UI）→ 才写进负面声明 |
| ③ **参考图自带的小角标** | 九宫格每格里的时间戳、缩略图水印、截图边框处的小字 | **一律排除**，写进负面声明 |

自检加一问：**参考图里的字，我是不是分完类了？** 该留的一个字都没漏、该去的没多写。

##### 屏幕文字标点规范（2026-08-05 用户强调）

**铁律：屏幕文字原则上不用标点符号**——句号/逗号/冒号/顿号在屏幕上难看且易渲染错乱。例外：**感叹号**可用于表达情绪（"真不要脸！"）。**词语之间用空格间隔**。

```text
✅ "开天" "辟地" "斩道"（三个词，无标点）
✅ "一刀出 万法灭"（词间用空格，不用逗号）
✅ "玄黄刀 一刀开天"（空格间隔，无句号）
✅ "一柄难求"（无标点）
✅ "真不要脸！"（感叹号表情绪，允许）
❌ "开天。" "辟地。" "斩道。"（句号是噪音）
❌ "一刀出，万法灭"（逗号易渲染错乱，改空格）
❌ "玄黄刀。一刀开天。"（句号易乱，改空格）
```

**检查**：交付前扫描所有英文双引号内的文字，删掉句号/逗号/冒号/顿号（保留感叹号），词间改空格。

##### 字体风格匹配题材（2026-08-05 用户强调：字体也要有设计感）

**铁律：字体风格必须匹配题材**——字体是设计语言的一部分，跟画面一样讲究"适配"。题材/情绪决定字体，不是默认纤细白字（苹果风）就完事。
| 题材 | 字体风格 | 写法示例 |
|---|---|---|
| **古风/仙侠/武侠** | 毛笔书法字（笔锋/飞白/墨迹）、可加碑刻金石感、印章元素 | 古风毛笔书法大字，笔锋遒劲，带飞白墨迹 |
| **科技/数码/未来** | 无衬线细字、等宽字、几何字 | 无衬线超细字体，现代科技感 |
| **日系小清新** | 手写体/圆体，轻盈 | 圆润手写字体，清新轻盈 |
| **国风水墨** | 行书/草书 + 宣纸/印章 | 行书书法大字，如墨落宣纸，落款朱红印章 |
| **赛博朋克** | 故障风/霓虹字效 | 霓虹发光字，电子故障扭曲效果 |
| **暗黑/哥特** | 衬线古典字、尖角字 | 古典衬线字体，雕花质感 |

**材质/质感也匹配**（文字物理材质化技法的延伸）：
- 古风 = 墨迹晕染/宣纸底/鎏金烫金/碑刻金石
- 科技 = 玻璃/金属/发光
- 赛博 = 霓虹/故障/扫描线

```text
✅ 玄黄刀广告：主标"玄黄刀"用古风毛笔书法大字，笔锋遒劲带飞白，鎏金烫金质感；副标"先天至宝"同款书法小字；"开天 辟地 斩道"如碑刻大字带金石气；标签"一柄难求"落朱红印章式小字。
❌ 玄黄刀广告：白色纤细大字"玄黄刀"（苹果风字体配仙侠题材 = 设计脱节）
```

**检查**：写完屏幕文字后问"这个题材配这种字体对吗？"——古风配纤细白字、科技配毛笔字 = 不伦不类，重写。

##### 🎨 整体设计语言统一（2026-08-05 用户强调：字体风格和设计要与题材统一）

**铁律：不只是字体，整条片子的视觉设计语言必须统一到题材**——布光、色彩、质感、字体、场景道具，全部出自同一个设计体系，不能混搭。

**反面案例（设计语言分裂）**：
```
❌ 仙侠法宝 + 苹果发布会冷白轮廓光 + 现代影棚 + 古风毛笔字 = 分裂
   （画面是"科技极简"，字体是"东方古典"，两个体系打架）
```

**正面做法：先定"设计体系"，再让每个元素对齐**：

| 题材 | 设计体系 | 布光/色彩 | 质感 | 字体 |
|---|---|---|---|---|
| **古风/仙侠** | 东方高级感 | 玄金暗调、烛光/灵光、水墨留白 | 鎏金/金石/宣纸/墨迹 | 毛笔书法、碑刻、印章 |
| **科技/数码** | 现代极简 | 冷白硬光、纯黑背景、玻璃反射 | 金属/玻璃/发光 | 无衬线细字 |
| **赛博朋克** | 霓虹废土 | 霓虹彩色光、雾气、强对比 | 故障/扫描线/金属锈蚀 | 霓虹发光、故障字 |
| **日系小清新** | 通透治愈 | 自然光、高明度、柔光 | 棉麻/木质/轻盈 | 手写体、圆体 |

**统一性检查**（交付前逐项问）：
1. 布光是否出自该体系？（古风 = 玄金暗调 + 灵光，不是冷白影棚）
2. 质感是否出自该体系？（古风 = 鎏金/金石/宣纸，不是金属浮雕）
3. 字体是否出自该体系？（古风 = 书法/碑刻/印章，不是无衬线）
4. 色彩是否出自该体系？（古风 = 玄/金/朱，不是纯黑白灰）
5. 场景道具是否出自该体系？（古风 = 尘埃/灵雾/符文，不是玻璃/钢筋）

**任何一项出自别的体系 = 设计分裂，重写对齐。**

**⚠️ 例外（2026-08-05 玄黄刀实测修正）：高端产品片/广告片允许"现代画面 + 题材字体"分层组合**——画面保持现代极简高级感（苹果式影棚光效、纯黑背景），字体承载题材文化属性（古风毛笔书法/碑刻/印章）。实测效果优秀。

```text
✅ 玄黄刀实测版（效果不错）：苹果发布会风格影棚光效 + 纯黑背景（画面=现代高级感）
   + 古风毛笔书法"玄黄刀" + 碑刻"开天 辟地 斩道" + 朱红印章"一柄难求"（字体=东方文化）
   = 画面负责高级感，字体负责题材感，分层不冲突
```

**何时用全体系统一 vs 分层组合**（2026-08-05 两个版本均已实测生成，效果都好）：
- **纯题材氛围片**（古风剧情/水墨空镜）→ 全体系统一（画面+字体都东方化）
- **高端产品片/广告片**（把"古风神器/国潮产品"拍出高级感）→ **两条路都验证可行**：
  - **分层组合**（实测✅）：苹果式现代画面（纯黑+影棚+冷白轮廓光）+ 古风字体 → 画面高级感、字体题材感
  - **全体系统一**（实测✅）：东方玄金暗调画面（玄黑+金色灵光+水墨留白）+ 古风字体 → 整片东方氛围更浓
- 判断：产品的卖点是"高级感"还是"文化感"？**都要 → 分层；只要氛围 → 全统一**；不确定就两条都生成对比

#### overall_soundscape 写法规则（2026-08-05 用户实测：音效变差；2026-08-10 补事件型铁律）

**问题**：音效堆砌（4+ 个）+ 超现实抽象音（灵光嗡鸣/粒子气流）→ H3 渲染成一团噪音或直接弱化。

**规则**：
1. **最多 2-3 个音效**，宁缺毋滥；堆 4+ 个 = 互相干扰
2. **优先真实可辨识音**（金属/风声/水声/脚步/鸣响），**禁用超现实抽象音效**（"灵光流动的嗡鸣""粒子气流"这类模型渲染不出）
3. **音效必须与画面动作对应**：画面出现什么才配什么音，不全程堆
4. 音量标注（极低/轻/渐强渐弱）

**🚨 事件型铁律（2026-08-10 用户实测：庙外雨声没生成）**：
- **持续氛围型写法 = 生成不出来**："庙外雨声不断""风声萧瑟"这类抽象持续词，H3 生成优先级极低
- **必须写成事件型**：物体 + 动作 + 声音（"雨丝敲打屋檐""檐角积水滴落门槛溅起细响""风灌入庙门吹得烛火噼啪"）——每个声音绑定一个可见物体的交互
- **按时间/空间顺序串联**（先 A 声 → 再 B 声），官方示例全部如此（rain ticks against the window / water drips from the bicycle frame）
- **音量词慎用"低/极低"**：加了 = H3 真压到听不见，被台词一盖等于没有；需要弱化就写"轻"或"渐弱"，不要写"音量低"
- **独立字段优先**：官方三段式（integrated_multimodal_description / overall_soundscape / non_diegetic_music）里 soundscape 是独立字段，字段名识别权重高于中文模板混在结尾的"环境音效："

```text
✅ overall_soundscape: 刀锋出鞘的金属长鸣、符文亮起时的清脆回响，音量极低。（2 个真实音，对应画面动作）
❌ overall_soundscape: 灵光流动的嗡鸣、符文细碎清响、金属长鸣、粒子气流声贯穿全片。（4 个抽象音堆砌 → 噪音）
✅ 修正雨声（事件型）：雨丝敲打破庙屋檐，檐角积水滴落在门槛石沿上溅起细响；一阵风灌入庙门，烛火噼啪一晃。
❌ 修正前（持续型）：庙外雨声不断，音量低。（H3 不生成）
```

#### 🚨 声音元素总量铁律（2026-08-05 用户强调：MiniMax 音效处理有限，混太多必乱）

**核心**：MiniMax 对音效/多轨声音的处理能力有限——**声音元素越少越稳，每个必须有存在的理由（匹配画面 + 符合逻辑），宁缺毋滥**。声音元素一多，模型分不清主次，输出就是"乱七八糟的一团"。

**⚠️ BGM 默认不写（2026-08-05 用户强调：BGM 都是后期配的）**：
- **行业常态：BGM 不进 prompt，后期剪辑软件配**——模型生成的 BGM 质量不稳定、还容易盖过画面
- **默认 non_diegetic_music 写 `N/A`**，只在用户明确要求"BGM 要随画面生成"时才写
- **🚨 多段拼接场景 BGM 必须 N/A（2026-08-05 吸收自粉色气泡水广告）：** 多段视频要拼接成完整片子时（怀旧六连段/系列短片），每段生成的 BGM 风格、节奏、音量必然不一致 → 拼接处断裂。**拼接片 BGM 一律后期统一配**，prompt 里可以加一句"不要生成BGM"。
- **⚠️ 区分：BGM（后期配）≠ 音效（画面内，保留）**——环境音、动作音、结尾提示音/UI 音都是**画面内的声音事件**，属于画面内容，**必须保留在 prompt**；只有"背景音乐"是后期配的
- 画面内角色能听到的声音（收音机/电视/现场演奏）仍要写（diegetic，属于画面内容），但那是画面的一部分，不是 BGM

**全片声音元素总量控制**：

| 类别 | 上限 | 说明 |
|---|---|---|
| **环境音效（overall_soundscape）** | ≤2 个 | 每个必须对应一个画面元素/动作 |
| **结尾提示音/UI 音** | 1 个（保留，属音效范畴） | 第 14 秒与标语同步，并入 soundscape 或画面描述 |
| **BGM 乐器（non_diegetic_music）** | **默认 N/A**；要求生成时 ≤3 个乐器元素 | 后期配 |
| **台词** | 按需，不算"杂音" | 有台词时环境音/BGM 还要再减 |

**全片声音元素总量**：**默认无 BGM ≤4 个，有 BGM ≤6 个**（台词除外）。默认无 BGM 时 2-3 个环境音/音效就够（如：环境音 2 + 结尾提示音 1）。

**配乐映射原则**（音乐驱动运动映射技法，仅当用户要求 BGM 生成时适用）：
- 映射最多用 **2 个乐器元素**（如"琴音=刀光、鼓点=粒子"）
- 第 3 个（弦乐/人声）只在高潮段出现，其余时间沉默——不是全程 3 个齐响
- 不要为了"丰富"加乐器，声音元素少 = 每个都被模型认真处理

```text
❌ BGM 7 个元素齐响：合成器+低频脉冲+电子鼓点+弦乐垫+人声吟唱+结尾提示音+2 音效 = 全片 9 个声音元素 → 必乱
❌ 默认给产品片写 BGM → 违背"BGM 后期配"行业常态
✅ 精简版（默认）：环境音 2（金属长鸣+符文回响）+ 结尾提示音 1 + BGM N/A = 全片 3 个 → 画面纯净，BGM 后期配
```

**检查**：交付前数一遍全片声音元素（环境音个数 + BGM 乐器个数 + 尾音），**默认无 BGM 时 ≤4 个，有 BGM 时 ≤6 个**。

#### 🎧 声画对应的“有理由超额”例外（2026-08-07 新增）

默认声音总量上限是稳定性优先的经验规则，不是绝对禁令。若声音数量超出默认限制，只有同时满足以下条件，才允许判定为“有理由的超额”，而不是无序堆音：

1. **每个声音都有明确的画面来源**：能指出它由哪个可见动作、物体或空间产生。
2. **声音承担叙事或运动功能**：用于标记变形、推动通勤路径、强化动作节拍、连接转场或完成结尾，而不是单纯增加热闹感。
3. **声音按时间分段出现**：不是所有声音从开头到结尾同时持续；声音应在对应动作发生时进入、减弱或结束。
4. **声音类别清晰且彼此可辨**：环境底噪、动作声、变形声、提示声和角色声音不能混成一团。
5. **音色与整体风格一致**：超现实声音也应轻巧、柔和、可辨识，不能突然变成噪音、惊吓音或压迫性低频。
6. **必要时仍要删减**：即使声画对应，也应优先保留关键动作声，删除重复、同义或无法听清的声音。

**允许超额的典型场景**：实拍与手绘动画融合、连续形态变换、复杂通勤/追逐、音乐驱动运动、声音桥转场。此时可在 `overall_soundscape` 中写多个声音，但必须按动作阶段组织，并明确“只在对应动作发生时出现”。

```text
✅ 有理由的超额：键帽脚步声、充电线滑行声、杯柄攀爬声、纸飞机掠过声、自行车铃声、时钟滴答声——每种声音都对应一个清晰可见的变形或移动动作，分阶段出现，且整体轻巧可辨。
❌ 无序堆音：全程同时加入脚步、风声、粒子声、机械声、铃声、警报、人声和低频轰鸣，只为制造“丰富感”。
```

**自检追加**：声音超出默认上限时，逐项回答“来源是什么、何时出现、叙事作用是什么、能否删掉而不损失画面信息”。有任一声音无法回答，删除它。

#### 🔊 空间声场方位写法（2026-08-06 吸收自第三方 H3 教程"立体声 6 套"，严谨吸收版）

> **来源与定位**：第三方教程利用 H3"原生立体声"卖点，主张把声音**方位写满**（左/右/前/后/上/下/远/近 + 渐变方向）。⚠️ 教程原话"立体声层数越多越能体现卖点"与**用户实测冲突（声音元素一多必乱）**，故修正为下方边界——**只吸收"方位精度"，不吸收"元素堆叠"**。与「声音…

**核心公式**：每个声音元素写 `方位（左/右/前/后/上/下/远/近）+ 距离变化（由远及近/由近及远）+ 声相移动（左→右）+ 混响随距离变化`。

**写法模板**：
```text
✅ 脚步声从左后方远处开始，逐渐移动至正前方近处，混响随距离变化——远处混响长，近处混响短。（1 个元素：脚步，方位+距离+混响全写）
✅ 雨声分层：上层树冠雨打阔叶声左右均匀覆盖，下层积水溅落声在脚下。（1 个元素：雨，分层写方位）
✅ 推进器引擎声从左后方合拢至正前方，金属关节液压声左右交替。（1 个元素：引擎，声相移动）
❌ 脚步声+引擎声+警报声+雨声+风声同时堆 5 个。（元素堆叠 → 噪音，违总量铁律）
```

**混响特性档位**（写进 overall_soundscape，与方位配套）：
| 空间 | 写法 |
|---|---|
| 无混响干声 | 适用于直播间/密闭舱/口播 |
| 小房间轻微反射 | 厨房/卧室/茶室 |
| 大厅长混响 | 空旷大厅/殿堂，混响时长随距离衰减 |
| 户外开放无反射 | 天台/山顶/旷野 |

**声音动态档位**（音量变化，可并入 soundscape 或分镜描述）：`音量恒定` / `由弱渐强` / `突然爆发后衰减` / `节奏性脉冲`。

**⚠️ 适配边界**：方位写法适合**镜头静止或缓动的氛围片/音效片**（声场本身就是内容）；文戏/快切剧情片**不要喧宾夺主**（有台词时环境音还要再减，见总量铁律）。

#### non_diegetic_music 写法规则

- 只写**乐器、速度、节奏、动态变化**；**禁用抽象情绪词**（"温馨""庄重""史诗感"都不行）
- 角色能听到的音乐（收音机/电视/手机/现场演奏）= **diegetic 事件**，进 integrated_multimodal_description，不是 non_diegetic_music
- 无 BGM 时写 `N/A`

```text
✅ non_diegetic_music: Sparse piano notes at a slow tempo, joined by sustained low strings that gradually increase in volume before fading out.
   （中文等价写法：稀疏钢琴慢速弹奏，加入持续低音弦乐渐强后渐弱。注：示例保留官方英文原样供对照，交付时全中文）
❌ non_diegetic_music: 温馨而庄重的背景音乐。（抽象情绪词，禁）
```

#### 🚨 跨镜一致性：根治靠参考图，文字只是缓解（2026-08-04 用户实测 + 官方确认）

**问题**：文生视频跨镜头物体/角色漂移（桌上一只茶杯，下镜变两只/消失）。根因：**模型逐镜生成，没有上一镜记忆**——每镜都从文字重建，没写死的东西就自由发挥。

**官方/准官方结论（fal.ai Day-0 合作伙伴 + getimg.ai）**：

| 方案 | 效果 | 说明 |
|---|---|---|
| **Reference to Video + 参考图锁定**（最多 9 图） | ✅ **根治** | "carries the same face, wardrobe, and product **from one shot to the next**"——用图片锁定关键物体/角色/场景，模型跨镜拿同一张图重建 |
| 时间码分镜（`At MM:SS.mmm`） | 🟡 缓解 | "keeps the pacing from drifting into a slideshow"——保持节奏，不解决物体漂移 |
| 每镜重申关键道具（数量+位置+状态） | 🟡 缓解 | 给模型更多锚点，但非根治 |
| 官方承认边界 | ⚠️ | "Longer sequences and fast action are harder to hold"——长序列/快动作更难保持，多生成几版挑好的 |

**操作指引**：
1. **关键道具/角色/产品必须一致**（茶杯/人物/商品）→ **先 himg 生成样图 → Reference to Video 提交** → prompt 里每镜写"保留图中X"
2. **纯文生（T2VA）** → 时间码分镜 + 每镜重申 + 接受一定漂移 + 多跑几版
3. **场景文字详细度**：环境细节写一次锁定世界（禅房/光线/材质）；关键道具每镜提"那只/那杯"锁数量位置；状态变化显式声明（"变化要写，不变更要写"）

##### 🔗 纯文字层一致性锚点（2026-08-06 吸收自第三方 H3 教程"转场/一致性 5 套"，严谨吸收版）

> **来源与定位**：第三方教程"一致性靠同一主体 + 同一光线逻辑，转场类写清从 A 到 B 的过渡方式，关键是过渡中主体不能变形"。⚠️ **定位：缓解手段，不是根治**——与上方「根治靠参考图」结论一致，无图纯文生时用它降低漂移，有图仍优先参考图。原话"避免跳帧"系第三方表述，H3 无逐帧控制能…

**文字层 3 锚点**（纯文生/跨场景时写）：

1. **光比恒定、色温随场景变**：场景/光线变了，但**光逻辑不变**（如各场景光比保持 3:1，色温 3000K→7000K 渐变）——给模型一个"同一世界"的锚
   ```text
   ✅ 五个场景主光不同但光比保持 3:1，色温随场景变化 3000K 到 7000K
   ❌ 场景一客厅暖光，场景二海滩光，场景三雪地光（无光逻辑锚）
   ```
2. **转场锚点音**：用**同一重复音效标记转场瞬间**（水珠"滴"声/钟声/提示音），跨场景声音连续
   ```text
   ✅ 水珠滑落瓶身的"滴"声作为转场锚点，每个场景切换时出现一次，居中定位
   ```
3. **过渡中主体不变形**：明确声明主体外观在 A→B 过渡中保持不变，变化只发生在场景/光线/服装（有意的变化才允许）
   ```text
   ✅ 玻璃水瓶身外观在五场景过渡中保持不变，仅场景与光线变化
   ```

**⚠️ 适配边界**：这 3 锚点是**文字层缓解**，跨镜角色/道具一致性仍以参考图为准（参考图=根治，锚点=兜底），多跑几版挑好的。

#### 说话人补充规则

- 多人同时说话：`(S1,S2)` 复合 ID
- 不发声的角色**不分配**说话人 ID
- 画外音标准短语：`says in an off-screen voiceover` + `<d>` 后必须声明 `while his lips remain completely closed`（嘴唇闭合）
- 跨镜头台词：`<scenetrans>` + 延续描述（`continues seamlessly across the cut` / `carries over from the previous shot`）；被视频结尾截断用 `<cutoff>`

#### 🚨 `<d>` 台词区域隔离铁律（2026-08-11 用户实测：语音演绎文字被 H3 朗读）

**问题**：`</d>` 后面紧跟语音演绎文字（如"尾音发颤，最后一个字几乎散在风里"）→ H3 把它**当作台词/旁白读出来**。

**铁律**：
1. **语音演绎（音色/语气/颤音/气口）必须放在 `<d>` 前面**作 delivery 描述：`嗓音带着明显的哭腔和笑意、尾音发颤，轻轻说 <d>[中文] 你……回来了。</d>`
   > ⚠️ **2026-10-04 更新**：短剧对白戏一律改用「🚨 台词标签固定版式」——delivery **独立成行、冒号收尾**，`<d>` **另起一行、行首即标签**；上面这种内联的「…说 `<d>`…」写法禁用（标签夹在句子里 → H3 分不清哪段要念）。
2. **`</d>` 之后只能跟画面动作**，且用"随后/然后"等词明确引导，禁止出现任何声音/语音类文字（"尾音""声音散在风里""带着哭腔""话音落下"）
3. 台词说完后的动作：`</d> 随后她低头把花束抱紧，肩头轻轻耸动。`（画面动作 ✅）｜`</d> 尾音发颤，最后一个字几乎散在风里。`（声音文字 ❌ 会被朗读）

```text
❌ 轻轻说 <d>[中文] 你……回来了。</d> 尾音发颤，最后一个字几乎散在风里。（H3 把"尾音发颤..."读出来）
✅ 嗓音带着明显的哭腔和笑意、尾音发颤，轻轻说 <d>[中文] 你……回来了。</d> 随后她低头把花束抱紧，肩头轻轻耸动。（演绎在前、画面在后）
```

**检查**：写完台词后扫一遍——`</d>` 后面有没有声音/语音类文字？有就移到 `<d>` 前或改成画面动作。

#### 🚨 台词标签固定版式（2026-10-04 用户实测定稿：「这样台词就不混乱了 都是谁读谁的」）

**适用范围：短剧对白戏 / 任何有台词的片子，一律照此版式。** 一句台词 = 一个三行块：

```text
[Shot N] At MM:SS.mmm, <景别 + 机位>。<角色（Sx）> <画面动作>。
Sx 角色名台词（<语气 / 音色>）：
<d>[中文] 台词原文</d>
随后嘴唇轻合，<收尾画面动作>。
```

**五条铁律**：
1. **`<d>` 另起一行、行首即标签**——禁把标签揉进叙述句中间。
2. **delivery 独立成行、冒号收尾**，只写语气/音色；**禁「说」字**——含「说」的引导句会被 H3 当语音内容念出。
3. **说话人归属写进 delivery 行开头**（`S1` + 角色名），跨镜 ID 不变 = 「谁读谁的」只认这一行。
4. **`</d>` 之后只跟画面动作**（`随后嘴唇轻合，…`），禁任何声音/语气/音色词。
5. **一句一处**：同一句台词不得再出现在台词表、语气表或「念出第 N 句台词」里（三处表示 = 重复或错位朗读的根因）。

```text
❌ 旧写法（会乱）：……以轻蔑、不耐烦、句尾下压的语气说 <d>[中文] 苏泽，欲擒故纵的把戏够了吧？</d> 随后嘴唇轻合，指尖敲了一下。
   （标签夹在句子里 + 有「说」字 + 说话人靠上下文猜）

✅ 新写法（实测不混乱）：
[Shot 2] At 00:01.800, 切到林婉近景，机位固定。林婉（S1）双手抱在胸前，下巴微微抬起，眼神自上而下轻蔑地扫过对方。
S1 林婉台词（轻蔑、不耐烦、句尾下压）：
<d>[中文] 苏泽，欲擒故纵的把戏够了吧？</d>
随后嘴唇轻合，右手食指在左臂上极轻地敲了一下。
```

**自检硬问句**：每句台词是不是三行块？delivery 行开头有没有 `Sx` + 角色名？有没有残留「…说 `<d>`…」的内联写法？

#### 🚨 听觉/心理动词也会被配音（2026-08-11 用户实测：非台词句被当画外音读）

**问题**：不只在 `</d>` 附近——**整条描述流里**，含听觉动词或心理描写的短句都可能被 H3 当台词/旁白配音："她极轻地吸了一口气，像是要把什么情绪压回去"→ H3 把整句读了出来。

**根因（官方文档+实测）**：H3 是原生多模态模型，画面与声音**同一 pass 同步生成**（Runware 官方指南）；且它**默认有"补对话"倾向**——不声明"不要旁白"就会自动编台词（H3 实测评测原话："I forgot to say to add any dialogue... and the generator, it will give some dialogue"）。画面里出现张嘴/吸气/抽泣等**发声动作** = "这里有语音"信号 → 连描述文字一起配音。

**规则**：
1. **视觉分镜里写呼吸，只写视觉结果**：`她的肩膀随着呼吸轻微起伏` ✅ ｜ `她吸了一口气` ❌（听觉动词）
2. **删心理描写**（"像是要压回去""仿佛在忍"）——这是给读者看的，H3 会当真
3. **听觉信息只进 overall_soundscape 字段**（独立字段），不散落在分镜描述里
4. **加负面声明压"默认补对话"**（fal.ai 指南：negative direction 对 H3 特别有效）：
   `全程除 <d>[中文] ...</d> 这句台词外，无任何旁白、画外音或额外人声，人物不发出其他语音。`
5. 同理：`尾音被风带走`、`声音散在风里` 这类模糊语音描述，soundscape 里也删，只留明确的物理声（吸气/抽泣/脚步）

```text
❌ [Shot 2] ...她极轻地吸了一口气，像是要把什么情绪压回去，睫毛上挂了一层水珠。
✅ [Shot 2] ...她的肩膀随着呼吸轻微起伏，睫毛上挂了一层水珠。
   overall_soundscape: ...随后是女主角一声急促的吸气、一声压抑的抽泣鼻音...
   末尾负面声明：全程除台词外无任何旁白、画外音或额外人声。
```

#### 🚨 朗读规则句本身也会被配音（2026-09-30 用户实测）

**现象**：prompt 里写的这条声明——「朗读规则：全片只有【台词表】中引号内的文字会被念出，其余都是制作说明。」——H3 把其中的个别字/短语念进了音轨。

**根因**：H3 对**含语音动词（念出／朗读／说）的自然语言句子**一律按「这里有语音」处理；句子里的名词短语（「台词表」「引号内的文字」）会被当成待配内容。它不区分「描述规则的句子」与「要念的台词」。

**修法（三层，缺一不可）**：
1. **删掉整句朗读规则**——不写「只有 X 会被念出」这类元规则；
2. **只靠结构性隔离**：台词全部用 `{}`（普通模式）或 `<d>[中文] …</d>`（全参考模式）包裹。**区分两种「念」**：镜头动作句里的「开口念出第 N 句台词」是必要的落点指令，**保留**；**几是描述「哪部分会被念／不被念」的说明句一律删**（元规则句才是被配音的源头）；
3. **兜底句改成「不出现」句式、只放末尾负面声明**：「全片除上述台词外，不出现任何旁白、画外音或额外人声。」（比「不会被念出」稳）。

**另**：语气／表演说明块的块首标注，别写「一律不朗读」（带语音动词），改写成「本段仅为表演参考，不属于画面内容」。

**自检硬问句**：prompt 里除了台词本身，还有没有第二处带「念／朗读／说」字样的句子？有 → 删。

### 全参考模式（Full-Reference Mode）官方规范（2026-08-04 补充）

| `retention_analysis` | 逐标签说明参考内容如何保留/转移/复用 |
| `detailed_description` | 按播放顺序逐镜头描述（画面/动作/镜头/声音/台词） |
| `overall_soundscape` | 全片环境音+物理声音 |
| `non_diegetic_music` | 只有观众能听到的 BGM |

#### retention_analysis 保留标记体系（2026-09-11 补充官方标记词）

`retention_analysis` 段必须**逐个参考标签用一行**写清"保留程度"，用下方固定英文标记词（模型识别固定值，不自定义）：

**可见内容（Visible）四档：**

| 标记 | 含义 | 何时用 |
|---|---|---|
| `fully_preserved` | 参考内容**完整保留**，所有已定义特征原样沿用 | 要锁死脸/穿搭/场景时 |
| `partially_preserved` | 参考内容**仍沿用但部分特征被改/省略** | 只想留部分（如留环境换服装） |
| `attribute_transfer` | 把参考的**某个特质**转移到另一个目标主体上 | 只借颜色/材质/风格，不保留原主体 |
| `weak_reference` | 只保留**粗略风格/类别/构图/氛围**相似 | 仅当"神似即可" |

**音频（Audio）四档：** `fully_copy` / `partially_copy` / `reference` / `weak_reference`

**写法示例（一行一标签）：**
```text
retention_analysis:
<Subject 1> (appears in [Shot 1], [Shot 2]): fully_preserved - 保留女性身份、微卷发、痣、比例、绿色外套、米色衬衫与深色长裤。
<Subject 2> (appears in [Shot 3]): partially_preserved - 保留咖啡厅木质桌，其余场景元素不沿用。
<Audio 1>: reference - 仅作为 <Subject 1> 的音色参照，不复制内容。
```

**🚨 关键澄清（官方明确，防误用）：** `partially_preserved` 指的是**参考内容的特征被改了部分**，不是"这个镜头里主体只露出一部分"。整间咖啡厅保留但某镜头只拍到桌子，仍写 `fully_preserved`；只有当你真的改了特征（换服装/删元素）才写 `partially_preserved`。

**与"图锁信息不重描"铁律的结合**：`fully_preserved` 就是在 retention_analysis 里履行"保留图中设定"的精确写法——两张图分别 `fully_preserved` 锁死角色、锁死场景，文字就只写增量。

#### Style opening 位置规范（2026-08-06 官方指南 §5.2）

**Ref 模式风格开场必须写在 `[Shot 1]` 之前，1-2 句**（与 T2VA 不同——T2VA 风格写在 `[Shot 1]` 之后）：

```text
The target video is in a cinematic, literary music-video style with soft lighting and a slightly desaturated color palette.
[Shot 1] The scene opens in a crowded urban street...
```

- 中文表达同样适用：`[Shot 1]` 前先给 1-2 句风格总声明（画风+光线+色彩基调），再进分镜
- `detailed_description` 正文 350-500 英文词（中文场景约等量），对白密集内容优先保证完整台词时间线，不为凑字数机械堆词

#### 四类标签体系（核心！）

| 标签 | 含义 | 何时用 |
|---|---|---|
| `<Subject N>` | 从参考素材抽象出的**可见内容**（人物/场景/道具/服装/动作/风格） | 会实际用在目标视频里的内容单元 |
| `<Picture N>` | 参考图作为**具体帧锚点**（首帧/关键帧/尾帧/构图锚点） | 仅当图片本身作为帧使用 |
| `<Video N>` | 参考视频作为编辑源/延续起点/整片时间结构 | 编辑/延续/节奏参考 |
| `<Audio N>` | 音频信号被复制或引用 | 音色/音效/BGM 参考 |

**关键规则**：
- 图片只用于定义角色/场景/服装 → **不建独立 `<Picture N>`**，直接在 `<Subject N>` 定义里引用来源
- 图片作为首帧/关键帧 → 才建独立 `<Picture N>`（如 `<Picture 2> is the first frame of [Shot 1]...`）
- 标签一旦分配，全程（六段）含义不变
- 一个 Subject 可来自多个素材；一个素材可提供多个 Subject
- **`<Video N>` 与 `<Audio N>` 独立编号**（2026-08-06 官方指南 §2.5）：两套编号互不绑定，同一参考视频可以对应 `<Video 1>` 和 `<Audio 2>`（不同索引不阻止同一来源）
- **普通参考视频不因"文件含声音"就自动建 `<Audio N>`**（2026-08-06 官方指南 §2.5）：只有音频确实承担复制/引用角色时才建 Audio 标签；`<Audio N>` 定义主要写"音频的角色"，不必点名它来自哪个 `<Video N>`（除非来源有歧义才声明共享来源）

#### 🚨 图锁定的信息不重复描述（2026-08-04 用户提出，Ref 模式铁律）

**有参考图时，外貌/发型/服装/道具已在图里锁定，文字不要重新详细描述**——两个信源描述同一特征 = 冲突，模型不知道听谁的，可能产生插值/混合（如图是卷发、文字说直发）。

**规则**：文字只写"增量"（图给不了的），图锁定的写"保留"。

| 信息类型 | 有参考图时怎么写 |
|---|---|
| 外貌/发型/服装/道具（图里已有） | **不写细节**，写 `保留 <图片N> 中的外貌与服装` |
| 声音/音色/语速/性格（图给不了） | **必须写**（静态图没有声音） |
| 表情/动作动态（图是静态的） | **必须写** |
| 图里不需要的元素（背景/路人） | 写"不采用"声明 |

**示例**：
```text
✅ <Subject 1> 是 <图片1> 中的动漫小信使，保留图中的外貌、发型、服装与青铜纹样工作牌。声音清甜明快、语速轻快、尾音带笑意。
❌ <Subject 1> 是 <图片1> 中的动漫小信使，圆脸杏眼，黑色短发齐刘海扎双丸子头，身着米白对襟短衫配墨绿马面裙……（重复描述 = 双信源冲突）
```

**例外（有意为之才写文字覆盖）**：参考图不理想，想改发型/换服装 → 才写文字覆盖 + 声明（`保留图中的发型，服装改为玄色长袍`）。

**注意**：无参考图的角色（纯文字锁定形象）仍要完整写外貌——图锁定的信息不重复描述**只适用于有图的主体**。

**示例**：
```
<Subject 1> 是 <图片1> 中的动漫小信使，圆脸杏眼，双丸子头，米白短衫配墨绿马面裙。
<Subject 2> 是 <图片2> 中的青铜巨鼎，鼎身饰饕餮纹，青铜锈色斑驳。
<图片1> 用于定义 <Subject 1> 的外貌与服装，不采用图片背景。
```

#### 🚨 分镜参考图（开发板 / Storyboard Reference）专属铁律（2026-08-22 用户验证）

> 2026-08-22 用"动画开发板（角色设计 + 8格分镜 + 蓝色运镜箭头 + CAM/LENS/TIME 标注）"做 H3 I2VA 测试时发现的铁律。

**核心问题**：开发板/分镜参考图与首帧图完全不同。

| 维度 | 首帧图（I2VA） | 开发板/分镜图（Storyboard Reference） |
|---|---|---|
| 图的角色 | 视频第一帧（keyframe） | 分镜规划图（planning reference） |
| H3 任务类型 | I2VA / L2VA / FL2VA | **Reference Generation**（不是 I2VA） |
| 图里有什么 | 单一画面 | 角色设定表 + 网格分镜 + 红色边框 + 蓝色箭头 + 镜头编号 + CAM/LENS/TIME 标注 + 手写注释 + 纸张底纹 |
| 容易误用 | 用 I2VA 当首帧 | 跑出"H3把整张开发板画进视频" |

**铁律 6 条**：

1. **任务模式必须选对**：开发板/分镜图是 `Reference Generation`（ref 章节下面的 `[reference generation]` 任务类型前缀），不是 I2VA。误用 I2VA 会让 H3 把开发板的网格、文字、边框当首帧复刻出来。

2. **板上元素全部不进成片**：必须在 prompt 中显式声明以下元素都不出现在最终视频画面——
   - 角色设定表（含 SECTION A 标签、角色名、姿势编号）
   - 分镜网格 / 红框 / 蓝箭头
   - 镜头编号 / CAM / LENS / TIME 标注
   - 手写注释 / 文字备注
   - 纸张底纹 / 色卡名 / 角色表标签

3. **图锁定信息不重复描述（继承上方铁律）**：角色造型、服装、发型、配饰、场景设计、画风、调色已经在图里锁定，文字只写"信息增量"（动作变化 / 状态变化 / 镜头运动 / 声音事件）。每镜只写"画面怎么动起来"，不要重描"画面是什么样子"。

4. **H3 不稳定识别图形箭头，必须把蓝色箭头翻译成文字运镜**：
   - ❌ 错误写法：`请按照图片中蓝色箭头的方向运动`（H3 不一定理解）
   - ✅ 正确写法：先用 vision 读图，把每格箭头翻译成 H3 官方运镜词（缓推 / 右移 / 上摇 / 下俯 / 拉远 / 环绕 / 固定），写进对应 `[Shot N]` 里
   - 箭头只是方向辅助，最终运镜以文字为准

5. **8 镜 = 板上 8 格**：prompt 里的 `[Shot N]` 必须严格对应开发板的 8 格，**不能擅自新增或合并镜**。每镜时长按板上标注或平均分（15s/8≈2s/镜），切点用 H3 官方 `At MM:SS.mmm` 递增。

6. **声音事件型**（继承上方铁律）：每个 `[Shot N]` 末尾或汇总到 `overall_soundscape` 段，每镜 1 个对位声音，禁止"全程持续型抽象音"。

**失败处理（参考图专用）**：

| 翻车现象 | 修复 |
|---|---|
| H3 把开发板当首帧复刻出整张网格 | 任务模式改用 `[reference generation]`，不是 I2VA |
| 板上红框/箭头/文字出现在成片 | 在 prompt 末尾显式列出"全部不进成片"清单 |
| H3 没按箭头方向运镜 | 把箭头翻译成 H3 官方运镜词写进文字 prompt（不要依赖图形） |

#### summary 任务类型前缀

```
[reference generation] ...          # 素材提供生成指导（最常见）
[keyframe completion] ...           # 图片作为首帧/尾帧锚点
[video editing + audio reuse] ...   # 编辑原视频 + 复用原音频
[video continuation + keyframe completion] ...  # 延续 + 尾帧
[audio reference] ...               # 只参考音色/风格，不复制信号
```
多关系用 `+` 组合，不重复。纯生成场景（图片仅作指导）= `[reference generation]`。

**任务类型判断规则（2026-08-06 官方指南 §3）**：
- **"存在视频/音频" ≠ 自动建对应 task type**：素材只是"存在"不构成 task type，看它在目标视频里的实际角色
- 参考视频只提供运镜/切点/节奏 → 归 `reference generation`（不是 video editing/continuation）
- 只有"直接编辑原视频"才用 `video editing`；只有"从原视频继续/延伸"才用 `video continuation`
- 编辑原视频且原音频仍可闻 → 加 `audio reuse`；延续但没直接复制音频、只延续音轨特征 → 加 `audio reference`
- 视频编辑任务的 summary 前缀后以 `The target video is an edited version of <Video 1>.` 开头

| `partially_preserved` | 部分保留/部分特征改变 |

```

#### 台词格式（覆盖铁律 #0 的例外）

- 台词统一用 `<d>[语言] 原文</d>`，原文逐字保留（中文台词 = `<d>[中文] ...</d>`）
- 说话人 ID `(Sx)` 按目标视频实际发声顺序分配，全程复用
- 参考 Subject 说话时写 `<Subject N> (Sx)`；无 Subject 的说话人用稳定声音描述 + `(Sx)`
- 画外音标记 `off-screen`；跨镜头台词 `<scenetrans>`；被截断 `<cutoff>`
- 直接复用的台词/歌词必须原词原语言进 `<d>`，不猜不改写

**台词清洗规则（2026-08-06 官方指南 §5.4）**：
- 听不清的片段写 `[unclear]`，**不猜不意译**
- 标点标准化：只保留表达句意的基本标点（`,` `.` `?` `!`），删掉重复波浪线、emoji、项目符号、重复/装饰性标点；完整陈述/疑问/感叹句分别以 `.` `?` `!` 收尾（在 `</d>` 前）
- 只参考音色/节奏/情绪时，**不把原音频的台词带进目标视频**（带 = 台词复用，必须逐字保留原词）

**(Sx) 说话人纪律（2026-08-06 官方指南 §5.4）**：
- **不在 `retention_analysis` 里写 `(Sx)`**——retention 只描述保留关系，说话人 ID 只在 `detailed_description` 和 `subject_definitions` 的 Audio 绑定里出现
- `<Audio N>` 绑定目标说话人时**复用全局 `(Sx)`**，从不独立分配新 ID
- 复用 BGM/完整音轨里仅作"口白 cue"的声线（无真人/角色/旁白在画面上产出）→ 用 `<Audio N>` 作为可听来源，**不要发明额外 `(Sx)`**；有具体人/角色/旁白产出才分配 `(Sx)`

| 层 | 内容 | 中文模板对应 |
|---|---|---|
| **台词+同期声** | 对白、演唱、画面内声音事件 | 分镜头里的台词 `{}` |

### 🎬 结构级四技法（2026-08-05 吸收自专业时尚广告导演模板 AQUARELLE No.7）

> 来源：用户提供的专业 fashion film prompt（英文版），按"先批判评估再吸收"原则筛选。**这 4 个是 H3 模板的真实缺口**，其他部分（15s 一镜…

#### 技法 1：一句话 Concept（概念先行）

> ⚠️ **定性（2026-08-05 查官方文档后修正）：这是第三方写法，不是 H3 官方字段。** 官方公式 = 主要表现物 + 场景空间 + 运动/变化（+镜头运动+美感氛围），无"概念"字段。概念段的正确用法是**并入开头总声明作为自然语言定调**（官方认可"更丰富的表达带来更好的生成效果"），**不要单独列"概念："字段**，也不要把生成效果押在它身上——真正决定画面的是分镜描述。

**在分镜之前，先用一句话定义整条片子的核心隐喻**——"这个视频讲的是什么"。模型有了方向锚点，分镜才不会散。

```text
✅ 苹果新品发布会风格广告片，展示玄黄刀的工艺、力量与稀缺。（并入开头总声明，自然带出）
✅ 水彩成为活的媒介，指尖抽出透明水彩丝带，丝带拉动镜头、塑造文字、改造环境。（并入开头总声明）
❌ 概念：玄黄刀是先天至宝……（独立"概念："字段——非官方结构）
❌ （直接进分镜，没有任何方向定调）
```

**用法**：写在开头总声明段内，作为第一句/第二句自然语言（一句话），不单列字段。作用是锚定方向，权重低于分镜描述。

#### 技法 2：颜色来源规则（动态约束）

**人物设定段只锁静态外观不够——还要规定"颜色怎么变"**。写一条"新颜色只能通过 X 出现"的规则，防止模型乱改服装/环境色。

```text
✅ 服装颜色固定不变，新颜色只能通过水彩颜料渗入布料逐渐出现。
✅ 刀身玄黄不变，亮光只能通过符文点亮和粒子聚集出现。
```

**用法**：加在人物设定段末尾，一句话规则。

**🎨 光影色彩分离写法（2026-08-05 吸收自粉色气泡水广告，颜色规则高级形态）**：

**用"高光/暗部各自固定颜色"替代笼统的"冷暖对比"**——精确控制光线色温，模型渲染更准。

```text
❌ 画面冷暖对比。（笼统，模型自由发挥）
✅ 高光轻微溢出呈现柔和的樱花粉与阳光白，暗部保留通透的冷青色。（高光=暖、暗部=冷，各锁一色）
✅ 暖金顶光勾勒轮廓，暗部保留青铜绿锈的冷沉。（产品片的精确光影色）
```

**用法**：光影复杂的镜头（逆光/顶光/夜景），用"高光=某色，暗部=某色"写明；配合颜色来源规则（主体色不变 + 光影色分离）双保险。

#### 技法 3：文字物理材质化（字幕立体化）

**屏幕文字不是平面叠加，是物理物体**——写"字母有深度、有反光、有边缘、有阴影、有遮挡"，H3 渲染出来的字幕更融入画面。

```
✅ 字母带物理厚度，表面有湿水彩反光，边缘是纸纤维质感，投影落在画面上。
✅ 大字带金属浮雕感，边缘泛灵光，粒子从字面上滑落。
❌ 屏幕显示"白菜 Pro"（平面文字，模型会渲染成贴片）
```

**用法**：屏幕文字描述里加材质词（厚度/反光/边缘/阴影/遮挡）。

#### 技法 4：音乐驱动运动映射（声音 = 叙事引擎）

> ⚠️ **前置条件：仅当用户明确要求"BGM 要随画面生成"时才用**（默认 BGM 后期配，non_diegetic_music 写 N/A——见「声音元素总量铁律」）。此技法用于"用户点名要 BGM"的场景，让生成的 BGM 与画面强绑定。

**把 BGM 元素反向映射到画面变化**——每个乐器元素对应一种视觉运动。比"BGM 只写乐器节奏"更进一步：声音定义画面。

```
✅ 鼓点=镜头运动和纸面折叠；木鱼=纸结构折叠变换；低音=空间尺度感知变化。
✅ 琴音起=刀光一亮；鼓点落=粒子炸开；低音铺底=空间从特写拉向全景。
❌ 背景音乐：古琴缓慢弹奏（单向描述，声音只是背景）
```

**用法**：在 non_diegetic_music 段，写"乐器=视觉变化"的映射关系，不只写乐器名。

**⚠️ 适配边界（吸收时不吸收的 3 条）**：
| 原文写法 | 为什么砍 |
|---|---|
| 15 秒一镜到底 no cuts | H3 单次生成 5-6 秒上限，无切镜超能力边界 |
| 30 拍 × 0.5s 节奏表 | H3 无逐拍对齐能力，0.5s 节拍是噪音，只能当内部参考 |
| 英文 negative prompt | 铁律 #0 全中文；H3 无 negative 字段，负面清单转"不采用 X"声明 |

### 舞蹈编排 / 多拍节奏表：四条判据（2026-10-04）

| 判据 | 内容 |
|---|---|
| ① **还原表 ≠ 编舞** | 时间轴**逐拍带视角标注**（"侧面视角""转至侧/背视角""转回正面"）＝参考视频**抽帧还原表**。抽帧丢掉两样东西：**过渡动作 ＋ 重心变化** → 由此才会出现"相邻拍同形""腿位跨三平面硬切""全程重心焊死"。处理方式：不按编舞标准否定它，按**补过渡**改写 |
| ② **下肢必须参与** | 舞蹈的语法单位＝**重心转移 ＋ 上肢 ＋ 视线**。连续 3 拍以上只有手臂动作＝pose 串烧（成片观感像"定妆照在动"）。每 2–3 拍至少一次屈膝/重心下沉/落地缓冲 |
| ③ **难度曲线** | 同一支片子里两个量级（如 0–2.5s 专业 adagio 单腿三平面腿位 vs 之后站立摆拍）＝拼装痕迹。要么降幅（90°→45–60°），要么补落地与 pivot |
| ④ **卡点密度** | 0.83s/拍已进「0.5s 节拍是噪音」区（**H3 无逐拍对齐能力**）→ 补偿写法只有一种：**每拍末尾"短暂停住半拍"**；且每拍只给一个**单关节 hit**，多关节复合造型（交叉＋手扶对侧）在 0.83s 内无法成形 |

### 因果叙事链：短视频动作的上游规划（2026-08-07 新增）

> **高级参考案例：实拍 × 粗糙发光帧动画《光标提前下班》**  用于学习“概念锚点 + 连续变形动作链 + 实拍空间交互 + 摄影机迟到机制 + 完整结尾”的组合方法。核心链条：光标拒绝工作 → 逃出屏幕 → 行李箱 → 迷你地铁 → 纸…

> 来源：用户提供的「媒介质感 + 主体与环境 + 平静起点 + 触发事件 + 递进动作链 + 结尾回收」模板。此模块是自定义 MiniMax H3 Skill 的叙事规划层…

**适用**：剧情、短剧、生活片段、喜剧、反应和动作场景。  
**不适用**：纯空镜、产品静物展示、单纯镜头运动或不含事件变化的氛围任务。

> 🚨 **边界：后果强度由「题材」定，不由「动机强度」定（2026-09-24 用户纠正）**
>
> 「因果必须相称」指的是**动作有因、事件有果**（红线 8：因果关系断裂），**不是**要求“动机多强、后果就得多大”。把后者当铁律会误伤两类题材：
>
> - **写实 / 生活流 / 纪实**：后果要落**物理可信区间**（力度→后果相称；脱鞋砸摩托不该写成“连人带车摔泥坑”）。
> - **风格化题材（格斗游戏 CG / 修仙 / 特效片 / 动画）**：后果强度由**类型语法**决定——必杀技掀飞整片桌面、一剑劈开山，都是**类型契约**，不需要“实力铺垫”来配平；把威力调小反而砸掉视觉资产。
>
> **正确判据**不是“这个动机配得上这么大的后果吗”，而是“**在这套类型语法里，这一招的预期效果是什么、实际效果是什么**”。要写“失手/意外”，就落在**预期范围 vs 实际波及范围**的差上（她对着空处出招，没料到招式范围扫到了侧面），而不是把威力调小。

**基本结构**：
```text
平静起点 → 单一触发事件 → 第一层可见反应
→ 因果升级 → 主体主动选择 → 清晰视觉结果或情绪余波
```

**写作规则**：
1. 先建立一个平静且可见的初始动作，不要从抽象情绪或混乱高潮开始。
2. 优先只设置一个主要触发事件；先呈现其可见后果，再引入下一层升级。
3. 每个后续动作都必须由前一事件引发，不能把无关动作并列成流水账。
4. 每次升级至少改变人物状态、道具状态、空间关系或情绪强度中的一项。
5. 主体应在后段做出可见的主动选择，而不是一直被动反应。
6. 结尾落在完成动作、稳定道具状态、明确姿态、空间关系解决或可读的情绪余波上。
7. 除非用户要求戛然而止，不要停在关键动作尚未完成的位置。

**压缩成单段时可使用**：
```text
主体正在 A → 事件 B 触发反应 C → C 迫使主体做 D
→ D 改变 E → 主体主动选择 F → 画面以 G 收束。
```

**与不同任务模式结合**：
- 文生视频：完整使用“平静—触发—反应—升级—选择—结果”链。
- 首帧图生：从首帧已有的主体、道具和空间关系开始，不凭空新增触发条件。
- 首尾帧：把动作链压缩为首帧到尾帧之间的连续变化，重点写中间状态如何逐步接近尾帧。
- 尾帧生成：从尾帧结果反推最简洁、合理的前置状态和过渡动作。
- 多段拼接：每段只承担一个小因果单元，并让下一段继承上一段的动作结果或道具状态。

**与现有模块的分工**：本节只负责“为什么发生、如何递进、在哪里收束”；“动作链逻辑”负责动作前提与现实顺序，“情绪三阶段”负责表演过程，“剪辑逻辑”负责景别和切镜，“声音三层分工”负责声画归属。

### 🚨 动作链逻辑（2026-08-05 用户实测发现：人物动作顺序必须合理）

**问题**：只写动作结果不写动作顺序 → 模型生成的画面逻辑矛盾（"光脚跳下炕，凉鞋啪嗒作响"——光脚怎么会有凉鞋声？）。

**铁律：人物的连续动作必须按现实顺序写**——先做什么、再做什么、最后做什么，动作链完整无矛盾。**每个动作的"前提条件"必须先满足**：

```text
❌ 光脚跳下炕，凉鞋在青砖地面上"啪嗒"作响。（光脚 → 凉鞋声 = 矛盾）
✅ 跳下炕，弯腰把凉鞋套在脚上，踩在青砖地面上"啪嗒"作响。（穿鞋 → 才有鞋声）
❌ 他推开门走进屋，把钥匙放回口袋。（推门时钥匙应该在手上，不是口袋）
✅ 他从口袋里掏出钥匙开门，进门后把钥匙放回口袋。（掏出 → 开门 → 放回）
```

**动作链检查 3 步**（交付前逐镜问）：
1. **前提**：这个动作之前，该有的道具/状态存在吗？（鞋在脚上才能有鞋声）
2. **顺序**：动作先后符合现实吗？（先穿鞋后下床，先掏钥匙后开门）
3. **落点**：动作产生的声音/结果有来源吗？（"啪嗒"声来自哪只鞋、"哗啦"声来自哪个动作）

**常见逻辑矛盾**（写 prompt 时主动避雷）：
- 物品凭空出现（关门时钥匙已在口袋、说话时手里已多出东西）
- 声音无来源（光脚走路有鞋声、静止物体有摩擦声）
- 身体部位错乱（转头与视线方向不一致、抬手与目标位置不一致）
- 时间错乱（白天进店直接变夜晚、动作瞬间完成无过渡）

### 🚨 写作时实时避坑清单（2026-08-08 用户实测：自检前先避免）

> 🧭 **本节的角色（2026-09-24 修）**：本清单 = 「统一自检流程 · **阶段 1（写作时实时避坑 / 8 红线）**」的**展开版**（每条红线带正误对照与实测来源）。**阶段划分与流程入口只在「统一自检流程」定义**；本节只负责把 8 条红线讲透，不另立一套流程。

> **本节是通用版**，针对**所有 minimax skill 适用的题材**（不只动作戏）：短剧/对白戏/产品片/古风戏/喜剧戏/对话戏/概念片/动画插画……**动作戏/打斗戏/悬吊戏**详细 7 大类物理约束见 action-sequence-video-prompt skill 8.9，本节是日常通用必避的 8 类硬伤。

**写每镜时实时核对 8 条红线**（不是写完才检查，是**写每镜时边写边避**）：

#### 红线 1：声源不匹配 + 对白字数超载（短剧对白戏/喜剧戏实测：嘴里塞包子不能讲 4 句话）

**铁律**：台词长度同时受**声源物理**和**时间容量**双重约束——嘴里塞包子讲不了长句，15 秒也塞不下 80 字台词。字数上限查「对白字数科学档位」表，超出 = 必拆。

| 错误（声源不匹配）| 正确（声源匹配）|
|---|---|
| 嘴里塞着包子讲 4 句完整话 | 嘴里塞着包子只讲 1 句短台词 + 中途吞咽 |
| 嘴里含水说话清楚流利 | 嘴里含水只发"嗯嗯"含糊音 |
| 闭着嘴发声 | 必须张嘴才能发声 |
| 跑动时清晰台词 | 跑动时只能短促喘气 |
| 睡着时说话 | 睡着时只能"嗯"或梦话 |
| 边吃边讲长台词 | 边吃边讲短句 + 咀嚼音贯穿 |
| 戴口罩说话 | 戴口罩只发闷声 |
| 转头背对说话 | 背对只能听到闷声+音量低 |
| 中间打断说话 | 被打断后只能半句+余音 |
| 边咳嗽边说话 | 边咳边说只能断断续续+气声 |

**自检问**："这个声音的物理来源能支持这个内容吗？" + "这句话在这个镜头时长里能说完吗？"（字数超档 → 拆句/拆镜/改旁白）

#### 🚨 对白字数科学档位（2026-08-10 新增：按类型限字数，科学推导）

> **原理**：中文自然语速 200-260 字/分钟（情绪戏更慢 160-200，冲突戏更快 260-300）。**台词不能占满整段时长**——必须留气口（每句停顿 0.3-0.5s）、对方反应、动作表演、环境声。台词实际占用比：独白/慢戏 50-60%、对话 60-70%、冲突 65-75%。
> **公式**：字数上限 = 时长(秒) × 语速档(字/分钟) ÷ 60 × 台词占时比。下表按 15 秒基准，其他时长按比例缩放。

| 类型 | 语速档 | 台词占时比 | 15s 安全上限 | 15s 绝对上限 | 节奏 |
|---|---|---|---|---|---|
| 慢节奏/氛围/独白 | ~160 字/分 | 50% | **20-25 字** | 40 字 | 大停顿、留白、气口 |
| 正常对话/情感戏 | ~200 字/分 | 60% | **30-35 字** | 50 字 | 表演+信息平衡 |
| 快节奏/冲突/争吵 | ~240 字/分 | 65% | **40-45 字** | 60 字 | 紧迫、信息密集 |
| 信息密集/转场/交代 | ~260 字/分 | 70% | **45-55 字** | 65 字 | 极限值，表演要快 |

**三档判定**：
- 字数 ≤ 安全上限 → ✅ 直接过
- 安全上限 < 字数 ≤ 绝对上限 → ⚠️ 警告：必须注明气口/停顿/语速，让 H3 压着说
- 字数 > 绝对上限 → ❌ 必拆：拆句（两句之间给反应镜）/ 拆镜（换景别承接）/ 改旁白（画外音分担）

**反推时长公式**：所需秒数 = 字数 ÷ (语速档÷60) + 气口数 × 0.3~0.5s + 反应停顿 0.5~1s。算出后对照镜头时长，不够就加长或减字。

**群体戏再砍 30%**：2 人对戏按表走，3 人对戏上限再乘 0.7（每人分时间，还得抢话头）。

**⚠️ 物理状态修正**：嘴里塞东西/含泪/边跑边说/咳嗽 → 字数按档位再砍 50-70%，只留短句（衔接红线 1 声源物理）。

#### 红线 2：道具凭空出现 / 凭空消失

**铁律**：人物手里/身上/场景里的道具必须有**前世今生**——从哪来、怎么出现、用完放哪。

| 错误 | 正确 |
|---|---|
| 关门时钥匙已在口袋 | 掏出钥匙→开门→进门后放回口袋 |
| 说话时手里突然多出东西 | 拿东西是连贯动作"伸手→拿→收回" |
| 用完的道具还在手里 | 用完放下"放桌上/收回腰间/扔地上" |
| 设定段锁死状态 vs 分镜改变状态 | 设定段只锁"恒定"、分镜处理"变化" |
| 远处道具突然出现在近景 | 近景用之前先在远景/中景建立道具存在 |
| 中途换道具没交代 | 换道具"放下旧的→拿起新的" |
| 多人之间传递道具没交代 | 传递是连贯动作"A 递出→B 接过" |

**自检问**："这个道具之前在哪？现在怎么出现的？用完放哪？"

#### 红线 3：近景-全景人物凭空出现（人物在场性铁律）

**铁律**：所有人物/核心道具必须在**第一个镜头建立**，后续只做景别推进。

| 错误（凭空出现）| 正确（人物在场性建立）|
|---|---|
| Shot 1 全景无人物 → Shot 2 近景突然有人 | Shot 1 全景必须含后续关键主体 |
| Shot 2 近景虚化无背景 → Shot 3 全景突然有人群 | Shot 2 虚化背景中可隐约看到人影移动 |
| Shot 1 没人说话 → Shot 2 突然有人开口 | Shot 1 必须先建立说话人在场 |
| 道具从无到有 | 道具第一次出现必须有建立镜头 |
| 镜头跳到新空间没过渡 | 新空间镜头开始要有建立（先全后近）|
| 转场后人物位置不明 | 转场后第一个镜头先建立人物位置 |

**自检问**："这个人物/道具之前在哪一镜建立的？"

#### 红线 4：180 度轴线跨越（对白戏/双人对戏实测：3 镜机位方位不一致）

**铁律**：多镜人物对话/互动，机位轴线必须固定一侧，**不反打**。

| 错误（轴线跨越）| 正确（轴线固定）|
|---|---|
| Shot 1 在人物 A 背后 → Shot 2 突然在 A 正面（反打）| 全程在 A 背后同侧（如肩后侧 30 度方位）|
| Shot 1 在左侧拍 → Shot 3 跑到右侧拍 | 全程固定左侧或右侧 |
| 人物 A 看右 → Shot 2 A 看左 | A 的视线方向不能跨镜反方向 |
| 多人对话 180 度飘移 | 多镜固定在两人连线同一侧 |
| 双人对话 5 个镜头换 4 个机位 | 双人对白固定一个机位（肩后侧 30 度）|

**自检问**："这一镜的机位和上一镜在轴线同一侧吗？"

#### 红线 5：物理位置矛盾（古风戏/悬吊戏/被绑戏/被推戏/被打戏实测）

**铁律**：人物/物体的**空间位置**必须有物理来源。

| 错误（位置矛盾）| 正确（位置有来源）|
|---|---|
| 被吊起但身体自然站立 | 被吊起 → 双脚离地 + 躯干垂直 + 肩耸起 |
| 背对镜头但看着镜头方向的人 | 背对镜头 → 看不到脸 → 只能看到后脑勺 |
| 远处人物突然在近景说话 | 远处人物要变近景必须有运动过渡（走近/跑来）|
| 飘落时身体前倾落地 | 飘落是垂直下降 = 双脚同步触地 |
| 跳落时双脚同步触地 | 跳落是斜下方 = 单脚先触地 |
| 被打但身体不动 | 被打时身体因冲击后退 + 头偏 + 表情痛 |
| 站起时瞬间站直 | 站起是连贯动作"屈膝→发力→躯干→头抬起"|
| 坐下时瞬间坐到底 | 坐下是连贯动作"弯腰→屁股下落→靠背" |
| 推门时门自己开 | 推门是连贯动作"伸手→触门→用力→门开" |
| 落地无缓冲 | 落地必须有屈膝缓冲（高处落地更明显）|

**自检问**："这个位置状态之前是怎么形成的？符合物理吗？"

#### 红线 6：束发/发型与风的矛盾（古风戏/仙侠戏实测：束发戴冠不能被风吹动）

**铁律**：人物发型决定什么能被风吹动。

| 发型 | 能被风吹 | 不能被吹 |
|---|---|---|
| 散发 | 全部发丝 | 无 |
| 半束发 | 散开部分 | 束起部分 |
| 束发戴冠 | 系带、玉冠坠饰 | 束起的发丝 |
| 双丫髻 | 双髻上的丝带 | 双髻本身 |
| 道士发髻 | 发髻上的木簪系带 | 发髻本身 |
| 披发戴斗笠 | 斗笠系带 | 斗笠压住的头发 |

**自检问**："这个人物的发型允许这个元素被风吹动吗？"

#### 红线 7：动作/表情/情绪不协同（古风戏/对话戏/喜剧戏实测：尴尬时的微表情群）

**铁律**：强烈情绪必须有**协同反应**——单一表情不足以表达复杂情绪。

| 错误（情绪单一）| 正确（情绪协同）|
|---|---|
| 痛苦但面无表情 | 痛苦时眉头皱+嘴角下拉+瞳孔缩+呼吸急 |
| 尴尬时面无表情 | 尴尬时苦笑+眼神飘忽+喉咙微动+手部抓物体 |
| 惊讶时眼睁大但嘴不动 | 惊讶时眼睁大+嘴微张+眉毛上挑+手部微顿 |
| 恐惧时面无表情 | 恐惧时瞳孔扩大+嘴唇颤抖+脸苍白 |
| 愤怒时只皱眉 | 愤怒时眉头压低+牙关咬紧+鼻翼扩张 |
| 紧张时手不动 | 紧张时手会无意识抓身边物体（袖口/剑柄/衣角）|
| 深情时只说台词 | 深情时深吸气+胸口起伏+第一字发颤+末字气声 |
| 惊吓时只张嘴 | 惊吓时眼睛睁大+短促吸气+身体本能后退 |

**自检问**："这个情绪的协同反应写全了吗？（表情+呼吸+身体+手部）"

#### 红线 8：因果关系断裂（短剧对白戏/产品片/叙事片实测：上镜的事下镜接不住）

**铁律**：镜头之间必须有**因果链**——上镜发生的事，下镜必须有结果或延续。

| 错误（因果断裂）| 正确（因果延续）|
|---|---|
| Shot 1 角色拿起剑 → Shot 2 剑突然消失 | Shot 1 拿剑 → Shot 2 持剑或放下（连贯）|
| Shot 1 角色进屋 → Shot 2 角色在屋外 | Shot 1 进屋 → Shot 2 在屋内（空间延续）|
| Shot 1 角色说"我去 X" → Shot 2 角色在 Y | Shot 1 说完 → Shot 2 走向 X 或到达 X |
| Shot 1 角色受伤 → Shot 2 角色无伤 | Shot 1 受伤 → Shot 2 有伤口或包扎痕迹 |
| Shot 1 白天 → Shot 2 没交代突然夜晚 | Shot 1 白天 → Shot 2 至少有时间过渡（黄→暗）|
| Shot 1 角色独白 → Shot 2 没人接话 | Shot 1 独白 → Shot 2 有人接话或独白延续 |
| Shot 1 情绪高潮 → Shot 2 突然平静 | Shot 1 高潮 → Shot 2 余波（喘息/余光/回响）|

**自检问**："上镜发生的事，下镜有结果或延续吗？"

## 🚨 统一自检流程（2026-08-09 整合：把分散的 3 步/8 条/5 条合并）

> **问题**：minimax skill 有 4 套检查项（3 步动作链 / 8 红线避坑 / 5 步自检 / 交付格式）= **16 个检查项**（太分散，AI 写 prompt 时不知道先用哪个）。  
> **本节把 4 套合并为「三阶段流程」**：**阶段 1 写作时（避坑 8 红线）+ 阶段 2 写完后（自检 8 步）+ 阶段 3 交付（5 件套）**。

### 阶段 1：写作时实时避坑（边写边避，8 红线）

**写每一镜时**，**主动对照 8 红线**（不写完才检查）：

| # | 红线 | 边写边问 |
|---|---|---|
| 1 | 声源不匹配 | 嘴里塞包子能讲 4 句完整话吗？（不能）这镜时长能说完这句吗？（超档拆句）|
| 2 | 道具凭空 | 这个道具之前在哪？现在怎么出现的？|
| 3 | 人物凭空出现 | 这个人物在第一镜建立了吗？|
| 4 | 180 度轴线 | 这镜机位和上镜在轴线同一侧吗？|
| 5 | 物理位置矛盾 | 被吊起的人会自然站立吗？（不会）|
| 6 | 发型与风 | 束发戴冠能被风吹动吗？（不能）|
| 7 | 情绪不协同 | 尴尬时只有表情没有袖口捏皱？（不够）|
| 8 | 因果关系断裂 | 上镜发生的事，下镜有结果吗？|

**P0/P1 优先级**：见上 8 红线章节末（P0 = 1/2/3/4/8，P1 = 5/6/7）。

### 阶段 2：写完后自检（8 步检查清单）

**写完 prompt 后**，**按 8 步自检**（一次性扫完）：

| 步 | 检查项 | 通过标准 |
|---|---|---|
| 1. 物理一致性 | 8 红线全过 + 对白字数按档不超 | 8 红线全过 / 字数 ≤ 安全上限 / 漏 X 条 |
| **2. 故事/视觉/情绪** | 风格段写高级写法 4 层 | 色彩/光学/焦点/氛围落点 4 要素齐 |
| **3. 镜头设计** | 180 度轴线不跨越 + 景别切换有逻辑 | 建立→递进→高潮 3 段式 |
| **4. 运镜科学** | 每镜运镜有"为什么"+ 高级运镜用在转折点 | 运镜=故事的视觉化 |
| **5. 声音三层** | 台词三行块（`Sx 角色名台词（语气）：` / 行首 `<d>[中文]` / 收尾动作）+ overall_soundscape + BGM N/A | 3 段齐 + 9 元素按阶段 |
| **6. 因果叙事** | 因果叙事链 + 8 红线因果检查 | 上镜→下镜有结果/延续 |
| **6.5. 因果·分镜·动作逻辑**（2026-09-14 用户强调必加） | 逐镜问三件事：**① 因果关系**（事件有没有因由、前一镜发生的事后一镜是否有结果）**② 分镜逻辑**（景别/机位/运镜是否服务叙事递进，切镜有没有原因，不是为切而切）**③ 动作逻辑**（连续动作是否符合现实顺序：前提先满足→再动作→落点；人物姿态/道具状态跨镜延续不跳变） | 三问全过；发现空泛处（如镜头干跟拍无动机、动作缺前提、切镜无叙事目的）即标记为待修，补实后再交付 |
| **7. 内部标记污染** | prompt 内 0 个 8.8/8.9/4 层/1+1/P0/自检问 | 5 步净化（见铁律 #1） |
| **8. 交付格式（5 件套）** | prompt / 自检 / 修复 / 新增矛盾 / 评估检查轮（互不混排）| 详版见「交付格式（5 件套，唯一定义处）」|

| 旧 4 套 | 整合到新 2 阶段 |
|---|---|
| 3 步动作链（前提/顺序/落点）| → 阶段 2 步 1（物理一致性 = 8 红线，含 3 步）|
| 8 红线避坑 | → 阶段 1（边写边避）+ 阶段 2 步 1（写完扫一遍）|
| 5 步自检（选题→人物→分镜→声音→自检）| → 阶段 2 步 2-6（每步对应）|
| 交付格式（旧 4 件套）| → **阶段 3：交付（5 件套）** |

**整合后**：从 16 个检查项简化为 **8 红线（边写边避）+ 8 步（写完扫）+ 5 件套（交付）** = 分布到 **3 个清晰阶段**。

### 阶段 3：交付（**5 件套**；详版见「交付格式（5 件套，唯一定义处）」）

> ⚠️ 本表是**速查**；件数、每件内容与「整段交付铁律」以「交付格式（5 件套，唯一定义处）」为准。

| 件 | 内容 | 在哪 |
|---|---|---|
| 1 | 干净的 H3 prompt | 第一段 |
| 2 | 自检结果 | 第二段（独立，不混在 prompt 里）|
| 3 | 修复了什么 | 第三段 |
| 4 | 本次新增的物理矛盾 | 第四段 |
| 5 | **评估检查轮**（交付后自动跟一轮，不等用户点"评估"） | 第五段：读回门禁原文 + 硬问句逐条查 + 打分 + 必修项（附可替换句）|

### 实战节奏（写一条 prompt 的完整流程）

```
1. 写第一镜前：先看 8 红线表（知道要避什么）
2. 写每镜时：对照 8 红线（边写边避，不要写完才扫）
3. 写完 3 镜后：跑 8 步自检（一次性扫完）
4. 通过后：**5 件套交付**（prompt + 自检 + 修复 + 新增矛盾 + 评估检查轮）
```

**🚨 道具脱钩铁律（2026-08-05 用户实测：人物设定锁死状态 vs 分镜状态变化冲突）**：

**问题**：人物设定段写"脚穿绿色塑料凉鞋"，分镜让他"弯腰穿鞋"→ 模型听设定的，生成"穿着鞋下床再穿一次鞋"。根因：**人物设定 = 恒定状态，分镜 = 状态变化，两个信源打架，模型听设定段**。

**铁律：分镜里要"改变状态"的道具（穿/脱/拿起/放下），绝不能锁在人物设定段**——要放到场景段作为道具，人物设定段只锁"始终不变的"。

```text
❌ 人物设定：...脚穿绿色塑料凉鞋。分镜：他弯腰把凉鞋套在脚上。（设定=已穿，分镜=在穿 → 模型生成"穿鞋下床再穿一次"）
✅ 人物设定：...刚睡醒时赤脚。（锁定光脚状态）
✅ 场景：炕沿下方地上摆着一双绿色塑料凉鞋。（鞋=场景道具，锁定外观与位置）
✅ 分镜：赤着脚跳下炕，此刻脚上没穿鞋，弯腰捡起那双凉鞋套在脚上，才踩出"啪嗒"声。（变化从"没穿"到"穿"，动作链完整）
```

**检查**：写完 prompt 后扫一遍——①人物设定段有没有锁住分镜要改变的状态？②要变的东西是否已作为道具放进场景段？③"此刻/已经/才"等状态词是否显式声明了当前状态？

**🚨 人物在场性铁律（2026-08-05 用户实测：建立镜头必须包含后续关键主体）**：

**问题**：Shot 1 只拍空炕+光柱（人物没入画），Shot 2 近景突然出现孩子在床上 → 人物凭空出现，逻辑断裂。根因：**建立镜头没包含后续镜头的主角**，模型在 Shot 1 生成时不知道床上有人。

**铁律：第一个（建立）镜头必须把后续要出现的关键主体（人物/核心道具）同时建立入画**——后续镜头只做"景别推进"（放大聚焦），不能"无中生有"。

```text
❌ [Shot 1] 全景：晨光照在空炕上，浮尘飘动。（人没入画）
   [Shot 2] 近景：小毛睁开眼睛。（人凭空出现 = 断裂）
✅ [Shot 1] 全景：炕上侧躺着熟睡的小毛，光柱打在他身上。（人物建立）
   [Shot 2] 近景：小毛睁开眼睛。（只放大聚焦，不新增主体 = 连贯）
```

**检查**：写完分镜后自问——①第一个镜头里，后续所有镜头的主角都在画面中吗？②每个镜头的"新主体"出现前，有没有镜头提前建立它？③景别推进是否只做放大，不做"无中生有"？

**🚨 新主体入场必须有"进入动作"（2026-08-05 吸收自粉色气泡水广告）**：

**问题**：新人物/新道具如果"直接出现在画面里"而没有进入过程 = 凭空出现。**解法：给新主体一个"入口动作"**——从门口走进来、拉开门出现、从画外入画，让入场有路径。

```text
❌ 少女把粉色气泡水放在桌角。（少女直接出现在桌前 = 凭空）
✅ 一名短发少女从门口轻手轻脚走进来，走到空课桌前，把粉色气泡水放在桌角。（有进入动作）
❌ 少年出现在门口。（直接出现）
✅ 教室推拉门被少年拉开，一个模糊剪影出现在门口。（拉门 = 入场动作）
```

**检查**：每个首次出现的主体，问"他怎么进入画面的？"——有入口动作（走进来/拉门/入画/推门）✅；直接冒出来 ❌，补一个入场动作。

### 说话人 ID 系统（(S1)/(S2)）
- 发声者用稳定 ID，跨镜头不变（对应中文模板的角色代号）
- **说话人归属写进台词 delivery 行的开头**（`S1 林婉台词（轻蔑、句尾下压）：`）——多角色对白戏的「谁读谁的」**只认这一行**，写在台词表里不算（2026-10-04 用户实测定稿）
- **台词版式 = 三行块**：delivery 行 / 行首 `<d>` 行 / 收尾动作行（见「🚨 台词标签固定版式」）
- 台词格式 `<d>[语言] 原文</d>`，**原文逐字保留不翻译**
- 画外音必须声明"嘴唇闭合"（lips remain closed）
- 跨镜头台词用 `<scenetrans>`，被截断用 `<cutoff>`

### 中文版正反打示例（官方结构 + 中文表达，2026-08-03 验证）

> 官方正反打结构（建立→A特写→B反打→A反应→全景收尾）用中文重写。正反打 = 两人对话时镜头在双方之间来回切，15 秒配 5 镜。

```text
8K RAW 超高清，仙侠短剧场景，总时长15秒，文生视频。
人物设定：白发剑仙（S1），师父，老者，银发束冠，面容清癯，身着白色锦袍，声音低沉沙哑、语速平缓、无情绪起伏。弟子（S2），青年，面色苍白眉骨一道细疤，身着深蓝长袍，声音清亮平静、语速慢、几乎无波澜。
场景：飞升前夜，山巅古松下，云雾在脚下翻涌，月光冷白，两人相距三步相对而立。

镜头1（0-3秒，大全景，缓缓推近）：白发剑仙（S1）与弟子（S2）站在山巅古松下，衣袍被夜风吹动，镜头以中等幅度缓慢推近两人。画面冷色调，氛围肃穆。

镜头2（3-6秒，特写，固定）：剑仙（S1）垂着眼，以低沉沙哑的嗓音缓缓开口 {你恨为师么？}。话音落下嘴唇轻合，几缕白发被风吹起。

## 🎬 剪辑逻辑与景别运镜匹配（2026-08-03 用户强调：决定短剧视觉效果好坏，必加必验证）

> **核心原则**：景别切换不是随机的，**每个切镜都服务于叙事目的**（信息增量/情绪推进/关系呈现）。运镜必须与景别匹配（大景别=有运动空间，小景别=克制）。这是 AI 短剧从"能看"到"好看"的分水岭。

### 1. 景别五层级的叙事功能

| 景别 | 叙事功能 | 典型场景 | 适合运镜 |
|---|---|---|---|
| 远景 | 交代环境/时间/氛围，人物小 | 开篇、转场、收尾 | 缓推、缓拉、横移 |
| 全景 | 人物全身+空间关系，谁在哪儿 | 对峙、相遇、离场 | 缓推、缓拉、环绕 |
| 中景 | 腰部以上，动作+对话兼顾 | 对话主体、动作段落 | 缓推、跟随 |
| 近景 | 胸部以上，情绪开始显露 | 对话反应、情绪转折 | 固定、极缓推 |
| 特写 | 局部（脸/手/道具），情绪炸点 | 台词关键句、反转点 | **固定为主**，极缓推 |

**铁律**：景别越小，运镜越克制（特写几乎只能固定或极缓推，否则信息被运动淹没）；景别越大，运镜空间越大（全景/远景可缓推缓拉环绕）。

### 2. 景别切换的剪辑逻辑（为什么这么切）

**同一逻辑段内，相邻镜头景别必须"跳级"或"进级"，不能同级跳切**：
```
❌ 中景 → 中景（同级跳切=跳轴感，观众困惑）
✅ 全景（建立关系）→ 中景（动作）→ 特写（情绪炸点）
```

**五种常用剪辑逻辑**：

| 逻辑 | 结构 | 用途 |
|---|---|---|
| **推进式** | 全景→中景→近景→特写（逐级逼近） | 情绪升级、悬念逼近 |
| **后退式** | 特写→近景→中景→全景（逐级拉远） | 揭示环境、情绪冷却、反转揭底 |
| **正反打** | A特写 → B反打特写 → A切回 → B切回 | 两人对话（视线互相牵制） |
| **插入式** | 中景 → 特写道具 → 回中景 | 关键信息（信/刀/药）、时间流逝 |
| **环绕式** | 全景环绕 + 关键点停特写 | 展示空间、对峙张力 |

**切镜的 4 个合法理由**（至少占一个才切）：
1. 信息增量（新的画面信息，如道具/新人物）
2. 情绪推进（从平静到爆发，景别收窄）
3. 视角切换（A看B → 切B反应，正反打）
4. 节奏控制（快切=紧张，慢切=沉重）

**🚨 景别服务情绪，不套固定骨架（2026-08-05 用户强调：先全景后全景是死板套路）**：

**问题**：惯性用"全景开头建立 + 全景收尾余韵"的固定骨架，不管内容需不需要——情绪片也被迫拉远收尾，压抑感泄掉。**景别不是模板，是服务内容的工具**。

**铁律：先问"这段情绪需要什么景别"，再决定开/收，不预设骨架**：

| 需要什么 | 用什么景别 | 例子 |
|---|---|---|
| 沉浸进情绪（不需要环境信息） | **特写直接开场** | 深夜破功：桌面/手机/颤抖的手入画 |
| 需要环境信息 | 全景/远景建立 | 战场对峙、空间关系 |
| 情绪收束在细节 | **特写定格/渐暗收尾**（不拉远） | 泪落在账单上+画面暗下去 |
| 需要抽离/余韵 | 才拉远收尾 | 大远景定格（黄昏剪影） |

**反例（套路版，勿用）**：
```text
❌ 情绪片：全景建立（环境）→ ... → 近景拉远收尾（被迫余韵）——环境没信息量、拉远泄掉压抑感
✅ 情绪片：特写开场（手机/账单/手）→ 近景（对话）→ 特写（破功）→ 特写定格+渐暗——全程收紧
```

**检查**：写完景别曲线后问——①这个开场镜头提供了必要信息吗？还是为了"建立"而建立？②结尾拉远是在服务情绪（抽离/揭示），还是惯性收尾？③整条景别曲线是"情绪驱动"还是"模板驱动"？

### 3. 正反打规则（两人对话的标准切法）

```
Shot 1: 全景/中景（建立：两人同框，谁在左谁在右）
Shot 2: A 特写（说话，视线方向朝 B）
Shot 3: B 反打特写（回应，视线方向朝 A——必须与 Shot 2 的视线方向相反/镜像）
Shot 4: A 切回（反应，无需台词）
Shot 5: 全景（收尾/关系定格）
```

**正反打三铁律**：
1. **180 度轴线**：两人对话，机位只能站在轴线一侧，反打不过轴线（否则视线方向会"跳"，观众瞬间出戏）
2. **视线匹配**：A 看右，B 必须看左（或反之），镜像关系不能乱
3. **反打景别配对**：A 特写 → B 至少近景/特写（配对景别，不能 A 特写 B 全景）

**AI 短剧实用简化**：用"镜像视线 + 配对景别"两条就够了，轴线靠台词前后顺序自然维持。

### 4. 运镜与景别匹配速查

| 运镜 | 适配景别 | 情绪/功能 |
|---|---|---|
| 缓推（Push In） | 全景→特写均可 | 逼近、聚焦、紧张感 |
| 缓拉（Pull Out） | 特写→全景 | 揭示、抽离、反转揭底 |
| 环绕（Arc） | 全景/中景 | 对峙张力、展示空间 |
| 跟随（Tracking） | 中景/全景 | 移动中的动作（追逐/走路） |
| 横移（Truck） | 全景/远景 | 环境展示、多主体并列 |
| 升降（Pedestal） | 全景/远景 | 气势、空间感 |
| 固定（Static） | 特写/近景 | 情绪炸点、台词关键句、克制 |
| 微晃（Shake Slightly） | 近景/特写 | 紧张、不安、失控感 |

**匹配铁律**：情绪越重→景别越小→运镜越静（固定/极缓）；信息越多→景别越大→运镜越动（缓推/环绕）。

### 6. 镜头时长分配规律（2026-08-03 用户强调：时长按镜头需要定，不是固定 3 秒）

> **核心**：镜头时长 = 信息量 + 情绪权重 + 留白需求。不同功能镜头时长天然不同，均匀分配=剪辑感生硬。

**按镜头功能定时长**：

| 镜头功能 | 建议时长 | 原因 |
|---|---|---|
| 建立（全景/远景） | 4-6 秒 | 环境信息量大，观众需要时间读 |
| 对话（中景/近景） | 按台词长度：短台词 2-3s，长台词 4-5s | 声音+画面同时处理，不能太挤 |
| 反应（近景/特写） | 2-3 秒，关键反应可 1.5-2s | 反应镜头要"快切"才有冲击，拖长泄气 |
| 反转/炸点（特写） | 台词后留白 1-2 秒 | 让观众消化反转，不能说完就切 |
| 收尾（全景/远景） | 3-5 秒 | 余韵，让情绪落地 |
| 动作戏（追逐/打斗） | 快节奏 1-2s/镜 | 快切制造紧张 |

**15 秒总时长铁律**：所有镜头时长之和必须严格等于总时长（15s），起止时间连续无缝隙。

**节奏验证**：写完镜头时间后自问——①建立镜头是否给了足够时间读环境？②反应镜头是否短促有力？③反转镜头是否有留白？④收尾是否留了余韵？

### 7. 15 秒短剧的镜头节奏模板

```
15 秒 = 4-5 镜，时长按功能分配（非均匀）：
建立(4s) → 对话(3s) → 反应(2s) → 反转+留白(3.5s) → 收尾(2.5s)  ≈ 15s
节奏：建立(全景/中景) → 推进(中景/近景) → 炸点(特写，固定) → 收尾(全景)
```

**情绪曲线与景别同步**：平静段用中景/全景（舒展），高潮段用特写+固定（收紧），收尾回到全景（释放）。

### 8. 质量自检（剪辑逻辑专项）

- [ ] 相邻镜头是否"跳级"切换（无同级跳切）
- [ ] **景别是否服务情绪而非套固定骨架**（先问"这段需要什么景别"再定开/收：沉浸=特写开场，需环境=全景建立，情绪收束=特写定格/渐暗，需抽离才拉远；检查开场是否提供必要信息、结尾拉远是否惯性收尾）（2026-08-05 新增）
- [ ] 每个切镜是否有 4 大理由之一（信息/情绪/视角/节奏）
- [ ] 正反打是否满足镜像视线 + 配对景别
- [ ] 特写是否用固定/极缓推（没有大运镜）
- [ ] 全景/远景是否承担建立/收尾功能
- [ ] 运镜是否与景别匹配（小景别克制、大景别有运动）
- [ ] 15 秒是否控制在 4-5 镜，时长按功能分配（建立 4-6s / 反应 1.5-3s / 反转留白 / 收尾余韵）
- [ ] 镜头时长之和是否严格等于总时长（无缝隙无溢出）
- [ ] 情绪曲线是否与景别推进方向一致（升=收窄，降=拉远）

### 3.4 情绪方向与可观察表现（演技控制升级）

**核心洞察**：只写"紧张、温馨、压抑"等情绪词，H3 能理解方向但**表演方式会自由发挥**。要稳定控制演技，必须写**可观察表现**——眼神、眉头、嘴角、呼吸、视线、手部动作等直接可见的细节。

不必罗列所有面部细节。**单次情绪转折选 2-4 个最明确的表现即可**；只有多次转折才按触发事件分阶段描述。

**单次情绪转折模板**：
```
整体情绪从<起始情绪>转为<结束情绪>。
发生<触发事件>后，<主体>先出现<即时可观察反应>。
随后，<眼神、眉头、嘴角、呼吸、视线或手部动作>逐渐发生<变化>。
最终，<主体>以<克制或明确的外在表现>表达<目标情绪>。
```

**多阶段情绪模板（按触发事件递进）**：
```
听到或看到<第一个触发事件>时，<主体的第一个可观察反应>。
当<第二个触发事件>出现后，<主体的表情、视线或呼吸发生的变化>。
确认<关键信息>后，<主体试图克制或掩饰的情绪>通过<可观察表现>逐渐显现。
最终，<主体的最终动作、表情或说话方式>。
```

**示例**：
```text
整体情绪从平静转为震惊。听到那句话后，女孩先是愣住，端杯的手停在半空。
随后她的眼神从桌面缓缓移向对方，眉头微蹙，呼吸明显加重。
最终她放下杯子，嘴角扯出一个勉强的笑，声音却发紧 <d>[中文] 所以……你早就知道了？</d>
```

⚠️ 与语气标注系统互补：**语气管声音**（全参考模式 `<d>` 内台词 + delivery，普通模式 `{}` + 语气），**可观察表现管画面**（表情/动作/呼吸）——两者都写，声画才一致。

#### 🚨 情绪具象化铁律（2026-08-11 用户原话吸收）

> 用户原话：\"说白了我就想要达到这种效果：【情绪具象化】\"。这是**所有文戏/情绪戏情绪描写的总开关**，优先级高于后面所有情绪章节——写任何情绪前先过这条铁律。

**铁律：情绪词可以放在前面定调（如\"重逢的惊喜\"\"压抑的悲伤\"），但情绪的细腻表现必须在分镜里用物理信号写出来**——情绪词只负责告诉模型\"这段是什么情绪\"，不能替代表演细节；只写\"他很生气\"没有下文 = 不合格。

- **面部**：眉毛微皱或舒展、瞳孔收缩或放大、眼睑轻垂、鼻翼翕张、嘴角上扬或紧抿、喉结滑动
- **肢体**：无意识小动作（摩挲衣角、轻触颈侧）、身体重心转移、脊背松弛或挺直、手指舒展或收拢

**使用方式**：写任何情绪 → **前面（开头总声明/镜头前）先给情绪词定调**（惊喜/悲伤/恐惧/激动）→ **分镜里再写物理信号**：选 2-4 个协同信号（面部为主 + 肢体为辅）→ 写成\"部位+动作\"。情绪词定调在前，物理表演在后，两者都要。

```text
✅ 重逢的惊喜与哽咽（开头定调）——她眼睑微微撑大，眼眶迅速泛起水光，嘴角想扬起来却轻轻颤抖，喉结不明显地滚动了一下。（分镜物理信号）
✅ 压抑的悲伤（开头定调）——眼睑轻垂、嘴角紧抿、喉结滑动，指尖无意识摩挲衣角。（分镜物理信号）
❌ 他很生气（只有情绪词，无表演细节 = 模型自由发挥）
```

**与相邻章节的关系**：
| 章节 | 分工 |
|---|---|
| **情绪具象化铁律（本节）** | 总开关：任何情绪都转成物理信号，禁止情绪词 |
| **情绪三阶段演绎法** | 一次情绪转折的表演链：本能→台词→余韵 |
| **特写微表情弧线法** | 特写里 15 秒的表情演替：真→假→空 |

#### 🎭 情绪三阶段演绎法（2026-08-05 用户提供方法论：情绪+表情要有演技级描写）

> **核心技巧**：情绪不是"写个词"（紧张/生气），而是拆成**三阶段表演链**——**本能反应（身体先于意识）→ 台词演绎（带着情绪的声线）→ 余韵收尾（情绪残留在身体上）**。同一句台词，不同情绪 = 完全不同的演法（语速/音调/咬字/气声 + 微表情组合拳）。
>
> ⚠️ **这是方法论，不是固定模板**：示例只是展示写法，写任何情绪都按"三阶段 + 可观察表现 + 声线区分"来编，不要死记九种。

**套用方法**：确定情绪 → 拆三阶段 → 每阶段选 2-4 个可观察表现（眼神/眉/嘴/手/呼吸/身体重心）→ 台词带演绎（语速/音调/气声）→ 写进分镜（用"先…之后…随后…"连接）。

**示例（受惊慌促，展示写法）**：
```text
先：突遭惊吓后肩膀猛地一颤，身体下意识向后撤半分，眼睛瞬间睁大、瞳孔扩张，嘴微张，呼吸骤停半秒。
随后：带着慌促的气音脱口而出 "你干嘛？"，语速极快、音调偏高、声音微颤（被吓到的本能反应）。
最后：手轻抚胸口，胸口快速起伏喘气，眼神带余惊，眼睑微颤，慢慢平复呼吸。
```

**对照（同句台词"你干嘛？"，两种情绪的声线差异）**：
| 情绪 | 0-2s 本能反应 | 2-5s 台词演绎 | 5-7s 余韵收尾 |
|---|---|---|---|
| **受惊慌促** | 肩猛颤、后撤、瞳孔扩张、呼吸骤停 | 气音、极快、音调高、微颤 | 抚胸口喘气、余惊、眼睑微颤 |
| **清冷疏离** | 笑意瞬间收平、眼神温度骤降、瞳孔微缩 | 平稳匀速、无起伏、咬字清晰、无情绪 | 肩背挺直、呼吸平稳、无多余表情 |

**⚠️ 使用规则**：
1. **三阶段递进不可乱序**：本能反应 → 台词 → 余韵（身体先于意识，情绪最后留在身体上）
2. **同一台词不同情绪 = 不同声线**：语速/音调/咬字/气声是区分关键，台词必须带演绎
3. **微表情是"组合拳"**：选 3-5 个协同（眼神+眉+嘴+手+呼吸），不堆 8 个
4. **适合文戏/情绪戏**；动作戏/纪实直接动作，不用三阶段

#### 🎭 特写微表情弧线法（2026-08-11 吸收自 Context-IR 案例）

> **来源**：用户提供的 Context-IR 输出案例（原始输入"一个女生在听到'开始'后，先露出纯真甜美的笑，随后笑容因强忍悲伤而变得疲惫、眼神空洞"→官方三段式 p…

**核心洞察**：特写文戏的"戏"不在台词，在**一张脸的 N 阶段演替**——武戏靠动作链，文戏靠微表情链。观众盯的是 15 秒里表情怎么从真到假再到空。

**❌ 反例（情绪形容词，H3 自由发挥）**：笑容因强忍悲伤而疲惫、眼神空洞
**✅ 正例（物理可观测信号，H3 可执行）**：嘴角微颤 → 喉咙吞咽 → 笑完全垮掉、肌肉显沉重 → 眼神失焦空洞泛泪 → 肩膀下沉约一寸

**微表情描写公式**：每个情绪阶段拆成**可观测的物理信号**，用"部位+动作"写，不用情绪词：

| 部位 | 物理信号写法（示例） |
|---|---|
| 眼睛 | 眼神光亮起/眼角皱起/瞳孔缩放/失焦/泛泪/眼睑微颤 |
| 嘴角 | 上扬/微颤/僵硬/下拉/抿成一条线 |
| 脸颊/眉 | 脸颊抬起/眉头舒展/压低 |
| 喉咙/呼吸 | 吞咽/吸气/颤抖呼气/重叹 |
| 身体 | 肩膀塌陷/重心偏移/胸口起伏 |

**三阶段弧线结构**（15s 基准，按镜头时长缩放）：

| 阶段 | 时间 | 表情状态 | 身体/声音协同 |
|---|---|---|---|
| ① 触发 | 0-3s | **真表情**（有细节：眼角皱出纹、眼神有光） | 吸气 + 衣料窸窣 |
| ② 强撑 | 3-8s | **假表情**（只剩肌肉硬撑：嘴角微颤、喉咙吞咽） | 颤抖呼气 + 外部干扰（发丝扫脸/耳坠轻晃） |
| ③ 崩塌 | 8-15s | **空表情**（肌肉松垮、眼神失焦泛泪、目光移开镜头） | 重叹 + 肩膀下沉 |

**写法三要素**：
1. **物理动作代替情绪形容词**：嘴角微颤 ≠ 悲伤，眼神失焦 ≠ 疲惫——每个情绪都必须能"被镜头看见"
2. **情绪不是 A→B 直线，是 A→B→回到 A 的躯壳但灵魂抽空**：真笑（有鱼尾纹）→ 假笑（只剩肌肉）→ 空（无表情），不是真笑→哭
3. **三感官通道同步收尾**：视觉（眼神失焦泛泪）+ 听觉（颤抖重叹）+ 动觉（肩膀下沉）——观众同时接收，prompt 三通道分层同步写

**⚠️ 使用规则**：
1. 适合**特写/近景文戏**（哭戏、眼神戏、情绪独角戏）；全景/动作戏不用
2. 每阶段选 2-4 个协同信号，不堆 8 个（同「情绪三阶段」组合拳规则）
3. 时间轴卡 H3 镜头节奏：15s 文戏 = 触发(0-3s) → 强撑(3-8s) → 崩塌(8-15s)，单镜内用"先…之后…随后…"连接
4. 台词照常带语气（`<d>[中文]` 或 `{}`）——微表情链管画面，语气管声音，声画一致

### 3.5 专业摄影术语（通用视觉语言）

H3 能理解中文摄影术语，且**可见结果通常比单独写数值更明确**。光圈/焦距/快门数值可以写，但建议配套可观察描述。

**示例（可直接套用）**：
```
示例1. 浅景深人像，<糕点师>的眼睛和面部保持清晰，身后的玻璃罐和灯光虚化成柔和圆形散景。

示例2. 追随摄影，镜头与<滑板者>同速水平移动，人物保持清晰，街边墙面形成从右向左的水平拖影。

示例3. 黄金时刻，暖色低角度阳光从<登山者>左后方照入，山脊地面形成较长阴影。

示例4. 自然暗角，画面四角逐渐变暗，中心<钢琴演奏者>的亮度和肤色保持正常，不出现黑色边框。

示例5. 甩镜转场，第5秒镜头快速向左横移；前景书架完成整屏遮挡时切换到下一场景，切换后镜头继续保持向左运动和相近速度。
```

**用法**：摄影术语 + 可观察结果配套写。`浅景深` 单独写不如 `眼睛清晰，背景虚化成柔和散景` 明确。

### 3.6 主动拍摄技巧库（2026-08-05 用户强调：焦点切换等专业技巧在适合的片子里使用）

> **区别**：3.5 是被动状态（画面长什么样）；这里是**主动导演动作**（镜头做什么操作）。主动技巧制造"叙事焦点转移"，适合情绪片/广告片/剧情片，**按剧情需要选用，不堆砌**。

| 技巧 | 写法 | 叙事作用 | 适用 |
|---|---|---|---|
| **焦点转换（Rack Focus）** | 镜头焦点从远处的少年迅速转移到近处课桌上的气泡水，远处虚化、近处清晰 | 视线从人到物，揭示关键道具 | 广告/悬念/揭示 |
| **追焦（Follow Focus）** | 镜头跟随奔跑的孩子平移，孩子保持清晰，背景成水平拖影 | 动态主体锁定 | 动作/追逐 |
| **变焦推拉（Zoom Push/Pull）** | 镜头先广角看清全貌，之后缓慢变焦推近人物面部，背景逐渐压缩 | 压迫感/聚焦情绪 | 惊悚/对峙 |
| **甩镜（Whip Pan）** | 第5秒镜头快速向左横移，前景书架完成整屏遮挡时切下一场景 | 转场/时间流逝 | 转场衔接 |
| **慢门拖影（Slow Shutter）** | 夜间车灯在画面中拖出彩色光轨，人物短暂定格清晰 | 城市氛围/时间感 | 夜景/情绪 |
| **低机位仰拍** | 镜头贴近地面仰拍孩子背影，天空占画面上部，人物显得高大 | 童年视角/英雄感 | 怀旧/成长 |

**用法**（Rack Focus 范例，可直接套）：
```text
✅ Scene 04：教室推拉门被少年拉开，一个模糊剪影出现在门口。镜头焦点转换（Rack Focus），焦点从远处的少年迅速转移到近处课桌上的粉色气泡水，阳光正好打在罐身樱花暗纹上。
❌ 镜头焦点切换。（无具体转换路径，模型自由发挥）
```

**⚠️ 使用规则**：
1. **一个镜头一个主动技巧**，不叠加（Rack Focus + 变焦推拉同时 = 画面乱）
2. **技巧必须配可观察结果**（"焦点从 A 转移到 B，A 虚化 B 清晰"）
3. **适合的片子才用**：Rack Focus=广告/悬念，追焦=动作，慢门=夜景——情绪片用 1-2 个点缀，纪实不用

### 3.1 宫格分镜 + 白模参考（多图参考进阶，2026-08-04）

> 来源：Seedance 2.5 官方提示词指南（3.1），用户确认适用 H3。H3 多图参考可接受分镜图/白模图作为参考素材。  ⚠️ **适用边界（2026-08-06 官方吸收补充）**：宫格分镜 = **参考组合技法**，用于"多图参考/分镜规划"场景（文生、需要给模型看整体镜头顺序时）。**…

**宫格分镜**（给整体故事、镜头顺序、大致构图；不适合要求每格细节严格复刻）：

- 建议控制在 **15 格以内**，用简洁线稿或干净示意图，减少文字标注
- 提示词必须**明确读取顺序**，再写每格的主体动作、景别/运镜、最终画风和声音
- 用 H3 官方 `<Picture N>` 语法（宫格图 = storyboard reference，官方 ref 文档示例：`<Picture 3> is a storyboard reference for [Shot 1] and [Shot 2], defining their viewpoint, subject placement, and shot order`）

```text
<Picture 1> 提供<N格宫格分镜>的镜头顺序和大致构图，按照<从左到右、从上到下>的顺序读取，作为 [Shot 1] 至 [Shot N] 的 storyboard reference；不采用图中的<线稿画风、文字标注或占位人物>。
<Subject 1> 是 <Picture 2> 中的<主体A>，<外貌与服装描述>。
<Subject 2> 是 <Picture 3> 中的<关键道具或场景>，<结构、材质或光线描述>。

[Shot 1] <景别、主体动作、场景状态>。
[Shot 2] At MM:SS.mmm，<景别、主体动作、运镜或切换方式>。
……
[Shot N] At MM:SS.mmm，<结束动作和结束画面状态>。
```

**白模参考**（提供运动和空间骨架）：

- 先判断粗粒度 or 细粒度，再写清需要继承的时序、结构、材质和风格
- 粗粒度白模：整体动作/运镜/场景空间粗略骨架 → 需补全具体主体、场景、动作、风格
- 细粒度白模：更具体的主体动作细节和空间结构 → 仍需要写清主体、场景、动作、风格
- ⚠️ 白模视频只给骨架，**必须写清希望生成的主体、场景、动作和风格**，否则模型无内容可渲染

## 🚑 失败处理（2026-08-06 新增）

| 翻车现象 | 原因 | 修复 |
|---|---|---|
| 画面文字错字/变形 | 文字太复杂/未锁位置/标点干扰 | 文字改无标点短词、明确锁位置、减少文字数量（产品片只留 1-2 处）；或文字材质化（作画面元素） |
| 跨镜人物漂移（同人不同脸/服装变） | 文生无锚定 | 改图生（首帧/截帧作参考图）；或每镜重申关键外观特征（外貌+服装+道具） |
| 物体数量漂移（一只杯变两只） | 模型对数量感知弱 | 每镜重申数量 + 空间位置（"案上只有一只青瓷盏"）；动作场景锁空间关系 |
| 比例/画幅错 | 未在 prompt 明确 | 重跑并明确 16:9/9:16，前后端一致 |
| 镜头时长对不上总时长 | 切点超总时长/漏镜 | 用官方切点格式 `At MM:SS.mmm` 逐镜校对，[Shot 1] 无时间戳 |
| 对白嘴型不同步/说错词 | 台词复杂/语气缺失 | 台词口语化缩短；加语气标注系统；长台词拆短句 |
| 台词挤爆镜头（念不完/抢拍） | 对白字数超档 | 按「对白字数科学档位」限字数：拆句、拆镜、改旁白，或加长镜头 |
| 动作顺序不合理（先拔刀后收刀） | 动作链断裂 | 过「动作链逻辑」：每镜动作有上一动作的因 |
| BGM/音效打架 | 多段拼接各自生成音乐 | 多段拼接 BGM 一律 N/A 后期统一配；环境音 ≤2，全片声音元素 ≤4 |
| 拼接处画面跳变/色差 | 跨批次生成 | 过「五大衔接锁」：尾帧→首帧图生续接；跨镜相同 Aesthetic Header；后期统一 LUT/颗粒 |
| 宫格/分镜版式被拍进成片 | 宫格图当构图用 | 产品片禁用宫格（见宫格适用边界）；期望全画幅时改独立锚定照片 |

- [ ] 每个角色都配音色且与身份年龄匹配；多人台词标说话人
- [ ] 声音三层分工；元素总量 ≤4（无 BGM），超限须"有理由的超额"
- [ ] 每镜 1 个对位音、同刻 ≤2 音；音效 ≤2-3 个真实可辨识音
- [ ] BGM 默认 N/A；结尾提示音 / UI 音算音效，要保留
- [ ] non_diegetic_music 只写乐器/速度/节奏/动态，禁抽象情绪词
- [ ] 写 BGM 时点明"乐器=视觉变化"映射
- [ ] 声音方位写细（氛围/音效片）；文戏减

### 4. 物理与因果（8 红线）
- [ ] 动作链三查：前提 / 顺序 / 落点
- [ ] **后果强度按题材判**：写实/生活流 → 落物理可信区间；风格化（格斗/修仙/特效片）→ 由类型语法定，特效不因“动机弱”而缩小（见「因果叙事链」的边界条）
- [ ] 道具脱钩：要变状态的道具放场景段，不锁人物设定段
- [ ] 人物在场性：建立镜头含后续关键主体；新主体有入场动作
- [ ] 声源匹配（嘴塞东西 / 跑动 / 背对 不能讲完整长句）
- [ ] 180 度轴线不跨越；动作/追逐类逐镜锁空间关系
- [ ] 情绪用可观察表现；文戏用三阶段法；特写文戏用微表情弧线法
- [ ] 镜头间因果延续（上镜的事下镜有结果或延续）
- [ ] **舞蹈/多拍编排：下肢参与了吗？**连续 3 拍只有手臂动作＝pose 串烧；每 2–3 拍至少一次屈膝/重心下沉/落地缓冲
- [ ] **时间轴是否逐拍带视角标注？**（"侧面视角/转至侧背视角"）＝参考视频抽帧还原表，不是编舞 → 必须补过渡动作，并核难度曲线是否断裂（单腿三平面/无 plié）

### 5. 镜头与剪辑
- [ ] 景别服务情绪（不套固定骨架）；相邻镜跳级不跳切
- [ ] 每个切镜有 4 大理由之一（信息 / 情绪 / 视角 / 节奏）
- [ ] 运镜与景别匹配；主动技巧一镜一个并配可观察结果
- [ ] **有运镜的片子：每镜一主轨迹（至多叠一个从属微动，幅度小一档、不改走向、去掉仍成立）、幅度（极小/小/中/大）＋速度（极缓/缓/中/快）显式写出了吗？轨迹有起点→路径→落点吗？每镜都有叙事目的（信息/情绪/视角/节奏）吗？→ 按 `advanced-camera-movement` §7 逐项跑**
- [ ] 摄影术语配可观察结果
- [ ] 转场写全链条（触发→运动→变形→到达→声音）；要专业效果不要基础叠化（详见 `references/seedance-transitions.md`）
- [ ] 15s 内镜数与时长按功能分配；**时长之和严格 = 总时长**，切点 `At MM:SS.mmm` 递增
- [ ] **卡点密度核对**：0.83s/拍已进噪音区（H3 无逐拍对齐能力）→ 每拍末尾写"短暂停住半拍"当分节锚；每拍只给一个单关节 hit
- [ ] **机位与动作相位核对**：大动作（腿位组合）不与镜头绕行/推拉**同相位**；正面眼平机位读不出"落在身体轮廓之内"的手臂动作

### 6. 参考图 / 全参考模式
- [ ] 图锁定信息不重描（用"保留图中"）；图给不了的（声音/动态）必须写
- [ ] 多图逐一命名绑定 + 不采用声明；H3 用 `<Subject N>`，非 `@图片N`
- [ ] retention_analysis 逐标签标记；全参考模式六段式齐
- [ ] I2VA/FL2VA/L2VA 首帧对齐指令行必写；分镜参考图用 storyboard reference 句式（不写 fully referenced）
- [ ] 关键道具/角色用参考图锁定；纯文生须多镜重申数量位置状态
- [ ] 宫格分镜写明读取顺序 + 不采用线稿画风；白模写清主体/场景/动作/风格

### 7. 多段拼接 / 产品片（按需）
- [ ] 多段短剧先用六列镜头表规划 + 镜头表自检 6 项
- [ ] 多段拼接过五大衔接锁（详见 `references/official-skills-absorption.md` §5.1）
- [ ] 产品片多图参考用独立锚定照片而非宫格图
- [ ] 带品牌标识的片子走官方来源（禁 LOGO 聚合站 / AI 替代品）
- [ ] 连续运动型任务：启用正确模块 + 高动态单元三变（详见 `references/continuous-motion-module.md`）

### 7b. 长片 Chunk 模式（30 秒–1 分钟，按需）
> 详见 `references/continuum-longform.md`。以下 6 项是长片**专有**的翻车点，与上面第 7 组不重复。

- [ ] 段数 = `Chunks`，每个 `[Chunk N]` 恰好覆盖一次，N 从 1 连续
- [ ] `[Chunk N]` 独占一行；**三个字段每段都闭合**（不是只在首段）
- [ ] 首帧锚句只在 Chunk 1 写一次；Chunk 2+ 的 `[Shot 1]` 有 `Continuation of Chunk N.` + 中文承接句
- [ ] 每段末尾交接四件套（位置/动作相位/运镜/环境），下一段开头接住
- [ ] `<Picture N>` 编号全片稳定（中途不关图），设置说明里有槽位表
- [ ] 复合参考图（分格拼图/九宫格）已裁成单幅；参考图冲突已仲裁并写明服装权威源

### 8. 因果叙事专项（仅叙事任务启用）
- [ ] 平静起点 + 可见初始动作
- [ ] 只有一个主要触发事件
- [ ] 每个后续动作由前一事件引发
- [ ] 每次升级真正改变人物 / 道具 / 空间 / 情绪之一
- [ ] 主体做出可见的主动选择
- [ ] 结尾有清晰视觉结果或情绪余波
